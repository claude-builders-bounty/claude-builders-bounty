# Next.js + SQLite CLAUDE.md Template

This folder contains an opinionated `CLAUDE.md` for a greenfield SaaS app built with Next.js 15 App Router and SQLite through `better-sqlite3` or Turso/libSQL.

## Use

```bash
cp nextjs-sqlite-claude-template/CLAUDE.md /path/to/your-app/CLAUDE.md
```

Start Claude Code in the target repository. The file gives it stack assumptions, folder structure, migration rules, component patterns, commands, and anti-patterns without requiring additional project explanation.
