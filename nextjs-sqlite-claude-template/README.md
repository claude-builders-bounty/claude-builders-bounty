# Next.js + SQLite CLAUDE.md Template

This folder contains an opinionated `CLAUDE.md` for a greenfield SaaS project using Next.js 15 App Router and SQLite.

## Use in 3 steps

```bash
cp CLAUDE.md /path/to/your/nextjs-saas/CLAUDE.md
cd /path/to/your/nextjs-saas
claude
```

The template gives Claude Code project context for:

- stack and versions
- folder structure
- naming conventions
- SQLite migration rules
- component patterns
- server action patterns
- anti-patterns to avoid
- PR checklist

## Test note

I validated the document against the bounty acceptance criteria directly: every required section is present, every rule includes a practical reason or boundary, and it is written so Claude Code can act without asking for project-structure clarification in a typical greenfield Next.js + SQLite SaaS.
