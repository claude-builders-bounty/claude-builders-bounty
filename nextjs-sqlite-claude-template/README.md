# Next.js 15 + SQLite CLAUDE.md Template

Drop `CLAUDE.md` into a greenfield Next.js 15 App Router + SQLite SaaS project to give Claude Code clear project conventions.

## Setup

```bash
cp CLAUDE.md /path/to/your-project/CLAUDE.md
```

## Covers

- Next.js 15 App Router project structure
- SQLite + better-sqlite3 conventions
- Migration rules and typed query layer
- Server Components, Client Components, and Server Actions
- Testing expectations
- Anti-patterns to avoid

## Validation

This template is intentionally standalone: it should be copied into a target app rather than used as instructions for the bounty board repository itself.
