# Next.js 15 + SQLite CLAUDE.md Template

Opinionated `CLAUDE.md` for a greenfield SaaS app using Next.js 15 App Router and SQLite via `better-sqlite3` or Turso/libSQL.

## Use in 3 steps

1. Copy `CLAUDE.md` to the root of your Next.js + SQLite project.
2. Adjust package manager commands only if you do not use npm.
3. Ask Claude Code to inspect the project and follow `CLAUDE.md` before making changes.

## Test note

This template is designed to answer the common clarifying questions Claude Code asks on greenfield projects: stack, folder structure, migration policy, server/client boundaries, and anti-patterns.
