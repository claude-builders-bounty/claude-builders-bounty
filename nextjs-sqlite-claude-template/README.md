# Next.js + SQLite CLAUDE.md Template

Use this as the project instruction file for a greenfield SaaS app using Next.js 15 App Router and SQLite.

## Setup

1. Copy `CLAUDE.md` to the root of the Next.js project.
2. Update the app name and package manager command names if needed.
3. Start Claude Code from the project root.

The template is intentionally opinionated so Claude Code can act without asking for framework, database, or folder-layout clarification.
