# MCP Server: Bounty Automation

MCP server integrating all bounty automation tools.

## Tools

| Tool | Description |
|------|-------------|
| `review_pr` | Review pull requests |
| `generate_changelog` | Generate CHANGELOG.md |
| `generate_claude_template` | Generate CLAUDE.md template |
| `check_command_safety` | Check command safety |

## Setup

```bash
pip install mcp
```

## Usage

Configure in Claude Code settings.
