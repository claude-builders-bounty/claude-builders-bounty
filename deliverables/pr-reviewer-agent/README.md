# PR Reviewer Agent — `claude-review`

> Analyzes a GitHub PR diff and returns a structured Markdown review comment.

---

## Quick Install (2 commands)

```bash
pip install requests
cp claude-review.py /usr/local/bin/claude-review && chmod +x /usr/local/bin/claude-review
```

---

## Usage

### Review a PR by URL

```bash
claude-review --pr https://github.com/owner/repo/pull/123
```

### Review from a diff file

```bash
claude-review --diff-file changes.patch
```

### Review from stdin (pipe)

```bash
curl -sL https://github.com/owner/repo/pull/123.diff | claude-review --diff
```

### Demo mode (built-in sample)

```bash
claude-review --demo
```

### Save output to file

```bash
REVIEW_OUTPUT=review.md claude-review --pr https://github.com/owner/repo/pull/123
```

---

## Output Format

The agent produces a structured Markdown review with:

| Section | Description |
|---------|-------------|
| **📋 Summary** | 2-3 sentence overview of the change |
| **📊 Change Stats** | Files changed, lines added/removed, primary language |
| **📁 Changed Files** | List of modified files (up to 20) |
| **⚠️ Identified Risks** | Security, quality, performance, and logic issues |
| **💡 Improvement Suggestions** | Actionable recommendations |
| **🎯 Confidence Score** | High / Medium / Low based on risk count |

---

## Risk Detection

The agent detects **25+ risk patterns** across 5 categories:

### 🔒 Security (10 patterns)
- `eval()`, `exec()` usage
- SQL injection via string formatting
- XSS via `innerHTML`
- Hardcoded passwords, API keys, secrets
- Tokens in localStorage

### 📐 Code Quality (8 patterns)
- `TODO`, `FIXME`, `HACK` comments
- `var` instead of `let/const`
- Loose equality (`== null`)
- `debugger` statements

### ⚡ Performance (4 patterns)
- `for...in` loops
- Unnecessary `slice(0)` copies
- Date parsing in loops

### 🐛 Potential Bugs (5 patterns)
- Redundant `&& true` / `|| false`
- `if(true)` / `if(false)` dead code
- Empty `catch` blocks
- Bare `return` in non-void functions

### ✅ Test Detection (5 patterns)
- `it()`, `describe()`, `.test()`, `.expect()`
- `@pytest.fixture`
- Go `Test*` functions

## GitHub Action

Include `pr-reviewer-action.yml` in `.github/workflows/` to auto-review every PR:

```yaml
# .github/workflows/pr-review.yml
name: PR Review
on: [pull_request]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install requests
      - run: python claude-review.py --pr "https://github.com/${{ github.repository }}/pull/${{ github.event.pull_request.number }}"
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

| Variable | Required | Description |

| `REVIEW_OUTPUT` | Optional | Path to save review to file |
