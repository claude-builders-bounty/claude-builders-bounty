# Weekly Dev Summary — n8n + Claude API Workflow

Automated weekly narrative summary of GitHub repo activity, generated by Claude.

## Setup (4 steps)

1. **Import workflow** — Upload `weekly-dev-summary.json` to n8n
2. **Configure variables** in workflow static data:
   - `github_token` — GitHub personal access token (repo scope)
   - `claude_api_key` — Anthropic API key
   - `webhook_url` — Discord or Slack webhook URL
   - `repo_url` — GitHub API repo URL (e.g. `https://api.github.com/repos/owner/repo`)
   - `repo_name` — Human-readable repo name
   - `language` — `EN` or `FR`
3. **Activate** workflow
4. **Done** — summary arrives every Friday at 5pm

## Workflow Steps

1. **Cron Trigger** — Fridays at 5pm
2. **Fetch Commits** — GitHub commits API (past 7 days)
3. **Fetch Issues** — Closed issues (past 7 days)
4. **Fetch PRs** — Closed/merged PRs
5. **Aggregate** — JavaScript node merges data
6. **Claude API** — Generates narrative summary (claude-sonnet-4)
7. **Deliver** — Posts to Discord/Slack via webhook

## Configurable Variables

| Variable | Description |
|----------|-------------|
| `repo_url` | GitHub API repo endpoint |
| `repo_name` | Display name |
| `github_token` | PAT with repo scope |
| `claude_api_key` | Anthropic API key |
