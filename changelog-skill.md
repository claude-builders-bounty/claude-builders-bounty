# Skill: Generate Changelog

Generate a structured `CHANGELOG.md` from a project's git history.

## Trigger
`/generate-changelog` — invoked as a Claude Code slash command.

## How It Works

1. **Detect the last git tag** — uses `git describe --tags --abbrev=0` to find the starting point. Falls back to the initial commit if no tags exist.

2. **Collect all commits** since that tag (excluding merge commits) using `git log <tag>..HEAD --no-merges`.

3. **Auto-categorize each commit** into one of four sections based on conventional commit prefixes and keyword matching:
   - **Added** — `feat:`, `add:`, `new:`, `implement:`, `create:`, `introduce:`
   - **Fixed** — `fix:`, `bugfix:`, `hotfix:`, `resolve:`, `patch:`, `repair:`
   - **Changed** — `docs:`, `refactor:`, `style:`, `perf:`, or uncategorized
   - **Removed** — `remove:`, `delete:`, `drop:`, `deprecate:`

4. **Generate formatted output** — writes a KeepAChangelog-compatible `CHANGELOG.md` with version, date, and categorized commit list.

## Usage

### As a Claude Code slash command:
```
/generate-changelog
```

### As a standalone bash script:
```bash
bash changelog.sh
bash changelog.sh --since v1.0.0
bash changelog.sh --output RELEASE_NOTES.md --dry-run
```

## Example Output

```markdown
# Changelog

## [v1.2.0] — 2026-06-06

### Added
- feat: add user authentication with JWT
- new: implement email verification flow

### Fixed
- fix: resolve race condition in token refresh
- bugfix: correct null check on user profile

### Changed
- docs: update API reference for v2 endpoints
- refactor: extract validation middleware

### Removed
- drop: deprecated /v1/legacy endpoint

---
*Generated by changelog.sh on 2026-06-06*
```

## Requirements
- Git 2.0+
- Bash 4.0+ (or Zsh)

## Options

| Flag | Description |
|------|-------------|
| `--since <tag>` | Start from a specific git tag (default: latest tag) |
| `--output <file>` | Output file path (default: `./CHANGELOG.md`) |
| `--dry-run` | Print to stdout instead of writing to file |
| `--help` | Show usage help |

## Integration with Claude Code

```markdown

When the user types `/generate-changelog`:
```
