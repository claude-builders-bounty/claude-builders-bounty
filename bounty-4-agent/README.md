# PR Review Agent — Bounty Submission

A Claude Code sub-agent that automatically reviews GitHub PRs and posts structured comments.

## Features
- Fetches PR diff via GitHub API
- Analyzes correctness, security, performance, maintainability
- Posts structured markdown with severity levels (Critical/Warning/Suggestion)
- Includes file-by-file breakdown
- Provides an overall score and recommendation
