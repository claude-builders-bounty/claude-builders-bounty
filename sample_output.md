# Sample CHANGELOG Output

The following sample demonstrates the output generated by `generate_changelog.py` when run against a repository containing conventional commits:

```markdown
# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [v1.0.0] - 2026-10-04
> Changes since tag `v0.9.0`

### Added
- Introduce structured changelog generator CLI ([`7a1b2c3`]) by @developer
- Support automatic git tag detection and fallback ([`4d5e6f7`]) by @developer
- Add Keep-a-Changelog Markdown formatter ([`8a9b0c1`]) by @contributor

### Changed
- Refactor commit parser regex to support scoped conventional commits ([`2d3e4f5`]) by @developer
- Update README documentation with 3-step setup guide ([`5a6b7c8`]) by @developer

### Fixed
- Handle empty commit range gracefully when no commits exist ([`9b0c1d2`]) by @contributor
- Fix tag sorting order on older git versions ([`3e4f5a6`]) by @developer

### Removed
- Deprecate legacy manual changelog update workflow ([`1c2d3e4`]) by @developer
```
