# Product Context: Git Intelligence Suite

## 🎯 Mission
Создание набора инструментов для автоматизации рутинных задач разработчика: генерация логов, аудит коммитов и управление выпусками (Release Management).

## 🌍 Market & Use Cases
1. **Automated Release Notes**: Генерация списков изменений для стейкхолдеров.
2. **Commit Hygiene Audit**: Проверка соблюдения стандарта Conventional Commits.
3. **Repository Intelligence**: Анализ активности разработчиков на основе логов.

## 🛡 Security & Ethics
- Скрипт работает локально, не передает данные на внешние серверы.
- Обработка персональных данных (email в логах) регулируется локальными политиками приватности.
- Хеширование коммитов (SHA1/SHA256) используется для обеспечения неизменяемости истории.
