# Community Intel: Git & Changelog Standards

## 📜 Conventional Commits
- **Status**: Industry Standard.
- **Intel**: Популярные инструменты (Husky, commitlint) заставляют пользователей следовать этому стандарту. Наш парсер должен быть совместим.

## 💎 Semantic Versioning (SemVer)
- **Intel**: Использование тегов `vX.Y.Z` является критически важным для разбиения лога по версиям. 

## 🐙 GitHub Releases
- **Intel**: GitHub может автоматически генерировать лог, но наш инструмент дает большую гибкость (кастомные шаблоны, локальное использование без доступа в сеть).
