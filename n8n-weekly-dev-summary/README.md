# 📊 n8n + Claude: Weekly Dev Summary Workflow

An automated n8n workflow that generates a weekly narrative summary of your GitHub repo's activity using the Claude API.

Built for [claude-builders-bounty #5](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/5) ($200 bounty).

## What It Does

Every Friday at 5pm, this workflow:
1. **Fetches** from GitHub API: commits, closed issues, merged PRs (last 7 days)
2. **Merges** and filters the data
3. **Calls** Claude API (`claude-sonnet-4-20250514`) to generate an engaging narrative summary
4. **Delivers** the summary via Discord or Slack webhook

## Setup (5 steps)

### 1. Import the workflow
In n8n, go to **Workflows → Import from File** and select `github-weekly-summary.json`.

### 2. Create credentials
Go to **Credentials → Add Credential → Header Auth**:
- **Name**: `GitHub Token`
- **Header Name**: `Authorization`
- **Header Value**: `token ghp_your_github_token_here`

### 3. Set variables
In the workflow, click **Variables** and set:

| Variable | Description | Example |
|----------|-------------|---------|
| `GITHUB_REPO` | owner/repo to track | `facebook/react` |
| `ANTHROPIC_API_KEY` | Claude API key | `sk-ant-xxxxx` |
| `WEBHOOK_URL` | Discord or Slack webhook | `https://discord.com/api/webhooks/...` |
| `LANGUAGE` | Output language (EN/FR) | `EN` (optional, defaults to EN) |

### 4. Configure delivery
By default, the workflow sends to **both** Discord and Slack webhooks. To use only one:
- Delete the node you don't need
- Or leave the `WEBHOOK_URL` variable pointing to your preferred platform

### 5. Activate
Toggle the workflow to **Active**. It will run every Friday at 5pm.

## Configurable Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GITHUB_REPO` | ✅ | — | `owner/repo` to summarize |
| `ANTHROPIC_API_KEY` | ✅ | — | Claude API key |
| `WEBHOOK_URL` | ✅ | — | Discord or Slack webhook URL |
| `GITHUB_API_URL` | ❌ | `https://api.github.com` | For GitHub Enterprise |
| `LANGUAGE` | ❌ | `EN` | Output language (`EN` or `FR`) |

## Discord Webhook Setup

1. Server Settings → Integrations → Webhooks → New Webhook
2. Copy the webhook URL
3. Set it as `WEBHOOK_URL` variable

## Slack Webhook Setup

1. Go to https://api.slack.com/apps → Create New App
2. Enable Incoming Webhooks
3. Add to channel, copy webhook URL
4. Set it as `WEBHOOK_URL` variable

## Testing
