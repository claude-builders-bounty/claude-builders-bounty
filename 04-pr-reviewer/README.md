# Claude Code PR Reviewer Agent

A CLI tool and Claude Code sub-agent that reviews GitHub PRs and produces structured Markdown reviews.

## Setup

```bash
pip install requests  # or: python3 -m pip install requests
chmod +x claude-review.py
```

## Usage

```bash
# Review a GitHub PR
python claude-review.py --pr https://github.com/owner/repo/pull/123

# Review a local diff
python claude-review.py --diff-file path/to/changes.patch
```

## Sample Output

```markdown
# 🤖 AI Code Review

## Summary
**Fix memory leak in WebSocket handler** — This PR modifies 3 file(s) with 45 additions and 12 deletions.

## 🚨 Identified Risks
- ⚠️  **Potential SQL injection** — use parameterized queries

## 💡 Improvement Suggestions
- 💡 Remove `console.log` statements before merging
- 💡 No test changes detected — consider adding tests

---
**Confidence Score: High** | Files: 3 | +45 -12

*🤖 This review was generated by Claude Code PR Reviewer Agent*
```

## Features

- **Summary**: 2-3 sentence overview of changes
- **Risk detection**: Hardcoded secrets, SQL injection, dynamic code execution, large PRs
- **Suggestions**: Console.log removal, TODO markers, TypeScript any usage, missing tests
- **Confidence score**: Low / Medium / High based on risk count and PR size
- Works with `gh` CLI or direct GitHub API (fallback)

## GitHub Action (optional)

```yaml
name: AI PR Review
on:
  pull_request:
    types: [opened, synchronize]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install requests
      - name: Run AI Review
        run: python claude-review.py --pr "${{ github.event.pull_request.html_url }}" | tee review.md
      - uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            github.rest.issues.createComment({
              ...context.repo,
              issue_number: context.issue.number,
              body: fs.readFileSync('review.md', 'utf8')
            });
```
