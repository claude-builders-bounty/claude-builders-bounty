# Changelog Generator

Automatically generates a structured `CHANGELOG.md` from your git history, supporting both a direct bash script and a native Claude Code semantic command.

## Setup

1. Copy the contents of this folder into the root of your project.
2. For CLI usage, make the script executable: `chmod +x changelog.sh`
3. Generate the changelog by running `/generate-changelog` (in Claude Code) OR `./changelog.sh` (in terminal).
