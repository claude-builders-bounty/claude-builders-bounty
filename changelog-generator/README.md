# Changelog Generator

Automatically generates a structured `CHANGELOG.md` from your git history since the last tag. Commits are auto-categorized into **Added**, **Fixed**, **Changed**, and **Removed**.

## Setup in 3 Steps
1. Make the script executable: `chmod +x changelog.sh`
2. Place `changelog.sh` in the root of your git repository.
3. Run the script: `./changelog.sh`

*Your structured `CHANGELOG.md` will be instantly generated in the current directory.*
