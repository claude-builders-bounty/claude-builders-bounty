# CHANGELOG Generator

A Claude Code skill and bash script that generates a structured `CHANGELOG.md`
from git history — auto-categorizing commits into Added, Fixed, Changed, Removed.

## Installation (3 steps)

```bash
# 1. Make executable
chmod +x scripts/changelog.sh

# 2. Run it
bash scripts/changelog.sh

# 3. (Optional) Register as Claude Code skill
# The SKILL.md in skills/changelog-generator/ is auto-discovered
```

## Usage

```bash
# From most recent tag
bash scripts/changelog.sh

# From a specific tag
bash scripts/changelog.sh --since v1.0.0

# Custom output path
bash scripts/changelog.sh --output docs/CHANGELOG.md
```

## Categorization Logic

| Prefix | Category |
|--------|----------|
| `feat:`, `add:`, `new:`, `introduce:`, `implement:` | **Added** |
| `fix:`, `bug:`, `hotfix:`, `patch:`, `resolve:`, `correct:` | **Fixed** |
| `remove:`, `drop:`, `delete:`, `deprecate:` | **Removed** |
| Everything else (`chore:`, `refactor:`, `docs:`, etc.) | **Changed** |
