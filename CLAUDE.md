## Stack & Versions

| Layer | Choice | Why |
|-------|--------|-----|
| Framework | Next.js 15 (App Router) | RSC by default, streaming, server-first |
| Language | TypeScript (strict) | Catches null refs before they hit prod |
| Database | better-sqlite3 (dev) / Turso (prod) | Zero-config local dev, edge-ready prod |
| ORM | Drizzle ORM | Type-safe, SQL-like DX, no magic |
| Auth | Better Auth v1 | OAuth + credentials, server-only, typed sessions |
| Styling | Tailwind CSS v4 + shadcn/ui | Utility-first, component library on top |
| Validation | Zod | Parse at boundaries, trust inside |
| Payments | Stripe | Checkout sessions, webhooks, no card data on our servers |
| Email | Resend | React email templates, high deliverability |
| Testing | Vitest + Playwright | Fast unit tests, real browser E2E |
| Linting | Biome | Fast, replaces ESLint + Prettier |
| CI/CD | GitHub Actions | Runs on every PR |

## Naming Conventions

| What | Convention | Example |
|------|-----------|---------|
| Files | kebab-case | `create-team.ts`, `user-avatar.tsx` |
| Components | PascalCase, default export | `export default function UserAvatar()` |
| Hooks | camelCase, `use` prefix | `useDebounce`, `useCurrentUser` |
| Server actions | camelCase, `Action` suffix | `updateProfileAction` |
| Services | camelCase, verb-led | `createCheckoutSession()` |
| DB tables | snake_case, plural | `users`, `team_members` |
| DB columns | snake_case | `created_at`, `stripe_customer_id` |
| Env vars | `NEXT_PUBLIC_` for client, plain for server | `NEXT_PUBLIC_APP_URL`, `DATABASE_URL` |
| Route groups | Parenthesized kebab | `(auth)`, `(dashboard)` |

## SQL & Migration Rules

1. **Schema lives in `src/db/schema.ts`** — one file while under 20 tables. Split to `schema/` subfolder when it grows.
2. **Every table gets `created_at` and `updated_at`** — `created_at: text("created_at").notNull().default(sql`(datetime('now'))`)`
3. **Foreign keys are explicit** — `references(() => users.id, { onDelete: "cascade" })`. Never rely on implicit relations.
4. **No raw SQL in application code** — Drizzle queries only. Raw SQL is for migrations and seed scripts.
5. **Migrations are generated, never hand-written** — `drizzle-kit generate` then `drizzle-kit migrate`. Review generated SQL before committing.
6. **Index every column you query with `WHERE`** — add `.$index()` to the Drizzle column definition, or raw `CREATE INDEX` in a migration.
7. **Soft-delete over hard-delete for user data** — add `deleted_at` column, filter with `.where(isNull(table.deleted_at))`. Users demand data recovery.
8. **Turso (prod) vs better-sqlite3 (dev) compat** — use `sql` template tag for datetime functions (not `NOW()`), avoid `RETURNING` with complex joins, test migrations against Turso before merging.

## Component Patterns

### Server Component (default)
```tsx
// Always default export. Fetch data directly, no hooks.
import { db } from "@/lib/db";
import { users } from "@/db/schema";
import { eq } from "drizzle-orm";

export default async function UserList() {
  const allUsers = await db.select().from(users);
  if (allUsers.length === 0) return <EmptyState />;
  return <ul>{allUsers.map(u => <UserCard key={u.id} user={u} />)}</ul>;
}
```

### Client Component (opt-in with `"use client"`)
```tsx
"use client";
// Only when you need: useState, useEffect, event handlers, browser APIs.
// Prefer useActionState + Server Actions for form submissions.
export function SearchInput() {
  const [query, setQuery] = useState("");
  return <input value={query} onChange={e => setQuery(e.target.value)} />;
}
```

### Form Pattern — useActionState + Zod
```tsx
// actions/settings.ts
"use server";
import { z } from "zod";
import { updateUser } from "@/services/users";
import { auth } from "@/lib/auth";

const schema = z.object({ name: z.string().min(2).max(100) });

export async function updateProfileAction(prev: unknown, formData: FormData) {
  const session = await auth.api.getSession({ headers: headers() });
  if (!session) return { error: "Unauthorized" };

  const parsed = schema.safeParse({ name: formData.get("name") });
  if (!parsed.success) return { error: parsed.error.flatten().fieldErrors };

  await updateUser(session.user.id, parsed.data);
  return { success: true };
}
```

### Loading & Error Boundaries
```tsx
// page.tsx — Suspense for async, error.tsx for failures
export default function Page() {
  return (
    <Suspense fallback={<Skeleton />}>
      <AsyncContent />
    </Suspense>
  );
}
// error.tsx (sibling file, auto-wraps)
"use client";
export default function Error({ error, reset }: { error: Error; reset: () => void }) {
  return <div>Something went wrong. <button onClick={reset}>Try again</button></div>;
}
```

## What We Don't Do (And Why)

| Anti-pattern | Why it's wrong |
|-------------|----------------|
| `useEffect` for data fetching | Server Components fetch on the server. useEffect adds client-side waterfalls. |
| API routes calling other API routes internally | Circular dependency. Extract shared logic to `services/`. |
| `any` type | Defeats TypeScript. Give it 5 more seconds to type correctly. |
| `as` type assertions on external data | Parse with Zod. `as` lies; Zod verifies. |
| Barrel exports (`index.ts` re-exporting everything) | Causes tree-shaking failures and slow HMR. Import directly from the file. |
| `useSearchParams()` wrapped in Suspense without a fallback | Triggers CSR bailout on the entire page. Use a `<Suspense>` boundary around just the component that reads params. |
| `Date.now()` in Server Components or DB defaults | Non-deterministic. Use `sql`(datetime('now'))`` or pass dates explicitly. |
| `process.env` without `src/env.ts` validation | Crashes at runtime with cryptic errors. Validate at startup with t3-env or Zod. |
| Auth checks in components | Components render. Guards belong in layouts, middleware, or services. |
| Raw `fetch` without error handling | Always wrap: check `res.ok`, parse with Zod, handle network errors. |

## Auth Pattern (Better Auth)

```ts
// lib/auth.ts — one file, configures all providers
import { betterAuth } from "better-auth";
import { drizzleAdapter } from "better-auth/adapters/drizzle";
import { db } from "./db";

export const auth = betterAuth({
  database: drizzleAdapter(db, { provider: "sqlite" }),
  emailAndPassword: { enabled: true },
  socialProviders: {
    github: { clientId: env.GITHUB_CLIENT_ID, clientSecret: env.GITHUB_CLIENT_SECRET },
    google: { clientId: env.GOOGLE_CLIENT_ID, clientSecret: env.GOOGLE_CLIENT_SECRET },
  },
});

// In route handlers: await auth.api.getSession({ headers })
// In Server Components: const session = await auth.api.getSession({ headers: headers() })
// In layout: wrap in <Suspense>, call auth, redirect if null
```
