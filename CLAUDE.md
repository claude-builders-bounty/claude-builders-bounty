## Commands

```bash
npm install          # or pnpm / yarn — match lockfile
npm run dev
npm run lint
npm run test
npm run migrate      # if present
```

## Repository layout

- `app/` — routes, layouts, server components
- `lib/` — shared utilities and DB access
- `db/` — schema, migrations, seeds

## Conventions

- Prefer server components; mark client components explicitly
- Keep secrets in env; never commit `.env`
- One clear migration per schema change
- Name files by domain, not by framework trivia

## Anti-patterns

- Do not force-push to main
- Do not invent APIs that are not in the repo
- Do not bypass auth or invent credentials
