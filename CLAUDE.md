# CLAUDE.md — Next.js 15 + SQLite SaaS

## Stack
- **Framework**: Next.js 15 App Router (React 19, RSC)
- **Database**: SQLite via better-sqlite3 (Turso for production)
- **ORM**: Drizzle ORM with drizzle-kit migrations
- **Auth**: NextAuth.js v5 with credentials + OAuth providers
- **Styling**: Tailwind CSS 4 + shadcn/ui components
- **Validation**: Zod for API inputs + react-hook-form for forms
- **Language**: TypeScript strict mode

## Folder Structure
```
src/
├── app/            # Next.js App Router routes (no pages/)
│   ├── (auth)/     # Auth-related layouts
│   ├── api/        # Route handlers (REST)
│   └── dashboard/  # Protected routes
├── components/     # Shared React components
│   ├── ui/         # shadcn/ui primitives
│   └── forms/      # Form components
├── db/
│   ├── schema/     # Drizzle table definitions
│   └── migrations/ # Auto-generated by drizzle-kit
├── lib/            # Utilities, helpers, config
├── actions/        # Server Actions (one file per domain)
└── types/          # Shared TypeScript types
```

## DB / Migration Rules
- One `schema/*.ts` file per domain (users.ts, teams.ts, billing.ts)
- Never edit migration files manually — `drizzle-kit generate` only
- Migration naming: `YYYYMMDD_description` (auto-generated)
- SQLite has no enum type — use `text` with Zod enum validation
- All timestamps default to `sql`'s `current_timestamp`
- Soft deletes: add `deleted_at` column instead of `DELETE FROM`

## Component Patterns
- Server components by default — only add `"use client"` when needed
- Data fetching in Server Components (`async` component, not `useEffect`)
- shadcn/ui components customized in `components/ui/`
- Forms: react-hook-form + Zod resolver on the client, Server Action on submit

## Naming Conventions
- Files: `kebab-case.ts` (route groups use `(group)`)
- Exports: PascalCase for components, camelCase for functions
- DB columns: `snake_case`
- Types: PascalCase (UserProfile), prefixed with `T` for inferred types (TUser)

## Dev Commands
```bash
npm run dev        # next dev --turbo
npm run build      # next build
npm run test       # vitest
npm run db:gen     # drizzle-kit generate
npm run db:push    # drizzle-kit push (dev only)
```

## What We Don't Do
- **No `any`** — use `unknown` + Zod parsing for external data
- **No Redux/Zustand** — URL state for shareable state, React context for UI state
- **No raw SQL strings** — always use Drizzle query builder
- **No barrel exports** — explicit imports only (prevents circular deps)
- **No `useEffect` for data fetching** — Server Components or Server Actions
