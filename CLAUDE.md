## 🏗 Stack & Versions (Locked)

| Layer | Choice | Version | Why |
|-------|--------|---------|-----|
| Framework | Next.js | **15.x** (App Router only) | RSC by default, Server Actions, streaming |
| Database | **SQLite** | better-sqlite3 (local) / Turso (prod) | Zero-config, embeddable, 10x cheaper than Postgres for SaaS |
| ORM | **Drizzle** | Latest | Type-safe, no reflection overhead, migrations as code |
| Auth | **NextAuth v5** (Auth.js) | Edge-compatible | Server Actions + credentials/OAuth, no extra infra |
| Styling | **Tailwind v4** + shadcn/ui | Latest | CSS-first, no config file, tree-shakable |
| Validation | **Zod v4** | Schema-first | Single source of truth for types + runtime |
| Testing | **Vitest** + Playwright | Unit + E2E | Fast, native ESM, CI-friendly |
| Lint/Format | **Biome** | Replaces ESLint+Prettier | 10x faster, unified config |
| Package Manager | **pnpm** | Strict hoisting | Disk efficiency, monorepo-ready |

**Hard constraints:** No `pages/` directory. No `any` types. No raw SQL in application code. No `useEffect` for data fetching.

## 🗄 Database Conventions (Drizzle + SQLite)

```typescript
// db/schema/users.ts — CANONICAL PATTERN
import { sqliteTable, text, integer, index } from "drizzle-orm/sqlite-core";
import { sql } from "drizzle-orm";

export const users = sqliteTable("users", {
  id: text("id").primaryKey().$defaultFn(() => crypto.randomUUID()), // UUID v4
  email: text("email").notNull().unique(),
  emailVerified: integer("email_verified", { mode: "timestamp_ms" }),
  passwordHash: text("password_hash"),
  name: text("name"),
  avatarUrl: text("avatar_url"),
  role: text("role", { enum: ["owner", "admin", "member", "viewer"] }).default("member").notNull(),
  createdAt: integer("created_at", { mode: "timestamp_ms" }).default(sql`(strftime('%s','now')*1000)`).notNull(),
  updatedAt: integer("updated_at", { mode: "timestamp_ms" }).$onUpdate(() => Date.now()).notNull(),
  deletedAt: integer("deleted_at", { mode: "timestamp_ms" }), // SOFT DELETE
}, (t) => [
  index("users_email_idx").on(t.email),
  index("users_deleted_at_idx").on(t.deletedAt),
]);

// Relations in separate file: db/schema/relations.ts
export const usersRelations = relations(users, ({ many, one }) => ({
  teamMemberships: many(teamMembers),
  ownedTeams: many(teams),
  sessions: many(sessions),
  accounts: many(accounts),
}));
```

**Rules:**
1. **UUID v4 primary keys** — no sequential IDs (enumeration attacks)
2. **Soft deletes everywhere** — `deletedAt` timestamp, filter with `.where(isNull(deletedAt))`
3. **snake_case columns** — Drizzle maps to camelCase automatically
4. **Created/updated timestamps** — server-side defaults, `$onUpdate` for updatedAt
5. **Indexes on foreign keys + query patterns** — declare in table definition
6. **Enums as CHECK constraints** — `text("role", { enum: [...] })`
7. **Migrations are code** — `pnpm db:generate` → review SQL → commit → `pnpm db:migrate`

```tsx
  extends React.ButtonHTMLAttributes<HTMLButtonElement>,

  asChild?: boolean;
}
```

**Rules:**
- Server Components by default — add `"use client"` only when you need: interactivity, browser APIs, hooks, or event handlers
- Client components are **leaf nodes** — they don't import server components
- One component per file, colocated with its styles/tests

## ⚡ Server Actions (The Only API Layer)

```typescript
// app/actions/teams.ts
"use server";

import { revalidatePath } from "next/cache";
import { z } from "zod";
import { db } from "@/db";
import { teams, teamMembers } from "@/db/schema/teams";
import { eq, and } from "drizzle-orm";
import { getSession } from "@/lib/auth";
import { teamSchema } from "@/lib/validations/team";

export async function createTeam(input: z.infer<typeof teamSchema.create>) {
  const session = await getSession();
  if (!session) throw new Error("Unauthorized");

  const validated = teamSchema.create.parse(input);

  const [team] = await db
    .insert(teams)
    .values({
      name: validated.name,
      slug: validated.slug.toLowerCase().replace(/\s+/g, "-"),
      ownerId: session.user.id,
    })
    .returning();

  await db.insert(teamMembers).values({
    teamId: team.id,
    userId: session.user.id,
    role: "owner",
  });

  revalidatePath("/dashboard");
  return team;
}

export async function updateTeam(teamId: string, input: z.infer<typeof teamSchema.update>) {
  const session = await getSession();
  if (!session) throw new Error("Unauthorized");

  const membership = await db.query.teamMembers.findFirst({
    where: and(eq(teamMembers.teamId, teamId), eq(teamMembers.userId, session.user.id)),
  });
  if (!membership || !["owner", "admin"].includes(membership.role)) {
    throw new Error("Forbidden");
  }

  const validated = teamSchema.update.parse(input);

  const [team] = await db
    .update(teams)
    .set({ ...validated, updatedAt: Date.now() })
    .where(eq(teams.id, teamId))
    .returning();

  revalidatePath(`/dashboard/teams/${teamId}`);
  return team;
}

export async function deleteTeam(teamId: string) {
  const session = await getSession();
  if (!session) throw new Error("Unauthorized");

  const membership = await db.query.teamMembers.findFirst({
    where: and(eq(teamMembers.teamId, teamId), eq(teamMembers.userId, session.user.id)),
  });
  if (!membership || membership.role !== "owner") {
    throw new Error("Only owners can delete teams");
  }

  await db.delete(teams).where(eq(teams.id, teamId));
  revalidatePath("/dashboard");
}
```

**Rules:**
- One file per domain (`users.ts`, `teams.ts`, `billing.ts`)
- `revalidatePath` for cache invalidation — no manual cache tags
- Zod validation at the boundary — trust nothing
- Auth check first, authorization second
- Throw errors — Next.js catches and shows `error.tsx`
- No API routes for CRUD. Only: webhooks, OAuth callbacks, file uploads

## 🔐 Auth (NextAuth v5)

```typescript
// lib/auth.ts
import NextAuth from "next-auth";
import Credentials from "next-auth/providers/credentials";
import GitHub from "next-auth/providers/github";
import Google from "next-auth/providers/google";
import { db } from "@/db";
import { users, accounts } from "@/db/schema/users";
import { eq, and } from "drizzle-orm";
import { verifyPassword } from "@/lib/password";

export const { handlers, auth, signIn, signOut } = NextAuth({
  providers: [
    GitHub,
    Google,
    Credentials({
      name: "credentials",
      credentials: { email: {}, password: {} },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) return null;

        const user = await db.query.users.findFirst({
          where: eq(users.email, credentials.email as string),
        });
        if (!user?.passwordHash) return null;

        const valid = await verifyPassword(credentials.password as string, user.passwordHash);
        if (!valid) return null;

        return { id: user.id, email: user.email, name: user.name, role: user.role };
      },
    }),
  ],
  callbacks: {
    async jwt({ token, user }) {
      if (user) token.id = user.id;
      return token;
    },
    async session({ session, token }) {
      if (token.id) session.user.id = token.id as string;
      return session;
    },
  },
  pages: { signIn: "/login", error: "/login" },
  session: { strategy: "jwt" },
});
```

## 💳 Billing (Stripe + Server Actions)

```typescript
// app/actions/billing.ts
"use server";

import { headers } from "next/headers";
import Stripe from "stripe";
import { db } from "@/db";
import { subscriptions } from "@/db/schema/billing";
import { eq } from "drizzle-orm";
import { getSession } from "@/lib/auth";

const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!, {
  apiVersion: "2024-06-20",
  typescript: true,
});

export async function createCheckoutSession(priceId: string) {
  const session = await getSession();
  if (!session) throw new Error("Unauthorized");

  const subscription = await db.query.subscriptions.findFirst({
    where: eq(subscriptions.userId, session.user.id),
  });

  const customerId = subscription?.stripeCustomerId ?? (
    await stripe.customers.create({ email: session.user.email!, metadata: { userId: session.user.id } })
  ).id;

  const checkout = await stripe.checkout.sessions.create({
    customer: customerId,
    mode: "subscription",
    line_items: [{ price: priceId, quantity: 1 }],
    success_url: `${process.env.NEXT_PUBLIC_APP_URL}/dashboard/billing?success=true`,
    cancel_url: `${process.env.NEXT_PUBLIC_APP_URL}/dashboard/billing`,
  });

  return { url: checkout.url };
}

export async function createPortalSession() {
  const session = await getSession();
  if (!session) throw new Error("Unauthorized");

  const subscription = await db.query.subscriptions.findFirst({
    where: eq(subscriptions.userId, session.user.id),
  });
  if (!subscription?.stripeCustomerId) throw new Error("No subscription found");

  const portal = await stripe.billingPortal.sessions.create({
    customer: subscription.stripeCustomerId,
    return_url: `${process.env.NEXT_PUBLIC_APP_URL}/dashboard/billing`,
  });

  return { url: portal.url };
}

// Webhook handler: app/api/stripe/webhook/route.ts
export async function POST(req: Request) {
  const body = await req.text();
  const sig = headers().get("stripe-signature")!;
  let event: Stripe.Event;

  try {
    event = stripe.webhooks.constructEvent(body, sig, process.env.STRIPE_WEBHOOK_SECRET!);
  } catch (err) {
    return new Response("Webhook signature verification failed", { status: 400 });
  }

  switch (event.type) {
    case "customer.subscription.created":
    case "customer.subscription.updated":
    case "customer.subscription.deleted": {
      const sub = event.data.object as Stripe.Subscription;
      await db
        .insert(subscriptions)
        .values({
          userId: sub.metadata.userId,
          stripeCustomerId: sub.customer as string,
          stripeSubscriptionId: sub.id,
          stripePriceId: sub.items.data[0]?.price.id,
          stripeCurrentPeriodEnd: new Date(sub.current_period_end * 1000),
          status: sub.status,
        })
        .onConflictDoUpdate({
          target: subscriptions.stripeSubscriptionId,
          set: {
            stripePriceId: sub.items.data[0]?.price.id,
            stripeCurrentPeriodEnd: new Date(sub.current_period_end * 1000),
            status: sub.status,
            updatedAt: Date.now(),
          },
        });
      break;
    }
  }

  return new Response(null, { status: 200 });
}
```

## 🚫 Anti-Patterns — What We DON'T Do

| Anti-Pattern | Alternative | Why |
|--------------|-------------|-----|
| **NO `pages/` directory** | App Router only | Next.js 15 is App Router native |
| **NO `any` types** | Use `unknown` + Zod narrowing | Type safety at boundaries |
| **NO raw SQL in application code** | Drizzle query builder | Type-safe, composable, migration-friendly |
| **NO `useEffect` for data fetching** | Server Components or SWR/React Query for client | No waterfalls, streaming SSR |
| **NO API routes for forms** | Server Actions | Progressive enhancement, zero-JS fallback |
| **NO `process.env` in client code** | `NEXT_PUBLIC_` prefix or server-only context | Secret leakage prevention |
| **NO barrel exports from `components/`** | Import directly: `@/components/ui/button` | Avoids bundling entire UI library |
| **NO hardcoded URLs** | Environment variables or `headers()` for dynamic host | Multi-environment deployments |
| **NO `Date.now()` in server code without `server-only`** | `import "server-only"` at top of server modules | Ensures server-only execution |
| **NO `useOptimistic` without React 19 flag** | ⚠️ Experimental — use with caution | API may change/break |

## 🤔 When In Doubt

1. **Check Next.js docs first** — they have a pattern for most things
2. **Prefer composition over inheritance** — React is designed for it
3. **Keep files under 200 lines** — split aggressively
4. **One server action file per domain** (`users.ts`, `teams.ts`, `billing.ts`)
5. **Every PR touching schema includes a migration** — no exceptions

## 🔒 Server-Only Modules

- Add `import "server-only"` at the top of any file using: DB client, secrets, Node APIs (fs, crypto), Stripe secret key
- Use the `server-only` package (already a dependency of Next.js)
- This causes a build error if accidentally imported in a client component

```typescript

import Stripe from "stripe";

  apiVersion: "2024-06-20",
```

## 🗄 Database Singleton (Critical for Serverless)

`better-sqlite3` is not thread-safe and creates a new connection per import. In serverless (Vercel, etc.), this exhausts connections. Use a singleton pattern:

```typescript
// db/index.ts
import "server-only";
import { drizzle } from "drizzle-orm/better-sqlite3";
import Database from "better-sqlite3";
import { env } from "@/lib/env";

const globalForDb = globalThis as unknown as {
  db: ReturnType<typeof drizzle>;
};

export const db = globalForDb.db ?? drizzle(new Database(env.DATABASE_URL));
if (process.env.NODE_ENV !== "production") globalForDb.db = db;
```

## 🛡 Middleware Conventions

- `middleware.ts` at project root for: auth protection, i18n, bot detection, security headers
- Use `createServerClient()` pattern for auth in middleware (see NextAuth v5 middleware example)
- Matcher config: `export const config = { matcher: ["/dashboard/:path*"] }`

```typescript
// middleware.ts
import { auth } from "@/lib/auth";
import { NextResponse } from "next/server";

export default auth((req) => {
  const isLoggedIn = !!req.auth;
  const isOnDashboard = req.nextUrl.pathname.startsWith("/dashboard");
  
  if (isOnDashboard && !isLoggedIn) {
    return NextResponse.redirect(new URL("/login", req.nextUrl));
  }
});

export const config = {
  matcher: ["/dashboard/:path*", "/api/:path*"],
};
```

## 🧱 Error Boundaries

- `app/error.tsx` per route segment
- `app/global-error.tsx` for root layout errors
- Must use `"use client"` in error boundaries

```tsx
// app/dashboard/error.tsx
"use client";

import { useEffect } from "react";

export default function DashboardError({ error, reset }: { error: Error; reset: () => void }) {
  useEffect(() => {
    console.error("Dashboard error:", error);
  }, [error]);

  return (
    <div className="p-8 text-center">
      <h2 className="text-xl font-semibold">Something went wrong</h2>
      <p className="text-muted-foreground mt-2">{error.message}</p>
      <button onClick={reset} className="mt-4 btn-primary">
        Try again
      </button>
    </div>
  );
}
```
