# Claude PR Reviewer Agent

An intelligent Claude-powered agent that automatically reviews GitHub Pull Requests and provides structured, actionable feedback.

## Features
- Fetches real-time PR diffs using `gh` CLI.
- Analyzes code changes using Claude 3.5 Sonnet.
- Provides a structured Markdown report with:
  - Executive Summary
  - Risk Assessment
  - Improvement Suggestions
  - Confidence Scoring

## Setup in 2 Steps

1. **Install Dependencies**:
   ```bash
   pip install requests
   ```
2. **Set API Key**:
   ```bash
   export ANTHROPIC_API_KEY='your-key-here'
   ```

## Usage
```bash
python claude_review.py --pr https://github.com/owner/repo/pull/123
```
