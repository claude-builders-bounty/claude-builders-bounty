## Summary

A Claude Code `pre-tool-use` hook that intercepts Bash commands before
execution and rejects any command matching a destructive pattern:
`rm -rf` / `-fr`, `DROP TABLE`, `git push --force`, `TRUNCATE`,
`DELETE FROM` without a `WHERE` clause, `mkfs`, `dd`, `shutdown`, `reboot`.

Every decision is audit-logged to `~/.claude/hooks/blocked.log`
(timestamp, hashed command, project path, blocked flag, reason).
No plaintext credentials are ever written to disk.

## Installation (2 commands)

```bash
mkdir -p ~/.claude/hooks
cp solution.py ~/.claude/hooks/block_destructive_bash.py
chmod +x ~/.claude/hooks/block_destructive_bash.py
```

Then add to your Claude Code settings (`~/.claude/settings.json`):

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "python ~/.claude/hooks/block_destructive_bash.py"
          }
        ]
      }
    ]
  }
}
```
