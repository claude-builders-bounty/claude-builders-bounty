# Weekly Dev Summary — n8n workflow (GitHub → Claude → Email/Slack)

An importable n8n workflow that posts a weekly narrative summary of a GitHub
repo's activity, generated by the Claude API.

## What it does

1. **Weekly cron** — fires Friday at 17:00 (configurable).
2. **Fetch** — pulls the last 7 days of **commits**, **closed issues**, and
   **merged PRs** from the GitHub REST API.
3. **Aggregate** — merges the three responses into one compact activity object.
4. **Claude** — calls `claude-sonnet-4-20250514` to write a narrative summary.
5. **Deliver** — sends it via **email** *or* a **Slack/Discord webhook**
   (selected by the `DESTINATION` variable).

## Setup (5 steps)

1. **Import** the workflow: in n8n, `⋯ → Import from File` → pick
   `weekly-dev-summary.workflow.json`.
2. **GitHub credential**: create an *Header Auth* credential with
   `Name = Authorization`, `Value = Bearer <YOUR_GITHUB_PAT>` (a classic PAT
   with `repo` scope). Attach it to the three GitHub HTTP nodes.
3. **Anthropic credential**: create an *Header Auth* credential with
   `Name = x-api-key`, `Value = <YOUR_ANTHROPIC_API_KEY>`. Attach it to the
   *Claude: Generate Narrative* node.
4. **Edit the Config node** — set `GITHUB_REPO` (`owner/repo`), `DESTINATION`
   (`email` or `slack`), `EMAIL_TO`, `SLACK_WEBHOOK_URL`, and `LANGUAGE`
   (`EN` or `FR`).
5. **Activate** the workflow (toggle *Active*) and use *Test workflow* /
   *Execute Node* to confirm a run. For email delivery, configure your n8n
   instance's SMTP under *Credentials → Email*.

## Configurable variables

| Variable            | Purpose                                  | Example                          |
|---------------------|------------------------------------------|----------------------------------|
| `GITHUB_REPO`       | Target repository                        | `owner/repo`                     |
| `GITHUB_TOKEN`      | GitHub PAT (via Header Auth credential)  | `ghp_…`                          |
| `DESTINATION`       | `email` or `slack`                       | `email`                          |
| `EMAIL_TO`          | Recipient when `DESTINATION=email`       | `you@example.com`                |
| `SLACK_WEBHOOK_URL` | Webhook when `DESTINATION=slack`         | `https://hooks.slack.com/services/…` |
| `LANGUAGE`          | Summary language                         | `EN` / `FR`                      |
| `ANTHROPIC_API_KEY` | Claude API key (Header Auth credential)  | `sk-ant-…`                       |

## Notes

- The workflow JSON is standard n8n export format (validated: 11 nodes, 9
  connections) and imports cleanly on any recent n8n instance.
- GitHub's unauthenticated rate limit is low; a PAT is required for real use.
- Swap the email node for a Discord webhook by setting `DESTINATION=slack` and
  pasting the Discord webhook URL — the payload is plain `{"text": ...}`.
