# SKILL: Generate Structured CHANGELOG from Git History

Run `/generate-changelog` to generate a CHANGELOG.md from git history.

## Categories
- **Added**: feat, add, new, implement
- **Fixed**: fix, bug, resolve, patch
- **Changed**: change, update, refactor, improve
- **Removed**: remove, delete, drop, deprecate

## Output
Keep a Changelog format with version, date, and commit links.
