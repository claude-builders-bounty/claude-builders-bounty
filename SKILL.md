# Generate Changelog

Automatically generates a structured `CHANGELOG.md` file from git history categorized into Added, Fixed, Changed, and Removed.

## Usage

Run via bash script:
```bash
bash changelog.sh [OUTPUT_FILE]
```

Or invoke via Claude Code:
`/generate-changelog`
