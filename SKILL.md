# Next.js + SQLite CLAUDE.md Template

Production-ready CLAUDE.md for SaaS projects built with Next.js 15 App Router and SQLite.

## What it covers

- Stack & versions (Next.js, better-sqlite3, Zod, Tailwind, Vitest)
- Project structure with route groups and component boundaries
- SQLite conventions (WAL, pragmas, prepared statements, migrations)
- Server vs Client Component rules
- Zod-first validation patterns
- Anti-patterns table with reasoning
- Dev commands and testing patterns

## Usage

Copy `CLAUDE.md` to your project root. Claude Code will read it on startup.

## Customization

- Update the Stack & Versions table for your specific versions
- Add project-specific anti-patterns
- Include your team's naming conventions
