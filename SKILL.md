# Changelog Generator

Generates a structured `CHANGELOG.md` from a project's git commit history. Categorizes commits into sections: **Added**, **Fixed**, **Changed**, **Removed**.

## Usage

```bash
cd /path/to/repo
changelog.sh
# or
bash changelog.sh /path/to/repo
```

## How It Works

1. Reads commits since the last git tag (or full history if no tags exist)
2. Filters out merge commits
3. Classifies each commit by conventional prefix or keyword matching
4. Outputs `CHANGELOG.md` with categorized sections

## Commit Classification Rules

| Prefix / Keyword | Category |
|------------------|----------|
| `feat:`, `add:`, `new:` | **Added** |
| `fix:`, `bug:`, `patch:` | **Fixed** |
| `refactor:`, `update:`, `change:`, `mod:` | **Changed** |
| `remove:`, `delete:`, `drop:`, `deprec:` | **Removed** |
| *(anything else)* | **Changed** |

## Output Format

```markdown
# Changelog

## [v1.2.0] - 2026-05-20

### Added
  - feat: add user authentication

### Fixed
  - fix: resolve memory leak in cache

### Changed
  - refactor: simplify API client

*Generated by changelog.sh*
```

## Requirements

- `git`
- `bash` 4.0+

## Notes

- Merge commits are excluded (`--no-merges`)
- Commit messages are read from the subject line only (first line)
- If no tags exist, uses full commit history
- Non-conventional commits default to **Changed**
