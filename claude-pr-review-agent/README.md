# Claude PR Review Agent

Claude Code PR reviewer that accepts a GitHub pull request URL and returns a structured Markdown review comment.

## Install

```bash
python -m pip install -e ./claude-pr-review-agent
gh auth login
```

Optional for Claude-backed reviews:

```bash
npm install -g @anthropic-ai/claude-code
```

## Usage

```bash
claude-review --pr https://github.com/owner/repo/pull/123
```

The default backend is `auto`: it uses Claude Code when the `claude` CLI is installed, otherwise it falls back to a deterministic heuristic reviewer so CI and local tests still work.

Force Claude Code:

```bash
claude-review --backend claude --pr https://github.com/owner/repo/pull/123
```

Post the review as a PR comment:

```bash
claude-review --backend claude --post-comment --pr https://github.com/owner/repo/pull/123
```

## Output Format

The command returns a Markdown comment with:

- `Summary`: 2-3 concise sentences.
- `Identified Risks`: concrete review risks.
- `Improvement Suggestions`: actionable follow-ups.
- `Confidence`: `Low`, `Medium`, or `High` with a short reason.

## GitHub Action

Copy `github-action/claude-review.yml` into `.github/workflows/claude-review.yml`, then add an `ANTHROPIC_API_KEY` repository secret. The workflow installs Claude Code, runs `claude-review --backend claude`, and posts the review comment using `GITHUB_TOKEN`.

## Claude Code Agent

The sub-agent prompt lives at `.claude/agents/pr-reviewer.md`. It defines the same structured Markdown contract as the CLI prompt and can be reused directly inside Claude Code projects.
