## Summary

Adds a dependency-free Node.js CLI PR review agent for bounty #4.

The CLI accepts a GitHub PR URL or `owner/repo#number`, fetches PR metadata, changed files, and diff text from the GitHub REST API, then prints a structured Markdown review comment.

## What is included

- `claude-pr-review-agent/bin/claude-review.mjs`
  - CLI entrypoint
  - Supports `--pr`, `--out`, and `--help`
  - Uses optional `GITHUB_TOKEN` for higher GitHub API limits
- `claude-pr-review-agent/README.md`
  - Setup, usage, output format, and validation notes
- `claude-pr-review-agent/examples/`
  - Two real PR review outputs generated by the CLI

## Output format

The generated review includes:

- Summary of changes
- Identified risks
- Improvement suggestions
- Confidence score
- Review metadata

## Validation

```bash
node --check claude-pr-review-agent/bin/claude-review.mjs
node claude-pr-review-agent/bin/claude-review.mjs --help
node claude-pr-review-agent/bin/claude-review.mjs --pr https://github.com/rtCamp/nginx-helper/pull/500 --out claude-pr-review-agent/examples/nginx-helper-500.md
node claude-pr-review-agent/bin/claude-review.mjs --pr https://github.com/claude-builders-bounty/claude-builders-bounty/pull/2644 --out claude-pr-review-agent/examples/claude-builders-bounty-2644.md
```

All commands completed successfully.

## Notes

This version keeps automated GitHub comment posting out of scope on purpose. It prints or writes the Markdown review first, which is safer for a first version and avoids duplicate comments. A posting mode can be added later behind an explicit confirmation flag.
