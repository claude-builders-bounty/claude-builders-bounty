# Real PR sample: claude-builders-bounty #10

PR: https://github.com/claude-builders-bounty/claude-builders-bounty/pull/10

## Summary
This PR introduces a Bash `claude-review` command that fetches GitHub PR metadata and diffs, builds a structured review prompt, and invokes Claude Code non-interactively. It also documents installation requirements and includes two sample reviews.

## Risks
- The fallback `|| echo "$PROMPT"` exits successfully with the review prompt when both Claude invocations fail, so callers can receive something that looks like successful output even though no review happened.
- The README says diffs are truncated to 3000 characters, while `head -3000` limits lines rather than characters; a large diff can therefore still create a very large command argument and misleading documentation.
- Model output is not validated before being returned, so missing sections or an invalid confidence value can silently violate the bounty's structured-output contract.
- Metadata extraction adds a `jq` dependency even though the GitHub CLI already returns JSON that can be parsed without another command-line dependency.

## Improvement suggestions
- Fail non-zero when Claude Code cannot run instead of printing the prompt as a success fallback.
- Apply a byte or character limit explicitly and tell the model when the supplied diff was truncated so confidence can reflect missing context.
- Validate the four required sections and confidence enum before printing or posting a review.
- Add automated tests around PR parsing, truncation, failed Claude execution, and malformed model output.
