# Submission handoff

The implementation is ready in this folder. Publishing requires a GitHub
account you control; this session is not signed in and no account or identity
was fabricated.

1. Fork `claude-builders-bounty/claude-builders-bounty` on GitHub.
2. Copy this folder's files into the fork, commit them, and push the branch.
3. Open a pull request against `claude-builders-bounty/claude-builders-bounty` and use `PR_BODY.md` as the description.
4. Comment `/opire try` on issue #1: https://github.com/claude-builders-bounty/claude-builders-bounty/issues/1

The bounty issue states that payment is released automatically on merge. The
generated sample in `examples/CHANGELOG.md` was produced from the real bounty
repository after verifying both an untagged history and a tagged range.
