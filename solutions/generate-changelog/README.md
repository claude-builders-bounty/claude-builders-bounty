# Automatic Changelog Generator

Generates a `CHANGELOG.md` from Git commit subjects after the latest reachable tag. Commits are categorized as **Added**, **Fixed**, **Changed**, or **Removed**, with short commit hashes. Without any tags, all commits are included. The script requires Bash and Git; no API keys, dependencies, or network connection are necessary.

## Setup (3 steps)

1. Download `changelog.sh` into your Git repository (or clone this project).
2. Run `bash changelog.sh` from inside the Git repository, or `bash changelog.sh /path/to/repo`.
3. Open the generated `CHANGELOG.md` in that repository.

## Example

Given a repository tagged `v1.0.0` followed by commits `feat: add invoice export`, `fix: prevent duplicate uploads`, `remove: legacy endpoint`, `docs: clarify setup`, the output contains:

```markdown
# Changelog

## Changes since v1.0.0

### Added

- feat: add invoice export (`<hash>`)

### Fixed

- fix: prevent duplicate uploads (`<hash>`)

### Changed

- docs: clarify setup (`<hash>`)

### Removed

- remove: legacy endpoint (`<hash>`)
```

The file is rewritten on each run to avoid duplicated entries. Conventional Commit prefixes `feat:` and `fix:` are supported, along with readable verbs. All other commit subjects fall under Changed.
