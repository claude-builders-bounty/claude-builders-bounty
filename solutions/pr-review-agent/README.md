# 🔍 Claude Review Agent

A Claude Code agent that analyzes GitHub PR diffs and returns a structured Markdown review.

```bash
claude-review --pr https://github.com/owner/repo/pull/123
```

## Output

Every review includes:
- **📋 Summary** — files changed, additions/deletions, overview
- **🚫 Identified Risks** — security issues, bugs, bad patterns
- **⚠️ Warnings** — code smells, TODOs, potential problems
- **💡 Improvement Suggestions** — actionable recommendations
- **📊 Confidence Assessment** — Low / Medium / High

## Installation (2 commands)

```bash
# 1. Download the script
curl -O https://raw.githubusercontent.com/ktakahiro150397/claude-review/main/claude-review.py
chmod +x claude-review.py

# 2. Set your GitHub token
export GITHUB_TOKEN=ghp_xxx
```

## Usage

```bash
# Review a PR
python3 claude-review.py --pr https://github.com/owner/repo/pull/123

# Save to file
python3 claude-review.py --pr owner/repo/123 -o review.md

# Via GitHub Action (see .github/workflows/review.yml)
```

## GitHub Action

Copy `.github/workflows/review.yml` to your repo to auto-review every PR.

## Requirements

- Python 3.8+
- GitHub token (`GITHUB_TOKEN` or `GH_TOKEN`)
