# CLAUDE.md for Next.js 15 + SQLite SaaS

An opinionated, production-ready CLAUDE.md for a typical Next.js 15 SaaS project with SQLite.

## Usage

Copy CLAUDE.md to the root of your Next.js 15 + SQLite project:

```
cp CLAUDE.md /path/to/your-project/CLAUDE.md
```

Then open the project in Claude Code.

## What's Covered

| Section | Content |
|---------|---------|
| Project Structure | Full directory layout with purpose annotations |
| Naming Conventions | Files, variables, database columns, types |
| Dev Commands | npm scripts for dev, testing, production |
| Patterns to Follow | Server actions, Drizzle queries, error handling |
| Anti-Patterns to Avoid | Common mistakes with rationale |
| Tech Stack | Locked choices with reasoning |
