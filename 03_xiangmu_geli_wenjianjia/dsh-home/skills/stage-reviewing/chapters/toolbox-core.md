# 工具箱：三层结构

## Core Idea
写作工具分三层。金王管他爸的工具箱叫"大家伙"，建议你的写作箱至少四层。词汇放最上层。

**Source**: lines 3525-3740

## Frameworks Introduced

### 三层工具箱
| 层 | 内容 | 核心要点 |
|----|------|----------|
| **最上层** | 词汇、语法、风格要素 | 用得最多、最顺手 |
| **中层** | 段落结构、节奏 | 段落是真正的写作单位 |
| **下层** | 大件工具（不常用但要有） | 比喻、象征、主题意识 |

- 他爸的工具箱有三层，装满约八十斤。他哥问为什么拖整幢房子，他爸答"有备无患"。
- **"必要建造自己的工具箱，然后增强肌肉力量，才能有力气"** [Source: line 3631]
- **"每样工具往工具箱里收的时候再检查一遍"** [Source: line 3643]

## Key Takeaways
1. 词汇不必追求大词，但要准确、顺手
2. 段落才是写作的肌肉——先练好中层
3. 工具不在多，在"有备无患 + 每件都磨锋利"
