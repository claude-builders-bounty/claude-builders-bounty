# Cheatsheet —《写作这回事》决策规则（快查）

## 写作前自问

| 问题 | 是 | 否 |
|------|----|----|
| 门关上了吗？ | → 写 | 先关门 |
| 情境绞紧你了吗（不是情节设计）？ | → 写 | 找"如果"情境 |
| 有具体的理想读者吗？ | → 写 | 先选一个人 |
| 三个月内能写完初稿吗？ | → 写 | 缩小篇幅 |

## 决策规则（If-Then）

- **想写"他生气地说"** → 删"生气地"，让对话自带火气
- **想用"被"字句** → 查主语在不在做事，把施事者前置
- **卡在"情节怎么发展"** → 别设计，回头问"情境里人物现在最想要什么"
- **初稿写完想立刻改** → 埋 6 周冷却，写别的去
- **不确定节奏快慢** → 给理想读者看，问哪段不耐烦
- **想用大词显水平** → 换准确的小词
- **想不出下一章** → 问一个更狠的"如果"

## Tells & Smells（症状 → 诊断）

| 症状 | 诊断 | 处方 |
|------|------|------|
| 满屏"-地说" | 副词依赖 | 蒲公英清除法，动词/对话传情 |
| 连续被动句 | 胆怯遮羞布 | 转主动，施事者前置 |
| 情节线失控 | 硬造情节 | 回到情境，让它自然长 |
| 初稿一直改不完 | 没关门 | 关门，三个月内写完 |
| 读自己的稿子走神 | 缺理想读者 | 给塔碧莎式的人看 |
| 细节贫瘠 | 阅读不够 | 回炉读书，一个月六七种 |

## 修改清单执行顺序

1. **冷却**：初稿埋 6 周
2. **宏观**：情境是否绞紧？故事化石挖完整了吗？
3. **中景**：段落节奏？关门/开门的界限？
4. **微观**：删副词、主动语态、准确词汇
5. **理想读者**：给那一个人看，问节奏和跑题

## 快速自检表（每章写完必过）

- [ ] 副词拔干净了吗？
- [ ] 被动语态转主动了吗？
- [ ] 段落长短有节奏吗？
- [ ] 是情境在推动，不是情节设计？
- [ ] 有写给"那一个人"的感觉吗？
