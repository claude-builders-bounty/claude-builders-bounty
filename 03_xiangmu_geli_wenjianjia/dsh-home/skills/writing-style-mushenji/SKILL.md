# 牧神记文风指纹

> 来源：《牧神记》（宅猪）前 50 万字（约 23 万汉字）
> 适用阶段：novel_pipeline 文风学习阶段（nemotron_humanify.py learn）

---

## 核心语感特征

### 1. 句式节奏
- **长短句交替**：长句铺陈环境/心理/背景，短句推进动作/对话/高潮
- **排比对仗**：常用三段式/四段式排比，增强节奏感
- **倒装/前置**：常将状语/修饰语前置，营造画面感
- **省略主语**：对话/心理活动常省略主语，靠语境推断

### 2. 词汇特征
- **动词密度高**：动词/动词短语占比高，动作感强
- **具体名词**：少用抽象词，多用具体事物/器物/动作
- **方言/口语化标记**：适度保留口语词（"嘛""呢""吧""哈""呦"），增加真实感
- **专有名词密度**：人名/地名/功法/神通/器物名高频出现

### 3. 修辞手法
- **比喻/拟人**：环境描写常用拟人（"黑暗吞噬""石像亮着"）
- **夸张**：关键节点用夸张强化冲击（"石像难以想象的沉重""吞噬山川河流"）
- **拟声/拟态词**："咕噜""嗤嗤""轰隆""叮叮当当"增强临场感
- **反问/自问自答**：心理活动常用自问自答推进心理变化

### 4. 节奏控制
- **环境铺垫 → 事件触发 → 动作爆发 → 心理反应 → 伏笔埋设** 标准四段式
- **段落长度**：描写段 80-200 字，动作段 40-120 字，对话段 20-80 字
- **场景切换**：常用"突然/突然/就在这时/就在这时"等标记硬切

## 场景描写模板

### 环境/氛围描写
```
[宏观环境] + [感官细节] + [人物心理投射] + [伏笔/钩子]
例："夜幕降临，残老村四角的石像又自动亮了起来...黑暗如同潮水飞快的向村子涌来..."
```

### 动作/打斗描写
```
[动作发起] + [感官细节/拟声词] + [力量/速度对比] + [后果/反应] + [心理/台词]
例："秦牧单刀上下翻飞，脚步移动，从向屠夫砍去，刀光越来越快，风声呼啸..."
```

### 心理/内心独白
```
[触发事件] + [直觉反应] + [逻辑推演] + [决策/行动]
例："秦牧脑中轰然，不知道这个从牛皮里钻出来的女子在说些什么。"
```

### 对话/互动
```
[动作/神态] + [口吻标记] + [核心信息] + [钩子/反转]
例：司婆婆瞥他一眼，道："这女子是距离这儿千里外的镶龙城城主夫人..."
```

## 高频句式库（可直接调用）

### 环境开篇
- "天黑，别出门。"
- "夜幕降临，[地点]四角的[物件]又自动亮了起来..."
- "[时间/季节]，[地点][现象]..."

### 事件触发
- "突然，[人物]耳朵动了动，呆了呆，失声道："
- "突然，[现象]..."
- "就在这时，[事件]..."

### 动作推进
- "[人物][动作]，[动作]，[动作]..."
- "[动词][动词][动词]..."
- "只见/只听/只觉/只觉得..."

### 高潮/爆发
- "轰隆/轰隆轰隆/嘭/咔嚓/叮叮当当..."
- "[人物]一拳/一刀/一脚/一掌轰出..."
- "轰隆一声巨响，[后果]..."

### 情感/心理
- "[人物]心中[轰然/一沉/一紧/一跳/一沉]..."
- "[人物]脑中轰然，[心理活动]..."
- "[人物]心中[一凉/一热/一紧/一松]..."

### 伏笔/钩子
- "[人物]心中[纳闷/疑惑/一沉/一紧]..."
- "[人物]心中暗道：[疑问/推测/警告]..."
- "他不知道，[未来事件/真相/反转]..."

## 禁用/避免模式

| 避免模式 | 替代建议 |
|----------|----------|
| 过度解释心理（大段内心独白） | 用动作/对话/环境外化心理 |
| 抽象名词堆砌（"极其痛苦""无比震惊"） | 具象化："心口像被重锤砸中""冷汗瞬间浸湿后背" |
| 被动语态过多 | 主动语态："秦牧挥拳" 而非 "拳头被秦牧挥出" |
| 过多"的/地/得" | 精简修饰，动词前置 |
| 同义词重复 | 建立同义词库轮换 |

## 文风指纹摘要（供模型学习用）

> **牧神记文风 = 环境压抑感 + 动作爽快感 + 群像喜剧感 + 玄幻史诗感**
>
> - **开篇即冲突**：第一章即"天黑别出门"钩子
> - **群像即战力**：每个配角都是战力单位，群像即战力体系
> - **爽点密度高**：平均 3 章一小爽，10 章一大爽，30 章一卷尾
> - **伏笔极深**：看似玩笑/闲聊实为核心伏笔（如"天黑别出门""霸体""村长身份"）
> - **文白对话平衡**：文白约 6:4，对话口吻极强区分度
