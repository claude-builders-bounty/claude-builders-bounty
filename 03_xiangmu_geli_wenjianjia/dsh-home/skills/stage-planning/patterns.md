# Patterns —《故事》设计范式与可复用模板（基于全文实证）

## 1. 激励事件设计模板
**When to use**: 确定故事起点时
**Template**:
```
激励事件类型：[决定/意外/大事件/安静的内在事件]
事件内容：_________________________
打破的平衡：_________________________
创造的 MDQ：主角能否 _________________________ ?
不可逆性验证：[ ] 无法回头 [ ] 赌注足够高
必须在银幕上：[是/否]
世界建立清单：[工作/政治/仪式/价值观/类型/履历/幕后故事/角色设计]
```

## 2. 三幕结构打桩表
**When to use**: 大纲阶段确立骨架
**Template**:
```
第一幕 (25%)：
  - 世界建立：_________________________
  - 主角欲望：_________________________
  - 激励事件：_________________________
  - Plot Point 1：_________________________ (主角主动选择)

第二幕 (50%)：
  - 不归点序列：_________________________ (每越过一个，排除该力度行动)
  - Midpoint 逆转：_________________________ (价值首次大逆转)
  - 复杂型冲突：[内在/个人/社会/环境 同时交织]
  - Plot Point 2 (危机前夜)：_________________________

第三幕 (25%)：
  - Crisis 抉择：_________________________ (两难/两恶之轻，静态定格)
  - Climax 逆转：_________________________ (主角驱动、不可逆、纯粹清白)
  - Resolution 新稳态：_________________________ (回答 MDQ)
```

## 3. 场景设计卡片
**When to use**: 分场大纲阶段，每场一张
**Template**:
```
场景编号：____  位置：[幕/序列]
统一时空：_________________________
场景价值：_________________________ (如：自由 vs 责任)
冲突层级：[内在/个人/社会/环境] (建议同时多层)

节拍追踪 (表面 + 潜文本)：
  Beat 1: Action ___________ → Reaction ___________ 价值微调：____
  Beat 2: Action ___________ → Reaction ___________ 价值微调：____
  Beat 3: Action ___________ → Reaction ___________ 价值微调：____

转折点：_________________________ (价值从 ____ 逆转为 ____)
四重效果：[惊奇/好奇/见识/新方向]
场景结束充电：[正/负]  电量：____/10
推进脊柱：[是/否]  如何推进：_________________________
伏笔埋设：_________________________ (分晓时刻：____)
潜台词核心：_________________________
```

## 4. 反派力量设计表
**When to use**: 设计反派系统时
**Template**:
```
主角核心弱点：_________________________
主角最大恐惧：_________________________

反派力量层级 (必须层层升级，量身定制)：
  社会/制度层：_________________________ (法律/政府/公司/阶级/传统如何施压)
  个人/人际层：_________________________ (谁背叛/对抗/竞争)
  内在/心理层：_________________________ (何种恐惧/缺陷/自我欺骗被激活)
  环境/命运层：_________________________ (自然/疾病/时间/科技如何恶化)

价值负面进展轨迹：
  正面价值：_________________________
  相反价值：_________________________ (不公平/冷漠/善意谎言...)
  矛盾价值：_________________________ (非正义/恨/明目张胆谎言...)
  否定之否定：_________________________ (专制/自厌/自欺...)

反派核心逻辑：反派眼中自己是英雄，因为 _________________________
```

## 5. 人物弧光设计表
**When to use**: 人物档案建立阶段
**Template**:
```
角色名：_________________________
面具期(第一幕)：社会面具 ___________ 防御机制 ___________
剥离期(第二幕)：面具破裂点 ___________ 直面恐惧 ___________
真实期(第三幕)：接纳真相 ___________ 主动选择 ___________

核心矛盾：_________________________ (欲望 vs 恐惧，内部矛盾)
人物塑造 vs 真相对照：_________________________ (外表与内在的反差)
维度矛盾点：_________________________ (深层内部/塑造与真相之间)

控制性思想服务：该角色如何服务/反讽主题 _________________________
```

## 6. 控制性思想验证清单
**When to use**: 大纲完成后、高潮设计前
**Checklist**:
- [ ] 格式："价值 + 原因" (如：正义胜出，因为正直者敢于牺牲)
- [ ] 正负价值明确：正 ___________ 负 ___________
- [ ] 每幕高潮都在论证该命题
- [ ] 高潮是命题的最终验证 (意生情)
- [ ] 无无关支线：所有支线都服务/反讽控制性思想
- [ ] 从尾到头逆向改写：所有场景比照高潮确立存在理由

## 7. 说明/铺垫植入检查
**When to use**: 对白/场景重写时
**Rules**:
- [ ] 无"如你所知"对白
- [ ] 无旁白大段交代
- [ ] 信息作为弹药在关键时刻使用
- [ ] 环境/行为/冲突中自然流露
- [ ] 只给此刻绝对必需的信息
- [ ] 进度：最不重要最先，秘密留最后
- [ ] 幕后故事留到危机/高潮揭示转折

## 8. 场景价值逆转自检
**When to use**: 每场景写完后
**Questions**:
- 场景开始价值：______ (正/负)
- 场景结束价值：______ (正/负)  → 必须相反
- 转折点在哪个节拍？______
- 潜台词是否承载真实逆转？[是/否]
- 是否推进脊柱/MDQ？[是/否]
- 四重效果是否触发？[惊奇/好奇/见识/新方向]

## 9. 对白质量检查
**When to use**: 对白润色时
**Checklist**:
- [ ] 压缩简约：最少词句表达最多内容
- [ ] 方向性：每次交流转折节拍，无重复
- [ ] 目的性：每行执行设计步骤，围绕转折点
- [ ] 结构简单：主谓宾/主谓补，口语化
- [ ] 悬念句：语义压最后一个字
- [ ] 无言优先：能视觉表达绝不写对白
- [ ] 潜台词密度：遮住人名能分辨是谁？台词下真正谈什么？
- [ ] 无"写在鼻子上"：场景不讲它表面讲的东西
