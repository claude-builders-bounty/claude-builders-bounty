# Chapter 11: 场景分析

## Core Idea
用《克拉默夫妇》胸部手术场景为例，演示如何逐节拍分析场景的价值逆转。核心原则：**文本 ≠ 潜文本**，场景若讲它表面讲的东西 = 掉进粪坑。

**Source**: Ch11 (lines 6124-6888)

## Frameworks Introduced

### 文本 vs 潜文本
| 概念 | 定义 | 原文证据 |
|------|------|----------|
| **文本** | 感官表面：影像、对白、音乐、音效、活动、言谈 | "文本是指一部艺术作品的感官表面...是我们所看见的东西，我们所听见的东西" |
| **潜文本** | 表面之下的生活：被行为隐藏的已知/未知思想情感、动作/反应、冲动、伊德、基因/感悟 | "潜文本是指在那一表面之下的生活 —— 被行为隐藏的已知和未知的思想和情感" |

> **铁律**："如果一个场景是讲述那个场景所讲述的东西，那么你算是掉进粪坑里了。" —— 写在鼻子上 = 死场景。

### 烛光晚餐 vs 换轮胎案例 (lines 6200-6300)
- **烛光晚餐**("我爱你"全说出来) = 无潜文本 = 演员拒绝表演 = 死场景
- **换轮胎**（对白全关于千斤顶/扳手/螺母，潜文本是"哥有情妹有意"）= 可表演 = 好场景

### 《唐人街》潜文本分析 (lines 6300-6350)
> **文本**：伊夫林哭喊"她是我妹妹，也是我女儿"
> **潜文本**："求你帮帮我。我丈夫不是我杀的，而是我父亲杀的...如果你逮捕我，他会把孩子抢走"
> **吉提斯回应文本**："我们得让你离开这座城市"
> **潜文本**："我已经理解一切。我爱你，会不惜牺牲救你和孩子。然后去抓那个狗杂种"

### 《星球大战》潜文本 (lines 6350-6380)
> **文本**：维达邀请卢克"共同治理宇宙恢复秩序"
> **潜文本**："奴役万民"
> **卢克反应**：企图自杀（非逻辑但合情理）
> **潜文本**："我宁死不加入你的邪恶事业"

### 场景分析五步法 (lines 6400-6550)
| 步骤 | 动作 | 关键点 |
|------|------|--------|
| **1. 确定冲突** | 谁驱动场景？想要什么？对抗力量想什么？用目的状语表述 | "为了做这个..." / "为了不做那个..." 冲突双方必须直接相对 |
| **2. 标注开篇价值** | 确认押上台面的价值，注意开始时正/负 | "自由。主人公处于负面，被囚禁于执着野心" |
| **3. 分解节拍** | 从两层审查：表面做什么 + 潜文本实际在做什么 | 用进行时短语："正在乞求"、"正在对其恳求置之不理" |
| **4. 标注结尾价值** | 场景结束时价值正/负，必须与开篇相反 | 正→负 或 负→正 |
| **5. 评估转折点** | 识别价值逆转的节拍，验证是否推进脊柱 | 转折点 = 价值逆转时刻 |

### 节拍表达原则
- **不是字面描述活动**，而是带情感色彩指称动作本质
- "正在恳求" = 庄重感；"趴在脚下" = 绝望卑躬屈膝
- 动作/反应交流 = 一个节拍

## Key Takeaways
1. **文本只是面具，潜文本才是真相** —— 永远要有与文本对照/矛盾的内在生活
2. **场景分析 = 解剖节拍层面的价值微调**，累积成大逆转
3. **潜台词密度 = 人设厚度 = 观众粘性**
4. **好演员绝不无潜文本上镜头** —— 他们会自己加，甚至与故事无关
