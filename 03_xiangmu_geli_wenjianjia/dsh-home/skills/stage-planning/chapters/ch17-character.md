# Chapter 17: 人物

## Core Idea
**人物在压力下的选择揭示真实本质**。人物弧光 = 压力下选择的累积轨迹。心灵虫 = 作家潜入人物心灵创造符合其本性的激励事件。

**Source**: Ch17 (lines 8965-9308)

## Frameworks Introduced

### 心灵虫隐喻 (lines 8970-9000)
> **作家 = 心灵虫**。潜入人物大脑，完全了解梦/恐惧/优点/弱点，创造符合其本性的事件，送上求索之路，迫使竭尽全力，揭示人性。

### 人物不是真人 (lines 9000-9030)
> 米洛的维纳斯不是真女人，人物也不是真人。**人物 = 对人性的比喻，艺术品，永恒不变，比朋友更了解**。里克永远是里克，我自己却不确定。

### 人物设计双重起点
| 方面 | 含义 |
|------|------|
| **人物塑造** | 可观察素质总和：外表、行为举止、语言风格、性别、年龄、智商、职业、个性、态度、价值观、住哪、住得怎样 |
| **人物真相** | 面具之下：忠诚/不忠、诚实/虚伪、爱心/冷酷、勇敢/怯懦、慷慨/自私、意志坚强/脆弱 |

### 人物真相只能通过两难选择表达 (lines 9030-9060)
> **压力越大，选择越能揭示真实**。问："我想要什么？" → 倾听诚实回答 → 找到追求意志。

### 欲望与动机
| 概念 | 核心观点 |
|------|----------|
| **欲望** | 自觉 + 不自觉。明确真实的答案伴随对角色把握而来 |
| **动机** | 不要简化为单一原因(虐待童年/基因/魔鬼附体) —— 动机是多种复杂力量综合。固着具体原因 = 缩减人物形象。留神秘色彩，给观众想象余地 |

### 人物维 = 矛盾 (lines 9080-9150)
> **维 ≠ 怪癖堆砌** (杰西=股票专家+霹雳舞+空手道+萨克斯 = 平板)
> **维 = 矛盾**：
> - 深层性格内部：负疚沉重的野心 (麦克白)
> - 人物塑造与深层性格之间：魅力四射的小偷
> - 必须连贯一致

**哈姆雷特 = 十维/十二维/数不清维**：
信神/渎神、爱/虐待、果敢/怯懦、冷静/冲动、无情/有情、孤傲/自怜、机智/悲哀、倦怠/活泼、清醒/迷茫、明白/疯狂、纯真世俗/世俗纯真

### 人物设计 = 太阳系 (lines 9180-9250)
> **主人公 = 太阳**，配角 = 行星，小角色 = 卫星
> 全部被主人公引力固定轨道，刻画其复杂维度
> - 人物A 招致悲伤/愤世嫉俗
> - 人物B 引出机智/希望
> - 人物C 激发爱心/勇气
> - 人物D 迫使恐惧退缩 → 愤激反抗
> A/B/C/D 存在完全由主人公需要决定

### 小角色原则
- 故意轻描淡写，但不呆板
- 给一个令人耳目一新的特征，值得演员表演那一刻
- 别比必要更有趣 → 虚假预期
- 如果不再出现至少一次 → 观众愤恨

## Key Takeaways
1. **人物不是标签，是压力下的选择累积**
2. **弧光 = 面具剥离过程**，不是性格突变
3. **核心矛盾（欲望 vs 恐惧）驱动弧光**
4. **全体人物围绕主人公旋转**，刻画其矛盾维度
