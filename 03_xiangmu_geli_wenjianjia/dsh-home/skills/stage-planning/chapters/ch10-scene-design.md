# Chapter 10: 场景设计

## Core Idea
场景是**通过冲突在统一时空中发生的行动**，改变角色生活的价值充电状态。**每个场景必须是一个转折点**。

**Source**: Ch10 (lines 5603-6123)

## Frameworks Introduced

### 场景的定义
- **统一时空**：一个地点，连续时间 (lines 5610-5630)
- **冲突驱动**：没有冲突 = 没有场景
- **价值变化**：场景开始和结束时，角色的价值充电状态必须不同（正→负或负→正）

### 转折点的四重效果 (lines 5650-5720)
| 效果 | 说明 |
|------|------|
| **惊奇** | 期望与结果裂开鸿沟，观众大吃一惊 |
| **好奇** | "为什么？" 记忆回溯搜寻答案 |
| **见识** | 理解深化，"啊，原来如此" |
| **新方向** | 故事向新方向运行 |

### 伏笔与分晓 (lines 5750-5850)
- **铺设伏笔** = 将知识一层层铺垫好
- **分晓** = 将铺设的知识传达给观众以闭合鸿沟
- 伏笔必须：第一次看有意义，见解搜寻后赋予第二/三/四层更重要意义

### 自我表达问题 (lines 5850-5920)
> **自我表达只能产生于从转折点中喷涌而出的见解洪流**，语言只是工具。

> **讲故事就是许诺**：注意听 → 给惊奇 → 发现生活的喜悦 → 在未想象层面探知喜怒哀乐。

### 场景设计案例 (lines 5630-5750)
| 影片 | 场景价值 | 转折过程 |
|------|----------|----------|
| **《颠倒乾坤》** | 财富 | 乞丐→代理人，轻松转折 |
| **《华尔街》** | 财富+真诚 | 诚实推销→加入非法阴谋，真诚→罪犯 |
| **《克拉默夫妇》** | 成熟/责任 | 不会做早饭→成长为大男人 |
| **《星球大战2》** | 身份/命运 | "我是你父亲" → 三年前内容重组 |
| **《唐人街》** | 真相/亲情 | "她是妹妹也是女儿" → 父女乱伦真相 |

## Key Takeaways
1. **无价值变化 = 无场景** —— 填充材料必须剪掉
2. **场景 = 转折点** —— 每个场景都要让价值翻转
3. **伏笔 = 见解的预埋**，分晓 = 闭合鸿沟
4. **语言是工具，转折点才是自我表达**
