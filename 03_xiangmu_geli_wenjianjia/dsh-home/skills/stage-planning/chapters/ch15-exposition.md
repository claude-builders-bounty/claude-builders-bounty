# Chapter 15: 解说

## Core Idea
说明/铺垫必须**暗藏、不显山露水**。最好的说明是观众在不知不觉中获得信息，感觉自己"发现"的。核心原则：**展示，不要告诉**。

**Source**: Ch15 (lines 7882-8209)

## Frameworks Introduced

### 说明的三大原则
| 原则 | 实操 | 原文证据 |
|------|------|----------|
| **作为弹药** | 信息在关键时刻被当作武器使用，而非随意倾倒 | "把解说转化为弹药...让他们把自己所知道的东西用作弹药来进行斗争" |
| **展示而非讲述** | 用行为/对白/环境暗示，不用旁白/对白直说 | "展示，不要告诉...向我们展示出诚实而自然的场景" |
| **必要性最小化** | 只给观众"此刻绝对需要知道"的最少信息 | "切勿将观众通过常理便能轻易推断出已经发生的事情包括在故事之中" |

### 说明植入技巧
| 技巧 | 说明 | 原文案例 |
|------|------|----------|
| **对白冲突中植入** | 争吵时自然说出过往 | 杰克对哈里："还是过去那种嬉皮士发型，没到中午就打蔫儿，净整一些小青年的勾当，二十年前你不就是为这被人踹出学校大门的吗？" |
| **环境叙事** | 道具/布景/细节暗示 | 墙上褪色的奖状暗示昔日荣光 |
| **延迟揭示** | 先制造悬念，后给答案 | "那个盒子里是什么？" → 第三幕打开 |
| **作为武器呈现** | 关键时刻主角用所知信息反击 | 律师在法庭上甩出关键证据 |

### 说明的禁忌
| 禁忌 | 后果 | 原文案例 |
|------|------|----------|
| **旁白大段交代** | 观众脱离沉浸，感到被说教 | 《恐怖地带》：丹尼尔斯对助理详细解说厄波拉病理知识 |
| **"如你所知"对白** | 角色说双方都知的事 = 假对白 | 杰克："咱们都他妈认识多少年了？二十年了吧？" |
| **信息倾倒** | 破坏节奏，杀死悬念 | "加州场景"：两陌生人喝咖啡互吐阴暗秘密 |

### 说明进度原则
> **最不重要的事实最先出现，最重要的秘密留到最后**。秘密 = 人物最不想让人知道的痛苦真相。

### 幕后故事的使用 (lines 8050-8150)
> 只有两种方法转折场景：**动作** 或 **揭示**。
> 强有力的揭示来自幕后故事 —— 留到危机时刻披露，创造转折点。
> - 《唐人街》："她是妹妹也是女儿" 留到二幕高潮
> - 《星球大战2》："我是你父亲" 留到高潮

### 传记性解说的处理
- 贯穿终生的故事脊柱罕见 → 遵从亚里士多德："从事情的中间开始"
- 高潮在35岁 → 生日前一个月开始 → 给35年人生构筑价值
- 无家可归酒鬼没赌注 = 静态肖像 → 选有所可失之人

## Key Takeaways
1. **说明 = 弹药**，留到关键时刻开火
2. **展示 > 讲述**，环境/行为/冲突中自然流露
3. **少即是多**，只给此刻必需的信息
4. **幕后故事 = 转折点的核弹**，留到最后
