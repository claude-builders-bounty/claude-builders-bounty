# Chapter 9: 幕设计

## Core Idea
经典三幕结构：**Setup(铺垫) → Confrontation(对抗) → Resolution(结局)**。每一幕以价值重大逆转为界。进展纠葛 = 越过一个个"不归点"。

**Source**: Ch9 (lines 5006-5602)

## Frameworks Introduced

### 三幕结构表
| 幕 | 名称 | 核心任务 | 关键节点 | 价值变化 |
|----|------|----------|----------|----------|
| **第一幕** | Setup (铺垫) | 建立世界、主角、欲望、激励事件 | **Plot Point 1**：主角主动选择跨入第二幕 | 平衡 → 失衡 |
| **第二幕** | Confrontation (对抗) | 正反派交锋、中点逆转、主角被逼至极限 | **Midpoint**：价值首次大逆转 → **Plot Point 2**：危机决策 | 正负多次翻转 |
| **第三幕** | Resolution (结局) | 危机决策 → 高潮 → 新平衡 | **Crisis** → **Climax** → **Resolution** | 终极逆转 → 新稳态 |

### 进展纠葛的核心机制：不归点 (lines 5020-5100)
> **激励事件把主人公送上求索之路 → 最小行动 → 结果激发对抗力量 → 期望与结果开掘鸿沟 → 这是不归点 → 必须采取更大行动 → 新鸿沟 → 新不归点 → 循序渐进直到终点**

> **故事绝不能退隐于轻量级行动，而必须循序渐进地朝着观众无从想象出更好替代的一个最后行动向前运行。**

### 典型片长结构
- 四十到六十个场景
- 组合成十二到十八个序列
- 构建为三个或更多幕
- 力度一个强似一个，循序渐进

### 冲突法则 (lines 5100-5250)
> **若无冲突，故事中的一切都不可能向前进展。冲突之于故事讲述，犹如声音之于音乐。**

> **生活中冲突的数量是常量** —— 从一个层面拿掉，另一个层面放大十倍。无聊 = 冲突本身的缺乏。

### 纠葛型 vs 复杂型 (lines 5250-5400)
| 类型 | 冲突层面 | 特征 |
|------|----------|------|
| **纠葛型** | 仅一个层面(内在/个人/社会/环境) | 人物庞大、多场地、场景重复单一层面冲突 |
| **复杂型** | 同时三层面冲突 | 《克拉默夫妇》法式烤面包场景：自信/孩子信任/家庭生存三重价值同时转折 |

### 复杂型案例：《克拉默夫妇》法式烤面包 (lines 5350-5450)
> 场景开始三价值皆正面：
> - 内在：克莱默怀疑/傲慢 vs 自信
> - 个人：儿子歇斯底里 → 相信父亲许诺
> - 外在：厨房如外星世界 → 摆法国大厨架势
> 转折：油太大 → 鸡蛋洒出 → 儿子哭 → 父亲吼 → 价值全翻负面

## Key Takeaways
1. 每一幕的高潮都是**价值的重大逆转**
2. 第二幕最长、最难写，需用 Midpoint 和 Plot Point 2 打桩
3. **不归点 = 进展的铁律** —— 绝不回退到已失败的行动力度
4. **冲突是常量**，层层升级才是进展
5. 复杂型 > 纠葛型 —— 三层面同时交织
