# Chapter 5: 结构与人物

## Core Idea
**人物即结构**。人物不是结构的装饰，人物的选择在压力下构建结构。结构是人物选择的外化。

**Source**: Ch5 (lines 2509-2773)

## Frameworks Introduced

### 人物即结构
- **结构 = 人物在压力下做出的选择序列** (lines 2520-2540)
- 没有独立的"结构"再套用"人物"，两者是同一枚硬币的两面
- **压力揭示真实本质**：压力越大，选择越能暴露人物深层本质 (lines 2540-2580)

### 人物 VS 人物塑造
| 概念 | 定义 | 原文证据 |
|------|------|----------|
| **人物塑造** | 一切可观察素质总和：年龄、智商、性别、语言风格、房子、车、职业、性格、价值观... | "人物塑造是一切可以观察到的人的素质总和...这种各种特质的独一组合便是人物塑造…… 但这不是人物" |
| **人物真相** | 在压力下做选择时揭示的深层本性：爱心/残酷、慷慨/自私、勇猛/懦弱... | "人物性格真相在人处于压力之下做出选择时得到揭示 —— 压力越大，揭示越深" |

### 核心原则：压力是根本
> **在没有任何风险的情况下做出的选择意义甚微。如果同样一个人物在说谎可以保全他性命的情况下依旧坚持讲真话，那么我们便能感受到诚实是其性格的核心。** (lines 2560-2580)

### 双车对撞案例 (lines 2580-2680)
> 清洁工(非法移民) vs 神经外科大夫，面对校车起火救人。**人物塑造截然相反，但压力下可能揭示相同人性，或截然不同的本性**。这就是"人物塑造 ≠ 人物真相"的铁证。

### 人物弧光 (lines 2680-2740)
> **哈姆雷特五步弧光**：
> 1. 人物塑造：悲伤王子
> 2. 选择揭示真实：睿智谨慎，决定复仇但等证据
> 3. 内在与外在冲突/对照："天上刮着西北风，我才发疯"
> 4. 压力升级：国王祈祷时可杀却不杀，等他下地狱
> 5. 高潮：平和成熟境界，"此外仅余沉默而已"

### 结构与人物的功能互锁
| 维度 | 说明 |
|------|------|
| **结构功能** | 提供不断加强的压力，逼向越来越困难的两难之境 |
| **人物功能** | 带来人物塑造素质，让选择令人信服地表现 |
| **互锁** | 改变事件设计 = 改变人物；改变人物深层性格 = 必须再造结构 |

### 类型适配复杂度
| 类型 | 人物复杂度要求 | 原因 |
|------|----------------|------|
| 动作/探险/滑稽剧 | 简单 | 复杂性分散注意力 |
| 教育/赎罪/内心冲突 | 复杂 | 简单化剥夺人性洞察 |

## Key Takeaways
1. **人物不是填入结构的模块，人物的选择就是结构**
2. **压力是试金石，越大的压力揭示越深的真实**
3. **被动主角 = 结构崩塌，必须让主角主动出击**
4. **人物复杂度必须与类型适配**
