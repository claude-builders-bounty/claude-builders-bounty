# Chapter 18: 文本

## Core Idea
**潜台词才是冰山本体**。显性(说出) < 隐性(有意隐藏) < 潜台词(真实思想/潜意识)。对白只是冰山一角。电影=视觉80%+听觉20%，戏剧相反。

**Source**: Ch18 (lines 9309-9864)

## Frameworks Introduced

### 三层沟通模型
| 层级 | 含义 | 可见性 | 原文证据 |
|------|------|--------|----------|
| **显性** | 说出口的台词 | 10% | "所言和所行并不是所思和所感" |
| **隐性** | 有意识隐藏的思想/情感 | 20% | "人们总是会另有所指。在说出的东西后面总是隐藏着不能说出的东西" |
| **潜台词** | 真实思想、潜意识冲动、未察觉的欲望 | 70% | "潜文本是指在那一表面之下的生活" |

### 潜台词的表达方式
| 方式 | 说明 | 原文案例 |
|------|------|----------|
| **反话** | 说反面意思 | "干得好啊" (实际: 干得烂) |
| **隐喻/暗示** | 用别的事物指代 | "这杯咖啡真苦" (暗示: 这段关系让人痛苦) |
| **沉默/停顿** | 不说话最有力 | 关键问题后的长久沉默 |
| **行为反差** | 说一套做一套 | 说"我不在乎" 却紧握拳头 |
| **潜台词对白** | 对白表面谈A，实谈B | 谈论"修屋顶" 实谈"修补关系" |

### 写潜台词的实操四步
1. **先写显性** —— 角色想说什么
2. **挖隐性** —— 角色不敢说/不想说什么
3. **挖潜台词** —— 角色自己都不承认的真实欲望/恐惧
4. **重写对白** —— 让显性承载潜台词，而非直接说出

### 对白铁律 (lines 9330-9420)
| 法则 | 说明 | 原文证据 |
|------|------|----------|
| **压缩和简约** | 最少词句表达最多内容 | "银幕对白必须以最少的词句表达最多的内容" |
| **具有方向** | 每次交流转折节拍，表达行为变化，无重复 | "对白的每一次交流都必须将场景中的节拍向一个或另一个方向转折" |
| **有目的** | 每行台词执行设计步骤，围绕转折点构建弧光 | "每一行台词...都要执行设计中的一个步骤" |
| **结构简单** | 主谓宾/主谓补，口语化 | "言如常人，思若智者" |
| **悬念句** | 语义延缓到最后一个字 | "如果你不想让我干，那你为什么要给我那个……" |
| **无言优先** | 能视觉表达绝不写对白 | "形象是我们的第一选择，对白是令人遗憾的第二选择" |

### 《莫扎特传》萨利埃里忏悔案例 (lines 9400-9450)
> 用默默反应分割对白，构建动作/反应型式：
> - 萨利埃里："我一直想向上帝歌唱...为什么？"
> - 牧师眼望别处、痛苦尴尬 → 萨利埃里恳切回答自己问题
> - 括弧标注潜文本："(为他自己的措辞感到得意)"、"牧师抬起眼皮，表情庄严如判官"

### 《沉默》伯格曼服务员案例 (lines 9480-9520)
> **文本写法**：服务员推荐菜、聊天、搭讪 = 说呀说
> **伯格曼写法**：服务员故意掉餐巾 → 弯腰捡时从头嗅到脚 → 安娜长气 → 切入：旅馆房间
> **纯视觉，零对白，完美银幕剧作**

### 描写原则 (lines 9520-9620)
| 原则 | 实操 | 原文 |
|------|------|------|
| **只描可拍摄的** | "他坐了很久" → "掐灭第十支烟/焦躁看表/打哈欠强迫不睡" | "人类语言90%在银幕找不到等同物" |
| **现在时生动动作** | 绝对现在时，生动运动 | "银幕本体论是处于连续生动运动中的绝对现在时" |
| **具体名词/动词** | "大钉子" → "尖铁钉"；"慢慢移动" → "pads/ambles/strolls/saunters/tiptoes/creeps" | "名词是物体名称；动词是动作名称" |
| **无修饰语** | 回避泛指名词、带修饰动词 | "努力寻找事物的具体名称" |

### 形象系统 (lines 9620-9750)
> 镶嵌在话语中的语言形象 → 最终构成电影形象，丰富意义情感
> - 象征/隐喻/提喻/转喻等修辞 → 服务于视觉化
> - 不是文学装饰，是电影图像的种子

### 片名 (lines 9750-9864)
> 片名 = 核心意象的浓缩。好片名能引导观众预期，坏片名误导。

## Key Takeaways
1. **对白只是冰山一角，潜台词是本体** (70%)
2. **好对白 = 表面谈 A，实质谈 B**
3. **形象第一，对白第二** —— 能视觉表达绝不写对白
4. **描写只写可拍摄的**，现在时，具体名词动词
5. **悬念句** = 语义压在最后一个字
