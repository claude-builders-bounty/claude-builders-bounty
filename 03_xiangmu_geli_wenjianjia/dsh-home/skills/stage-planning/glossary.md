# Glossary —《故事》核心术语中英对照（按章节标注）

## 结构谱系 (Ch2)
- **Archplot (大团结构/经典设计)** — 单一主角、因果闭环、三幕线性、封闭式结局、外在冲突主导.
- **Miniplot (小团结构/极简主义)** — 多主角、开放式结局、内在冲突为主、时间可非线性.
- **Antiplot (反结构/反传统)** — 打破因果/时间/现实、实验性、反讽.

## 结构单位 (Ch2)
- **Event (事件)** — 意味着变化，通过价值表达，通过冲突完成.
- **Story Value (故事价值)** — 人类经验中可从正转负的二元特质（生/死、爱/恨、自由/奴役）.
- **Scene (场景)** — 统一时空中通过冲突发生的动作段，至少一个价值层面转折.
- **Beat (节拍)** — 场景内最小单位，Action/Reaction 行为交替.
- **Sequence (序列)** — 2-5 场景串联，以更大逆转为高潮.

## 背景四维 (Ch3)
- **Period (时代)** — 故事在时间中的位置.
- **Duration (期限)** — 故事在时间中的长度.
- **Location (地点)** — 故事在空间中的位置.
- **Level of Conflict (冲突层面)** — 内在/人际/社会/环境.

## 研究与创作 (Ch3)
- **记忆研究 / 想象研究 / 事实研究** — 三大调查研究法.

## 类型 (Ch4)
- **Genre (类型)** — 观众预期的契约，表层/结构/深层惯例.
- **时代置换** — 用历史背景映照当代问题.

## 人物 (Ch5, Ch17)
- **Characterization (人物塑造)** — 可观察素质总和.
- **Character (人物真相)** — 压力下选择揭示的深层本性.
- **心灵虫** — 作家潜入人物心灵创造激励事件的隐喻.
- **维** — 矛盾（深层内部/塑造与真相之间），非怪癖堆砌.

## 意义 (Ch6)
- **Controlling Idea (控制性思想/主控思想)** — "价值 + 原因"，故事因果论证的结论.
- **Premise (前提)** — "如果...会发生什么？" 开放式灵感.
- **审美情感** — 思想与情感同时接触的艺术体验.

## 故事材质 (Ch7)
- **Desire (欲望)** — 有意识/无意识/超目标.
- **Spine (脊柱/故事脊椎)** — 欲望→反派力量→行动→结果的因果链.
- **Gap (鸿沟/缺口)** — 期望与结果的差距，故事能量源.
- **Antagonism (反派力量/对抗力量)** — 阻碍主角欲望的一切力量总和.
- **Empathy (移情)** — "像我"，观众认同深层性格.
- **Sympathy (同情)** — 可爱，可有可无.

## 幕设计 (Ch9)
- **Inciting Incident (激励事件)** — 打破主角生活平衡的事件.
- **MDQ (主要戏剧问题)** — "主角能否实现欲望？" 故事导航仪.
- **Plot Point 1 (第一情节点)** — 主角主动选择进入第二幕.
- **Midpoint (中点)** — 第二幕中点，价值首次大逆转.
- **Plot Point 2 (第二情节点)** — 危机前夜，最艰难抉择.
- **不归点** — 已失败行动力度永不回退的进展铁律.
- **纠葛型 / 复杂型** — 单层面 vs 三层面同时冲突.

## 场景设计 (Ch10, Ch11)
- **Turning Point (转折点)** — 价值发生逆转的时刻.
- **Setup / Payoff (伏笔 / 分晓)** — 铺设知识 → 闭合鸿沟.
- **Text / Subtext (文本 / 潜文本)** — 感官表面 vs 隐藏的思想情感.
- **情感充电** — 场景结束时的正/负电量.

## 危机高潮结局 (Ch13)
- **Crisis (危机)** — 极限压力下的抉择，揭示本质.
- **Climax (高潮)** — 绝对不可逆的价值逆转.
- **Resolution (结局)** — 新稳态，回答 MDQ.
- **螺旋式高潮** — 多重危机决定层层产生.
- **意生情** — 意义产生情感，高潮核心原则.

## 反派 (Ch14)
- **反派力量四层级** — 社会/个人/内在/环境.
- **价值负面进展** — 正面 → 相反价值 → 矛盾价值 → 否定之否定.
- **否定之否定** — 双重负面，人性黑暗极限（专制/自厌/自欺）.

## 解说 (Ch15)
- **展示，不要告诉** — 戏剧化解说，作为弹药使用.
- **幕后故事** — 过去重大事件，留到危机时刻揭示转折.
- **加州场景** — 陌生人互吐隐私的虚假解说.

## 问题与解决 (Ch16)
- **善之中心** — 移情锚点，必须在主角身上.
- **神秘 / 悬念 / 戏剧反讽** — 观众知情度三种关系.
- **熏鲱鱼** — 神秘类型中误导观众的虚假线索.

## 文本 (Ch18)
- **Subtext (潜台词)** — 真实思想/情感，隐藏在显性对白之下，占 70%.
- **悬念句** — 语义压在最后一个字.
- **形象系统** — 镶嵌在语言中的电影图像种子.
- **只描可拍摄的** — 描写原则：现在时、具体名词动词、无修饰语.

## 作家方法 (Ch19)
- **从里到外** — 步骤大纲→梗概→处理台本→初稿→重写.
- **从外到里** — 直接写对白描写，故事松散.
- **步骤大纲** — 3x5卡片，逐场单句，背面标注幕/序列.
- **处理台本** — 60-90页，逐刻描写+全套潜文本，不写对白.
- **关门写初稿，开门改重写** — 快写慢改.
