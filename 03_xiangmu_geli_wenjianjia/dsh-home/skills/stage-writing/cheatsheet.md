# Cheatsheet —《叙事技巧指南》决策规则（快查）

## 写作前自问

| 问题 | 是 | 否 |
|------|----|----|
| 知道在"展现"不是"讲述"吗？ | → 写 | 先查细节三要素 |
| 视角四维定好了吗？ | → 写 | 先定四维 |
| 人物五维体检过了吗？ | → 写 | 先补档案 |
| 知道情节因果链吗？ | → 写 | 先画冲突-危机-结局 |

## 决策规则（If-Then）

- **想写"他很生气"** → 改展现："他关上门，门框震了三下"
- **想用被动语态** → 改主动，施事者前置
- **想用形容词堆情感** → 找客观对应物(物/场景/事件链)
- **想写人物小传** → 别写，扔进情境看反应
- **想预设情节** → 别设，设计情境让人物自己爬出来
- **对话含发现/决定/戏剧行为** → 必须直接引语
- **对话是闲聊/过渡** → 用概括性对话压缩
- **想表达情感** → 禁形容词，找客观对应物
- **卡住了** → 问"视角四维哪里卡住了？" 或 "人物现在最想要什么？"

## Tells & Smells（症状 → 诊断）

| 症状 | 诊断 | 处方 |
|------|------|------|
| "他很生气/房间很乱/她很漂亮" | 讲述成瘾 | 强制转展现(细节三要素) |
| 被动语态密集 | 力量流失 | 全改主动，施事者前置 |
| 形容词堆情感 | 情感空心化 | 找客观对应物 |
| 人物像功能符号 | 缺五维档案 | 补可信/意志/复杂/变化/群体 |
| 视角在头里跳 | 头跳(大忌) | 定四维、标记跳跃 |
| 情节像流水账 | 缺因果链 | 画冲突-危机-结局三角 |
| 主题生硬/说教 | 硬贴标签 | 完稿问"在说什么"回头强化 |
| 细节全是抽象词 | 细节三要素缺失 | 强制五感+具体名词动词 |

## 阈值与默认

- **视角跳跃**：同场景最多 1 次，且需空行/章节标记
- **对话层级**：含发现/决定/戏剧行为 = 必须直接引语
- **修改顺序**：宏观 → 中景 → 微观 → 主题（严禁跳步）
- **重读标记**：四色(困惑/不信/啰嗦/慢/扁平)全覆盖
- **类型承诺**：读者知道买什么，必须兑现

## 修改清单执行顺序（严禁跳步）

1. **宏观**：因果链完整？人物弧光闭环？视角一致？
2. **中景**：场景有转折？节奏服务情绪？对话推进冲突？
3. **微观**：删副词、主动语态、精准名词、展现细节
4. **主题**：问"在说什么" → 删不服务/强服务/植入象征

## 快速自检表（每章写完必过）

- [ ] 全程"展现"无"讲述"？
- [ ] 视角四维全程一致？
- [ ] 主要人物五维档案全？
- [ ] 情节因果链无断裂？
- [ ] 对话层级用得当？
- [ ] 客观对应物替代了情感形容词？
