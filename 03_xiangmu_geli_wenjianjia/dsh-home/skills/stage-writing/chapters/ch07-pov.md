# Chapter 7: "请叫我以实玛利"——叙述视角

## Core Idea
视角不是选人称，是选**四维坐标**：谁在说、对谁说、以什么形式、以多远距离。**一致性是铁律**。

**Source**: lines 8667-9815

## Frameworks Introduced

### 视角四维坐标
| 维度 | 选项 | 核心差异 |
|------|------|----------|
| **谁在说** | 第一人称 / 三人称 | "我" vs "他/她" |
| **对谁说** | 读者 / 特定对象 / 自己 | 叙述契约 |
| **以什么形式** | 日记 / 书信 / 口述 / 标准叙述 | 载体决定质感 |
| **以多远距离** | 全知 → 限知 → 客观（行为主义） | 离内心多远 |

> **头跳 = 大忌**——同场景内不许在不同人物头里跳，必须标记清晰（空行/分章）。

### 视角选择的实操
- 第一人称：天然亲密、内在深度，但只能展现"我知道的"
- 三人称限知：最通用、可进可退
- 三人称全知：神视角，需极强控制力
- 客观/行为主义：只写看得见、听得到的，零内心

## Key Takeaways
1. 定视角 = 锁四维坐标，全程一致
2. 视角决定读者"离主角内心多远"
3. 想写深度内心选第一/限知；想写全景选全知/客观
