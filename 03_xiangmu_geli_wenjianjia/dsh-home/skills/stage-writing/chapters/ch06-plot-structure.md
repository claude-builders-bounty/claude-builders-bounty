# Chapter 6: 塔和网——情节与结构

## Core Idea
情节 = 因果链（为什么发生）；故事 = 时间顺序（发生了什么）。结构 = **塔（垂直冲突升级）+ 网（水平多线程）**。核心三角：**冲突 → 危机 → 结局**。

**Source**: lines 7158-8666

## Frameworks Introduced

### 情节三角
| 节点 | 核心 |
|------|------|
| **冲突** | 欲望遇阻（内在/外在） |
| **危机** | 冲突升到顶点，必须抉择 |
| **结局** | 危机之后的结果（解决或更深的冲突） |

### 塔与网
- **塔（垂直）**：冲突层层升级，危机比前一个更高、更重
- **网（水平）**：多条支线并行，交织成完整图景
- 长篇小说需要塔+网；微小说在极小空间里速成三角

## Key Takeaways
1. 故事没有冲突/危机/结局 = "有诱人之处，还称不上故事"（编辑拒稿常用语）
2. 冲突不一定要外在爆炸，内在挣扎同样可造危机
3. 长篇的网：多线程并行，关键节点汇入主塔
