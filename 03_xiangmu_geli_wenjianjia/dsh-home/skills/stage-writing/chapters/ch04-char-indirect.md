# Chapter 4: "有血有肉"——人物塑造（二）间接表现与深度

## Core Idea
直接表现不够，还需间接表现补全：**作者阐释**、**其他角色阐释**。深度人物五维：可信性、意志、复杂性、变化、群体互动。

**Source**: lines 4974-6176

## Frameworks Introduced

### 间接表现两法
| 方法 | 说明 | 风险 |
|------|------|------|
| **作者阐释** | 作者直说人物是怎样的 | 滑向"讲述"、破坏"展现" |
| **其他角色阐释** | 借他人之口评价 | 读者可能认同也可能不认同 |

### 深度人物五维
| 维度 | 含义 |
|------|------|
| **可信性** | 行为前后一致、动机可信 |
| **意志** | 有想要的东西、会行动 |
| **复杂性** | 内在矛盾、不止一面 |
| **变化** | 随故事有所改变/弧光 |
| **群体互动** | 与其他人物的化学反应 |

## Key Takeaways
1. 作者阐释最省事但最危险——能用"展现"就别用"讲述"
2. 他人阐释要选对观察者，读者可能认同也可能否定
3. 扁平人物 = 缺意志/缺复杂/缺变化的单一符号
