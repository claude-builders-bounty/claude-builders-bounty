# Glossary —《叙事技巧指南》关键术语

- **展现** — 用具体感官细节让读者体验（vs 讲述用概括告诉）. (ch02)
- **讲述** — 概括、解释、直接告诉读者结论. (ch02)
- **细节三要素** — 细致(五感)、确切(不可辩驳)、具体(名词动词). (ch02)
- **直接表现** — 对话/外貌/行为/心理活动直接表现人物. (ch03)
- **间接表现** — 作者阐释/其他角色阐释补全人物. (ch04)
- **深度人物五维** — 可信性、意志、复杂性、变化、群体互动. (ch04)
- **背景三要素** — 地点、时间、氛围. (ch05)
- **情节三角** — 冲突/危机/结局. (ch06)
- **塔与网** — 冲突垂直升级 + 多线程水平并行. (ch06)
- **视角四维** — 谁在说、对谁说、以什么形式、以多远距离. (ch07)
- **头跳** — 同场景在不同人物头里跳，视角大忌. (ch07)
- **明喻** — 用"像/如"显性比较. (ch08)
- **隐喻** — 隐含比较（A 是 B）. (ch08)
- **讽喻** — 延伸隐喻 → 寓言. (ch08)
- **象征** — 具体物 → 抽象义（多义）. (ch08)
- **客观对应物** — 物象/情境/事件链 → 激发特定情感（艾略特《圣木》）. (ch08)
- **修改三层** — 宏观(结构/人物/情节) → 中景(场景/节奏/对话) → 微观(词汇/句式/细节). (ch09)
- **主题生长** — 完稿后问"在说什么"再回头强化，而非先贴标签. (ch09)
