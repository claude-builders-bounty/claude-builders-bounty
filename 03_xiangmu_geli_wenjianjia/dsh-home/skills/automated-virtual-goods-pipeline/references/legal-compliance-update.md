# 法律合规更新 (2026-10-12 实战沉淀)

## 新增红线与自动化拦截

本次会话实测新增/硬化的法律合规红线，已落地为代码强制执行：

### 1. 许可证核验硬闸 (legal_gate.py)
- **license 归一化**：CC-BY-4.0 / CC-BY-SA-4.0 / MIT / Apache-2.0 / BSD-3-Clause / CC0-1.0 / GPL-3.0 / AGPL-3.0 等标准化识别
- **NC/ND 一律拦截**：CC-BY-NC / CC-BY-ND 等禁止商用/禁止演绎许可直接拒绝
- **歧义许可拦截**："MIT/CC0/Apache-2.0" 这种多许可并列、无法确定适用许可的直接拒绝
- **伪造许可拦截**：无 license 字段、license 为空、license="unknown" 直接拒绝
- **Copyleft 类别性拒绝**：GPL-3.0 / AGPL-3.0 等强传染许可直接拒绝（虚拟商品分发场景不可控）

### 2. 竞品数据物理隔离 (Phase 3 三重硬闸)
- **闸1 文件名白名单**：仅接受 `sellable_manifest_*.json` 前缀，旧 `resource_manifest_*.json` 含竞品直接拒绝加载
- **闸2 逐条重验**：每条货源上架前再跑一遍 `check_resource()`，防篡改/防旧文件/防手改
- **闸3 fail-closed**：全部未过闸时中止上架，绝不"空跑上架"
- **竞品检出告警**：检出 source=competitor 条目混入清单时记录 ERROR 级日志

### 3. 政府网站抓取绝对禁止
- 用户明确警告："不是哥，你别去爬国家网站去啊，别给我送进去了"
- 国家网站有 WAF，抓取行为本身可能构成违法
- **仅使用已核验许可明确允许商用的 GitHub 开源仓库**（MIT/CC0/Apache-2.0/BSD-3-Clause，API 实测存在+许可实测核验）

### 4. 文案数量编造零容忍 (listing_copy.py)
- **括号内子数量不计总数**："加了 20 个示例工作簿" 这种组成部分描述不参与"共 N 套"校验
- **仅真实统计可写入文案**：标题/描述里的 "XXX套" 必须来自 `res.count` / `res.file_count` 等实测字段
- **无真实数量时整体换词**：用"整套"/"合集"等不含数字的表述，绝不随机生成 888 套

- **标题中位数仅 4 字符** → 浪费 87% 标题空间（闲鱼上限 30 字）
- **价格中位 1.19 元** → 极低价红海
- **want_count/view_count 全 0** → 抓取字段没映射上，**需求量数据不可得 → 我不评分、不编造**

1. **integrate**：多源合并、统一目录结构、INDEX.json

## 详情页模板 (listing_copy.py) - 合规要素全含
- 差异化卖点（基于真实加工策略，非空话术）
- 发货规则前置：网盘链接+提取码、10分钟内、永久有效
- 退款规则前置：依据《暂行办法》第六条第三项（在线下载数字化商品不适用七日无理由）
- 售后承诺：链接失效/文件损坏/内容不符 → 48h 免费补发/退款
- 交付物清单化：每项 = 文件名+格式+大小+用途+来源许可
- 合规自检：validate_no_false_claims() 必须通过

## Phase 2 网盘上传真实状态
- **OAuth2 access_token**：authorization code flow + `redirect_uri=oob`（无需回调域名）
- **开放平台 API**：上传/分享返回 31500（权限未开放），已弃用
- **Web API 实测 9/9 通过**：BDUSS + bdstoken，UA=`softxm;netdisk`，app_id=778750（参考 BaiduPCS-Py）
- **第三方匿名验证**：分享链接在无登录环境下可下载、可预览
