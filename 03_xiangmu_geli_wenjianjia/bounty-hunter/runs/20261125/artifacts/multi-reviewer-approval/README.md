# 多审批人审批机制 — Bounty 提交流程

- 任务: Implement Multiple Reviewer Approval for Bounty Submissions

- 类型: 功能实现 / Python
- 语言: Python 3
- 成果文件: solution.py, test_solution.py

## 概述

为 bounty 提交流程引入“多审批人”机制：一个提交必须获得配置数量的审批人批准（默认 2 人）才能进入 APPROVED 状态；任意一名审批人拒绝即直接拒绝。

## 设计要点

1. **状态机流转**：DRAFT → SUBMITTED → IN_REVIEW → APPROVED / REJECTED
2. **阈值审批**：required_approvals 可配置，默认 2 人
3. **一票否决**：任意审批人 REJECTED 即整体拒绝
4. **不可变记录**：每次审批生成新的审批记录，不就地覆盖历史

## 主要类

| 类 | 职责 |
|---|---|
| `ReviewerApproval` | 单个审批人的审批记录（reviewer_id、status、comment、reviewed_at） |
| `BountySubmission` | 提交实体，包含 approvals 列表和 required_approvals 阈值 |
| `BountySubmissionManager` | 管理提交生命周期：创建、提交审审、添加审批人、执行审批 |

## 使用示例

```python
mgr = BountySubmissionManager()
sub = mgr.create_submission("Fix X", "description", "author-1", required_approvals=2)
mgr.add_reviewer(sub.submission_id, "reviewer-a")
mgr.add_reviewer(sub.submission_id, "reviewer-b")
mgr.submit_for_review(sub.submission_id)
mgr.review(sub.submission_id, "reviewer-a", ApprovalStatus.APPROVED, "LGTM")
mgr.review(sub.submission_id, "reviewer-b", ApprovalStatus.APPROVED, "Looks good")
assert mgr.is_fully_approved(sub.submission_id)
```
