## 问题描述

`parse_duration` 函数在解析持续时间字符串时，仅识别 `h`/`m`/`s` 单位，遇到 `d`（天）单位时会丢弃或报错，导致包含天数的持续时间无法正确解析。

## 修复内容

在 `solution.py` 中扩展正则解析逻辑，新增对 `d` 单位的支持：

- `2d`        -> timedelta(days=2)
- `3h`        -> timedelta(hours=3)
- `30m`       -> timedelta(minutes=30)
- `45s`       -> timedelta(seconds=45)
- `2d3h30m`   -> timedelta(days=2, hours=3, minutes=30)
- `1d5s`      -> timedelta(days=1, seconds=5)
- `0.5d`      -> timedelta(hours=12)

## 使用方法

```python
from solution import parse_duration, parse_duration_to_seconds

td = parse_duration("2d3h30m")   # timedelta(days=2, hours=3, minutes=30)
secs = parse_duration_to_seconds("2d")  # 172800.0
```
