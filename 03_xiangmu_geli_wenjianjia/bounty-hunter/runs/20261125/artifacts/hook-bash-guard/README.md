## 概述

本方案实现一个在工具执行前检查 Bash 命令的安全钩（pre-tool-use hook）。
命中破坏性模式（rm -rf /、mkfs、dd 写盘、shutdown 等）时拦截执行，并返回结构化 JSON 结果。

## 设计要点

1. **不可变性**：`is_destructive()` 仅读取输入命令，不修改任何共享状态；审计日志仅追加。
2. **合规扫描**：拦截的模式与 REQUIREMENTS.md 红线一致（禁止数据破坏、禁止未验证代码执行）。
3. **敏感数据不落盘明文**：审计日志仅记录命令的 SHA-256 摘要前 16 位，不记录明文命令或参数。
4. **安全前缀兜底**：对可能的误报（如 `eg`、`erg`）做白名单放行。

## 使用方法

```bash
# 将待执行命令作为 JSON 传入 hook
echo '{"tool": "bash", "command": "rm -rf /tmp/data"}' | python solution.py
# 输出: {"ok": false, "blocked": true, "reason": "destructive_command_blocked", ...}

echo '{"tool": "bash", "command": "ls -la"}' | python solution.py
# 输出: {"ok": true, "blocked": false, ...}
```
