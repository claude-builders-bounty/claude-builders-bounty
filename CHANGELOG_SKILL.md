# CHANGELOG Generator — SKILL.md

## Trigger
`/generate-changelog` or `bash changelog.sh`

## Description
Generates a structured `CHANGELOG.md` from git history. Fetches all commits since the last git tag and auto-categorizes them into **Added**, **Fixed**, **Changed**, and **Removed** based on conventional commit prefixes.

## Usage

### As a Claude Code skill
```
/generate-changelog
```
Or with options:
```
/generate-changelog --since v1.0.0 --output docs/CHANGELOG.md
```

### As a standalone script
```bash
bash changelog.sh                        # Uses latest git tag
bash changelog.sh --since v1.0.0         # From specific tag
bash changelog.sh --output RELEASE.md    # Custom output path
```

## How It Works

1. **Determines the starting point**: Uses the most recent git tag, or a user-specified tag via `--since`
2. **Fetches commits**: Runs `git log <tag>..HEAD` with a formatted output
3. **Categorizes**: Maps each commit to a category using conventional commit prefixes:
   - `feat`, `add`, `implement`, `introduce`, `create` → **Added**
   - `fix`, `bug`, `resolve`, `patch`, `hotfix`, `repair` → **Fixed**
   - `refactor`, `update`, `modify`, `improve`, `enhance`, `perf`, `style` → **Changed**
   - `remove`, `drop`, `deprecate`, `delete` → **Removed**
   - Everything else → **Other**
4. **Generates links**: Converts commit hashes to clickable GitHub links
5. **Outputs**: Writes formatted `CHANGELOG.md`

## Requirements
- Bash 4.0+
- Git
- A git repository with at least one tag

## Sample Output

```markdown
# Changelog

## [v1.2.0] — 2026-05-16

### Added
- feat: add user authentication ([abc1234](https://github.com/user/repo/commit/abc1234))
- add rate limiting middleware ([def5678](https://github.com/user/repo/commit/def5678))

### Fixed
- fix: handle null pointer in payment flow ([ghi9012](https://github.com/user/repo/commit/ghi9012))
- bug: resolve race condition in webhook handler ([jkl3456](https://github.com/user/repo/commit/jkl3456))

### Changed
- refactor: extract email service to separate module ([mno7890](https://github.com/user/repo/commit/mno7890))

---
*Generated by changelog.sh*
```

## Setup (3 steps or fewer)

1. Copy `changelog.sh` to your project root:
   ```bash
   curl -O https://raw.githubusercontent.com/claude-builders-bounty/claude-builders-bounty/main/changelog.sh
   chmod +x changelog.sh
   ```

2. Run it:
   ```bash
   bash changelog.sh
   ```

3. (Optional) Add to your release workflow:
   ```bash
   # In .github/workflows/release.yml
   - name: Generate changelog
     run: bash changelog.sh --output CHANGELOG.md
   ```
