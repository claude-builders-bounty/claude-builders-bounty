# Changelog Generator Skill 🚀

A professional bash script that generates beautiful, structured `CHANGELOG.md` files from git history with **conventional commit awareness** and **emoji-formatted categories**.

## Quick Start

```bash
# Clone a project and run
cd /path/to/your/repo
bash /path/to/changelog.sh

# Output: CHANGELOG.md with categorized, emoji-formatted entries
```

## Features

### ✨ Core Features
| Feature | Status |
|---------|--------|
| 🔍 Parses conventional commits (`feat:`, `fix:`, `docs:`, etc.) | ✅ |
| 🎨 Emoji-formatted categories (🚀 Added, 🐛 Fixed, 📚 Docs, etc.) | ✅ |
| 🏷️ Auto-detects last git tag as starting point | ✅ |
| 🔗 Multi-range support (`--since v1.0 --until v2.0`) | ✅ |
| 📊 Statistics section (lines added/removed, file counts) | ✅ |
| 👥 Contributor acknowledgment per commit count | ✅ |
| 💥 Breaking change detection (`!` or `BREAKING CHANGE:`) | ✅ |
| 📋 JSON mode for machine-readable output | ✅ |
| 📂 Scope-aware entries (`feat(api):` → `**api**: description`) | ✅ |
| ⚡ Zero dependencies beyond bash + git | ✅ |

| Tests | ✅ | `test:`, `testing:` |
| Security | 🔒 | `security:` |
| Build | 📦 | `build:` |

## Full Usage

```bash
# Generate full changelog (auto-detects last tag)
bash changelog.sh

# Custom range
bash changelog.sh --since v1.0.0 --until v2.0.0

# Custom output
bash changelog.sh --output RELEASE_NOTES.md

# Work on another repo
bash changelog.sh --repo /path/to/project

# JSON output (for CI pipelines)
bash changelog.sh --json

# Minimal output (no stats, no contributors)
bash changelog.sh --no-stats --no-contribs

# Combined
bash changelog.sh --since v1.5.0 --output CHANGES.md --json
```

## Requirements

- **Bash** 4.0+
- **Git** 2.0+
- Linux, macOS, or WSL
- No other dependencies

## Integration

### As a Claude Code Skill
Add to your `CLAUDE.md`:
```
## Available Scripts
- `bash /path/to/changelog.sh` — Generate CHANGELOG.md
```

### In CI/CD (GitHub Actions)
```yaml
- name: Generate Changelog
  run: bash changelog.sh --json --output changelog.json
```

### Pre-commit hook
```bash
# .git/hooks/pre-commit
bash /path/to/changelog.sh --since $(git describe --tags --abbrev=0) --output CHANGELOG.md
git add CHANGELOG.md
```
