### Implementation Details

**Core Features:**
- Fetches PR details and diff from GitHub API
- Analyzes code using Claude 3.5 Sonnet API
- Generates structured Markdown review
- Supports both CLI and GitHub Action modes
- Handles authentication via environment variables or CLI flags

**Output Format:**
```markdown
## 🤖 Claude Code PR Review
**PR:** <url>
**Author:** @<username>
**Changes:** +<additions> -<deletions> (<files> files)

---
<analysis from Claude>

---
*Generated by Claude Code PR Review Agent*
```

**Environment Variables:**
- `ANTHROPIC_API_KEY` (required) - Anthropic API key
- `GITHUB_TOKEN` (optional) - GitHub token for private repos

**CLI Options:**
- `--pr` - GitHub PR URL (required)
- `--github-token` - GitHub token override
- `--claude-api-key` - Anthropic API key override
- `--output` - Output file path
