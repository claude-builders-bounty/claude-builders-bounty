# Claude Code PR Review Agent

A Claude Code sub-agent that reviews GitHub pull requests and posts structured Markdown comments.

## Features

- **CLI Interface:** Review any PR from command line
- **GitHub Action Integration:** Automatic reviews on PR events
- **Structured Output:** Consistent review format with summary, risks, improvements, and confidence score
- **AI-Powered Analysis:** Uses Claude 3.5 Sonnet for intelligent code review

## Installation

### Prerequisites

- Python 3.11+
- Anthropic API key
- GitHub personal access token (optional, for private repos)

### Setup

1. Clone the repository:
```bash
git clone https://github.com/claude-builders-bounty/claude-builders-bounty.git
cd claude-builders-bounty
```

2. Install the package (includes CLI command):
```bash
pip install -e pr-review-agent/
```

3. Set environment variables:
```bash
export ANTHROPIC_API_KEY="your-anthropic-api-key"
export GITHUB_TOKEN="your-github-token"  # Optional, for private repos
```

## Usage

### CLI Mode

Review a specific PR:
```bash
claude-review --pr https://github.com/owner/repo/pull/123
```

Save review to file:
```bash
claude-review --pr https://github.com/owner/repo/pull/123 --output review.md
```

### GitHub Action Mode

To enable automatic PR reviews on your repository:

1. Copy the workflow file to your repo:
```bash
cp .github/workflows/pr-review.yml YOUR_REPO/.github/workflows/
```

2. Add secrets to your repository:
   - `ANTHROPIC_API_KEY`: Your Anthropic API key
   - `GITHUB_TOKEN`: GitHub token with repo access

3. The workflow will automatically run on:
   - PR opened
   - Manual trigger (workflow_dispatch)

## Output Format

The agent generates a structured review with:

### Summary
2-3 sentences summarizing the changes

### Risks
List of potential issues:
- Security concerns
- Performance implications
- Edge cases
- Breaking changes

### Improvements
List of suggestions:
- Code quality improvements
- Best practices
- Documentation additions
- Refactoring opportunities

### Confidence
- **Low:** Limited context, high uncertainty
- **Medium:** Reasonable context, some uncertainty
- **High:** Clear context, high confidence

## Configuration

### Environment Variables

- `ANTHROPIC_API_KEY` (required): Anthropic API key for Claude access
- `GITHUB_TOKEN` (optional): GitHub token for private repository access

### CLI Options

- `--pr`: GitHub PR URL (required)
- `--github-token`: GitHub personal access token (overrides env var)
- `--claude-api-key`: Anthropic API key (overrides env var)
- `--output`: Output file path (default: stdout)

## Limitations

- Diff truncated to 10,000 characters for API limits (with warning)
- Requires Anthropic API key (not free)
- GitHub token required for private repositories
- No caching of reviews

## Troubleshooting

### "ANTHROPIC_API_KEY required"
- Set the environment variable: `export ANTHROPIC_API_KEY="your-key"`
- Or use the flag: `claude-review --pr <url> --claude-api-key "your-key"`

### "Invalid GitHub PR URL format"
- Ensure URL format is: `https://github.com/owner/repo/pull/123`
- Do not use `/pulls/` (plural) or other variations

### "Request timed out"
- Increase timeout: `claude-review --pr <url> --timeout 60`

### "Rate limited"
- The tool automatically waits and retries on rate limits
- For frequent use, add a GitHub token to increase rate limits

### "Failed to fetch PR"
- Check that the PR exists and is public (or provide GitHub token)
- Verify your network connection
