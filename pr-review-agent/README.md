# PR Review Agent - Claude Code Agent

A Claude Code agent that reviews GitHub PRs and posts structured comments.

## Features

- Analyzes PR diffs automatically
- Identifies potential risks and security concerns
- Provides improvement suggestions
- Confidence score for the review
- Can post reviews as GitHub comments

## Installation

```bash
# Clone the repository
git clone https://github.com/jeremyclakson/claude-builders-bounty.git
cd claude-builders-bounty/pr-review-agent

# Make the script executable
chmod +x claude-review.py

# Optional: Add to PATH
ln -s $(pwd)/claude-review.py /usr/local/bin/claude-review
```

## Usage

### Basic usage
```bash
python3 claude-review.py --pr https://github.com/owner/repo/pull/123
```

### Post review as comment
```bash
python3 claude-review.py --pr https://github.com/owner/repo/pull/123 --post
```

### Save review to file
```bash
python3 claude-review.py --pr https://github.com/owner/repo/pull/123 --output review.md
```

## Output Format

The agent generates structured Markdown with:

### Summary
Brief overview of changes (2-3 sentences)

### Identified Risks
- Security concerns
- Large changes
- Missing tests
- etc.

### Improvement Suggestions
- Documentation updates
- Error handling
- Testing recommendations

### Confidence Score
- **High**: Small, focused changes
- **Medium**: Medium-sized PRs
- **Low**: Very large or complex PRs

## Requirements

- Python 3.8+
- GitHub CLI (`gh`) installed and authenticated
- Internet connection
