# PR Review Agent

A Claude Code sub-agent that takes a GitHub PR URL, fetches the diff,
and generates a structured Markdown review with summary, risks,
suggestions, and a confidence score.

## Installation (2 steps)

```bash
# 1. Make the script executable
chmod +x scripts/claude-review

# 2. Ensure gh CLI is authenticated
gh auth login
```

## Usage

### CLI mode (template output)

```bash
./scripts/claude-review --pr https://github.com/owner/repo/pull/123
```

This fetches the PR diff and outputs a structured review template
that you can paste into Claude Code for analysis.

### AI mode (requires Anthropic API key)

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
./scripts/claude-review --pr https://github.com/owner/repo/pull/123 --ai
```

Uses the Claude API to generate the review automatically.

### From Claude Code

Load the skill and say:

```
Review PR https://github.com/owner/repo/pull/123
```

Claude Code will fetch the diff and produce a structured review
following the agent's output format.

## Output Format

```markdown
# PR Review: <PR Title>

**PR:** <URL>
**Author:** @<author>
**Changes:** +N / -M lines across F files

---
## Summary
<2-3 sentences>

## Identified Risks
- **<Category>:** <description>

## Suggestions
- <actionable suggestion>

## Confidence Score
**<Low/Medium/High>** — <rationale>
---

*Review generated by PR Review Agent*
```

## Review Guidelines

| Check | What to look for |
|-------|-----------------|
| Security | Exposed secrets, injection vectors, missing auth checks |
| Breaking changes | API signature changes, DB migrations without rollback |
| Error handling | Missing try/catch, swallowed errors, unhandled promises |
| Tests | New logic without tests, assertions that don't verify behavior |
| Naming | Confusing variable names, inconsistent conventions |
| Performance | N+1 queries, unnecessary loops, missing indexes |
