# Claude Review -- PR Review Agent

Automated PR analysis tool that fetches a GitHub PR diff, analyzes it, and outputs a structured Markdown review.

## Install (2 commands)

```bash
# 1. Copy the script anywhere in your PATH
cp claude_review.py /usr/local/bin/claude-review

# 2. Done. No dependencies beyond Python 3 standard library.
```

## Usage

```bash
# Review a PR and print to stdout
python claude_review.py --pr https://github.com/owner/repo/pull/123

# Review a PR and save to file
python claude_review.py --pr https://github.com/owner/repo/pull/123 --output review.md
```

## Output format

```markdown
## PR Review

**PR:** https://github.com/owner/repo/pull/123
**Title:** Add feature X
**Author:** @username
**Stats:** 3 files | +150 / -20

---

### Summary

This PR modifies 3 file(s) with 150 addition(s) and 20 deletion(s).
It addresses: Add feature X.

### Identified Risks

- [file.py] Use of eval() detected -- potential code injection risk
- No test files modified -- confirm tests cover the changes

### Improvement Suggestions

- Add/update tests for new Python code
- Run type checker (mypy) on modified files

### Confidence Score

**Medium**

---

*Generated by claude-review -- an automated PR analysis tool.*
```

## What it checks

| Check | Detail |
|-------|--------|
| **Size** | Large PRs flagged (>500 additions) |
| **New/Deleted files** | Warns about missing dependencies |
| **Security** | `eval()`, `exec()`, `os.system()`, hardcoded secrets |
| **Tests** | Flags PRs without test file changes |
| **Description** | Warns if PR body is too brief |
| **Language-specific** | Python (mypy), JS/TS (eslint), Markdown (links) |

## Confidence scoring

| Score | Criteria |
|-------|----------|
| **Low** | 3+ risks or >500 additions |
| **Medium** | 1-2 risks or >200 additions |
| **High** | No risks and <200 additions |

## No API key needed

Uses unauthenticated GitHub API (60 requests/hour). For higher limits, set a `GITHUB_TOKEN` environment variable.
