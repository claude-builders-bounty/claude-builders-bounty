# claude-review

AI code-review agent for GitHub pull requests. Give it a PR URL, get a
structured Markdown review: **Summary · Risks · Suggestions · Confidence**.

Two ways to run it (this submission ships **both** paths of bounty #4):

1. **CLI** — `claude-review --pr https://github.com/owner/repo/pull/123`
2. **GitHub Action** — posts the same structured review as a PR comment, and
   *updates its existing comment* on new pushes instead of spamming duplicates.

## How it works

```
gh pr view + gh pr diff  ──►  claude_review.py  ──►  Anthropic Messages API  ──►  structured Markdown
(title/body/diff context)      (stdlib only,          (urllib; model via            printed / posted
                                no pip installs)       CLAUDE_REVIEW_MODEL)          as PR comment
```

## Setup (2 minutes)

1. Install the [GitHub CLI](https://cli.github.com/) and authenticate:

   ```bash
   gh auth login
   ```

2. Export your Anthropic API key:

   ```bash
   export ANTHROPIC_API_KEY=***
   ```

3. That's it — Python 3.9+, zero dependencies.

## CLI usage

```bash
# full URL form
python claude_review.py --pr https://github.com/pallets/click/pull/3782

# split-argument form, saving output to a file as well
python claude_review.py --repo pallets/click --number 3780 --write review.md

# executable shims
./claude-review --pr https://github.com/o/r/pull/123        # macOS / Linux
claude-review.cmd --pr https://github.com/o/r/pull/123      # Windows

# review a local patch without touching GitHub
python claude_review.py --diff-file fix.patch
```

Configuration (all optional):

| Variable | Default | Purpose |
|---|---|---|
| `ANTHROPIC_API_KEY` | *(required)* | Anthropic API key |
| `CLAUDE_REVIEW_MODEL` | `claude-sonnet-4-20250514` | any Anthropic model id |
| `CLAUDE_REVIEW_MAX_DIFF` | `120000` | diff chars kept before middle-truncation |

Oversized diffs are truncated head+tail with an explicit notice in the prompt,
never silently. The PR's title/body are included as review context when available.

## GitHub Action usage

1. Copy `pr-review-agent/.github/workflows/review.yml` into the target repo
   (adjust the script path if you place the folder elsewhere).
2. Add one repository secret: `ANTHROPIC_API_KEY`.
3. Open or push to any PR — the workflow posts the structured review and keeps
   a single comment up to date per PR.

Security notes baked into the workflow:
- The review body reaches the posting step through an **environment variable**,
  never `${{ }}` interpolation into the JS — so backticks/`${}` in review text
  cannot inject code into `github-script`.
- Uses only the built-in `GITHUB_TOKEN` for posting; forks without the secret
  skip cleanly instead of failing.

## Output contract

Exactly four sections, every run:

```markdown
## Summary
2–3 sentences on what changed and why.

## Risks
- specific risks ("- None identified." if clean)

## Suggestions
- concrete improvements ("- None." if nothing to add)

## Confidence
High | Medium | Low — one-line justification
```

## Tests

```bash
python -m unittest discover tests -v
```

Covers PR-URL/repo-number parsing, malformed-input rejection, middle-truncation
invariants, missing-`gh` handling, and the no-API-key guard (no network needed).

## Troubleshooting

| Symptom | Fix |
|---|---|
| `gh CLI not found` | install gh, run `gh auth login` |
| `ANTHROPIC_API_KEY is not set` | export it (see Setup step 2) |
| `API error 401/403` | check key validity/billing at console.anthropic.com |
| `API error 429` | rate limited — retry shortly or switch `CLAUDE_REVIEW_MODEL` |
