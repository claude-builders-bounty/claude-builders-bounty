# claude-review — PR Review Sub-Agent 🔍

A Claude Code sub-agent that analyzes GitHub pull request diffs and generates structured Markdown review comments with risk analysis, improvement suggestions, and confidence scoring.

**[Bounty #4 — $150](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/4)**

## Features

- ✅ **CLI tool** — Run from terminal: `claude-review --pr https://github.com/owner/repo/pull/123`
- ✅ **GitHub Action** — Auto-review PRs on `opened`/`synchronize` or via `/review` comment
- ✅ **Claude Code skill** — Use as a native Claude Code sub-agent via SKILL.md
- ✅ **Structured output** — Markdown format with Summary, Risks, Suggestions, and Confidence
- ✅ **Real PR diffs** — Fetches live diffs via GitHub API (no manual copy-paste)
- ✅ **Multi-source** — Review from PR URL, local diff file, or stdin pipe

## Setup (5 steps)

### 1. Clone & install

```bash
git clone https://github.com/YOUR_USER/claude-review-agent
cd claude-review-agent
pip install -r requirements.txt
```

### 2. Set API keys

```bash
# Required: Claude API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Optional: GitHub token for PR diff fetching (avoids rate limits)
export GITHUB_TOKEN="ghp_..."
```

### 3. Run a review

```bash
# Review a PR
python claude_review.py --pr https://github.com/tiangolo/fastapi/pull/100

# Save to file
python claude_review.py --pr https://github.com/tiangolo/fastapi/pull/100 -o review.md

# From a local diff
git diff main...feature > changes.diff
python claude_review.py --diff-file changes.diff
```

### 4. (Optional) Set up GitHub Action

Copy `.github/workflows/claude-review.yml` to your repo's `.github/workflows/` directory and add `ANTHROPIC_API_KEY` as a repository secret.

To request a review on any PR, comment `/review`.

### 5. (Optional) Use as Claude Code skill

Copy `SKILL.md` to your project's `.claude/skills/` directory. Then in Claude Code:

```
> Review https://github.com/owner/repo/pull/123
```

## Output Format

```markdown
## 🤖 Claude Code Review: <PR Title>

**PR:** <url>
*Generated by claude-review on YYYY-MM-DD HH:MM UTC*

---

## Summary
(2–3 sentences summarizing changes)

## Identified Risks
- `filename:line` — Description
- (or "No risks identified.")

## Improvement Suggestions
- Suggestion 1
- (or "No suggestions.")

## Confidence
**High** — justification
```

## Confidence Levels

| Level | Meaning |
|---|---|
| **Low** | Not enough context to review properly (massive diff, unfamiliar domain) |
| **Medium** | Reasonable review but may miss domain-specific issues |
| **High** | Clear, well-scoped changes; confident in assessment |

## How it works

```
┌──────────────┐     ┌──────────────────┐     ┌─────────────┐
│  PR URL /    │────▶│  GitHub API      │────▶│  PR Diff    │
│  Diff File   │     │  (fetch .diff)   │     │  (text)     │
└──────────────┘     └──────────────────┘     └──────┬──────┘
                                                     │
                                                     ▼
┌──────────────┐     ┌──────────────────┐     ┌─────────────┐
│  Markdown    │◀────│  Claude Code     │◀────│  System +   │
│  Review      │     │  CLI / API       │     │  User Prompt│
└──────────────┘     └──────────────────┘     └─────────────┘
```

1. **Fetch**: Pull PR diff via GitHub API (or read from file/stdin)
2. **Analyze**: Send diff + structured prompt to Claude API (or Claude Code CLI)
3. **Output**: Return formatted Markdown review with Summary, Risks, Suggestions, Confidence
