# CLAUDE.md at Root — Usage

Place this file at the root of your repository as `CLAUDE.md` to guide Claude Code (claude.ai/code) when working on your project.

## Customize

Replace all `{{PLACEHOLDER}}` values with your project-specific information:
- `{{PROJECT_NAME}}` — your project name
- `{{PROJECT_DESCRIPTION}}` — one-line description
- `{{LANGUAGE}}` — JavaScript / TypeScript / etc.
- `{{FRAMEWORK}}` — React / Vue / Express / etc.
- `{{PACKAGE_MANAGER}}` — npm / yarn / pnpm
- `{{TEST_RUNNER}}` — Jest / Vitest / Mocha
- `{{LINTER}}` — ESLint / Prettier

## Sections

- **Project Overview** — what the project does
- **Tech Stack** — languages, frameworks, tools
- **Project Structure** — directory layout
- **Available Scripts** — npm/yarn/pnpm commands
- **Code Conventions** — style rules
- **Common Tasks** — how to add features, fix bugs
- **AI Agent Guidelines** — instructions for AI agents
