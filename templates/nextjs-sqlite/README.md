# Next.js + SQLite CLAUDE.md Template

Production-ready CLAUDE.md template for a greenfield Next.js 15 App Router SaaS project using SQLite.

## Install
```bash
mkdir -p . && cp templates/nextjs-sqlite/CLAUDE.md ./CLAUDE.md
claude
```

## What it covers
- stack and versions
- folder structure
- App Router rules
- database and migration conventions
- component patterns
- naming conventions
- multi-tenant SaaS safety rules
- anti-patterns and why to avoid them
