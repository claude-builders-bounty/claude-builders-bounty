# Next.js + SQLite CLAUDE.md Template

This implements bounty #2 with an opinionated `CLAUDE.md` for a production-ready Next.js 15 App Router SaaS project backed by SQLite.

## Setup

1. Create a Next.js 15 TypeScript project.
2. Copy `templates/nextjs-sqlite/CLAUDE.md` to the project root.
3. Ask Claude Code to implement a route, migration, or server action using the app conventions.

## Included Guidance

- Stack and version assumptions
- Folder structure
- Naming conventions
- SQL and migration rules
- Component, server, data, and test patterns
- Anti-patterns with reasons
- PR checklist

## Validation

The template was checked against the greenfield scenario in `context-check.md`. The prompt supplies a normal SaaS feature request and verifies that the `CLAUDE.md` already answers the expected project-structure, migration, command, and implementation-style questions.
