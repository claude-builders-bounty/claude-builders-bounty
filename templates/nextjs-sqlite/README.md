# SaaS Template (Next.js + SQLite) 🚀

An opinionated `CLAUDE.md` template for high-velocity SaaS development using Next.js 15 and SQLite.

## How to use
1. Copy the `CLAUDE.md` file to your project root.
2. Initialize your project with Next.js 15 and Drizzle ORM.
3. Claude Code will now automatically follow the project structure and conventions defined in the file.

## Why this structure?
- **Speed**: SQLite + better-sqlite3 is the fastest local development experience.
- **Safety**: Drizzle ORM provides type-safe SQL queries.
- **Modern**: Fully optimized for Next.js 15 App Router and React Server Components.
