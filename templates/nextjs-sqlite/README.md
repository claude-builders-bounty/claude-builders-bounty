# Next.js 15 + SQLite CLAUDE.md Template

Copy `CLAUDE.md` into the root of a greenfield Next.js 15 App Router SaaS
project that uses SQLite through `better-sqlite3` or Turso/libSQL.

Validation checklist used for this bounty:

1. The template names the stack, folder structure, SQL/migration conventions,
   component patterns, dev commands, and anti-patterns.
2. Each major rule includes a reason so Claude Code can preserve intent instead
   of applying generic preferences.
3. The final instruction tells Claude Code to inspect existing conventions and
   proceed when the template already answers the question, reducing unnecessary
   clarifying questions in a greenfield project.
