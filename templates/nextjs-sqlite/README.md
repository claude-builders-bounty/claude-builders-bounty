# Production CLAUDE.md for Next.js 15 + SQLite SaaS

An opinionated, production-tested `CLAUDE.md` template tailored for modern SaaS applications using Next.js 15 App Router, SQLite, and Drizzle ORM.

## Quick Usage

Drop `CLAUDE.md` into the root of your Next.js + SQLite repository:

```bash
cp templates/nextjs-sqlite/CLAUDE.md ./CLAUDE.md
```
