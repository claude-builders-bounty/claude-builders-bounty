# Next.js 15 + SQLite SaaS Template Specification (`CLAUDE.md`)

This template provides an opinionated, production-ready `CLAUDE.md` specification designed for Next.js 15 App Router + SQLite SaaS architectures.

## Quickstart

Copy `CLAUDE.md` to the root of any greenfield or existing Next.js + SQLite project:

```bash
cp templates/nextjs-sqlite/CLAUDE.md /path/to/your/project/CLAUDE.md
```

Claude Code will instantly recognize:
1. Stack & strict versions (Next.js 15 App Router, React 19, Drizzle ORM, SQLite WAL mode).
2. Clean folder layout and naming conventions.
3. Database migration workflow & atomic transaction guidelines.
4. React Server Component vs Client Component separation.
5. Strict anti-patterns ("What we don't do and why").
