## ⚡ Quick Start

1. Copy `CLAUDE.md` to the root of your greenfield or existing Next.js + SQLite project:
   ```bash
   cp templates/nextjs-sqlite/CLAUDE.md /path/to/your-project/CLAUDE.md
   ```
2. Start Claude Code in that project:
   ```bash
   claude
   ```
3. Claude Code will instantly understand your architectural boundaries, SQLite WAL mode, Server Actions convention, and folder layout without asking clarifying questions.
