# Next.js 15 + SQLite SaaS Template Specification

This directory provides the production-grade `CLAUDE.md` specification for building modern SaaS applications using Next.js 15 (App Router, Server Components, Server Actions) and SQLite with Drizzle ORM.

## Usage with Claude Code
1. Place `CLAUDE.md` at the root of any greenfield or existing Next.js 15 + SQLite project.
2. Run `claude` in your terminal.
3. Claude will immediately adhere to the mandatory SQLite PRAGMA rules, Server Action data validation standards, and folder conventions without requiring prompt initialization.
