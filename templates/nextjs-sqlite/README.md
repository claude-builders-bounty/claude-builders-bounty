# Next.js 15 + SQLite CLAUDE.md Template 📋

An opinionated, production-ready `CLAUDE.md` template designed for SaaS projects built with **Next.js 15 App Router**, **React 19**, **TypeScript**, and **SQLite** (via **Drizzle ORM**).

---

## ⚡ Quick Usage

Copy `CLAUDE.md` directly into the root directory of your Next.js + SQLite repository:

```bash
cp templates/nextjs-sqlite/CLAUDE.md /path/to/your-nextjs-project/CLAUDE.md
```

When invoking Claude Code, the agent will automatically parse `CLAUDE.md` and adhere strictly to its architectural invariants, database migration workflow, and Server Component conventions without requiring clarifying questions.
