# Next.js 15 + SQLite CLAUDE.md

This template makes concrete defaults for a greenfield SaaS: Next.js 15 App
Router, React 19, strict TypeScript, npm, better-sqlite3 and a persistent Node
server. It deliberately chooses the local SQLite option in issue #2.

## Use

1. Put `CLAUDE.md` at the new project's root.
2. Start Claude Code there and ask it to bootstrap or implement a feature.
3. Run the recorded typecheck, test and build commands before reviewing the diff.

Every rule explains its operational reason. No provider credentials or company
specific IDs need to be substituted in the file. The bootstrap section tells the
agent to establish the minimal scripts when the project is still empty.

The accompanying fixture and recorded checks exercise the conventions; they are
not an authentication system, a deployed SaaS or a claim that this document alone
supplies missing application code. Claude context-comprehension evidence is
recorded separately from TypeScript, SQLite and build tests.
