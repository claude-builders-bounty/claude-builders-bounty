# Next.js + SQLite CLAUDE.md Template

This template provides a standardized `CLAUDE.md` configuration file for projects built with **Next.js (App Router)** and **SQLite**.

## Installation

Copy `CLAUDE.md` to the root directory of your Next.js + SQLite project:

```bash
cp templates/nextjs-sqlite/CLAUDE.md /path/to/your/project/CLAUDE.md
```

## Included Guidelines

- **Commands**: Build, dev, test, and SQLite migration commands.
- **App Router Rules**: React Server Components vs Client Components conventions.
- **SQLite Best Practices**: WAL mode configuration, parameterized queries, and transaction safety.
- **Directory Layout**: Standard Next.js 14/15 directory structure.
- **Security**: Input validation with Zod and environment safety.
