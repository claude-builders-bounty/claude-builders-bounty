# Next.js 15 + SQLite SaaS Starter Template

A production-grade, opinionated `CLAUDE.md` specification designed for immediate use on greenfield Next.js 15 App Router applications backed by SQLite / Turso libSQL.

## Quick Start (Zero Setup)
Copy `CLAUDE.md` directly into the root of any new Next.js 15 + SQLite project:

```bash
cp templates/nextjs-sqlite/CLAUDE.md /path/to/my-new-saas/CLAUDE.md
```

Claude Code will automatically detect the architectural rules, directory patterns, Zod validation boundaries, and WAL-mode SQLite constraints.
