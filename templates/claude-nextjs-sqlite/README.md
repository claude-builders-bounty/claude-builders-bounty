# Next.js + SQLite CLAUDE.md Template

A production-ready `CLAUDE.md` for Next.js 15 + SQLite SaaS projects. Paste it into your project root — Claude Code will understand your stack, conventions, and rules without asking clarifying questions.

## Usage

```bash
# Copy to your project root
cp CLAUDE.md /path/to/your/project/CLAUDE.md
```

## What's Covered

- **Stack & versions**: Next.js 15, SQLite (Turso/better-sqlite3), Drizzle ORM, Tailwind 4, next-auth v5
- **Project structure**: App Router layout with auth/dashboard/api groups
- **Naming conventions**: Files, components, DB, env vars — all consistent
- **SQL/Migration rules**: Drizzle-specific best practices
- **Component patterns**: Server-first, thin pages, server actions
- **Anti-patterns**: What we avoid and why (10 specific rules)
- **Auth & security**: NextAuth, rate limiting, CSRF
- **Testing**: Vitest, Playwright, coverage targets
