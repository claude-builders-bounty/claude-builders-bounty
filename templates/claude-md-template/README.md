# CLAUDE.md Template for Next.js SaaS Starters

This repository contains a comprehensive CLAUDE.md template for AI-assisted development of Next.js SaaS applications.

## What's Included

- ✅ **Project Architecture**: Complete folder structure and tech stack
- ✅ **Key Conventions**: Naming, component structure, API routes
- ✅ **Database Schema**: Common Prisma models and migrations
- ✅ **Authentication Flow**: NextAuth.js setup and protected routes
- ✅ **API Routes Reference**: Common endpoints and webhook security
- ✅ **Testing Strategy**: Unit, integration, and E2E tests
- ✅ **Deployment Steps**: Environment variables and deployment guides
- ✅ **Example Prompts**: Ready-to-use prompts for common tasks

## Usage

1. Copy `CLAUDE.md` to your Next.js SaaS project root
2. Customize sections for your specific project
3. Share with AI assistants (Claude, GPT-4, etc.)
4. Use the example prompts for common tasks

## Tested With
