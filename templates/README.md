# CLAUDE.md Template — Next.js 15 + SQLite SaaS

This is a production-ready `CLAUDE.md` template for SaaS projects built with Next.js 15 App Router and SQLite.

## Usage

1. Copy `CLAUDE.md` to your project root
2. Adjust versions if needed
3. Start coding with Claude Code — it will understand your project context immediately

## What's Included

- ✅ Stack & Versions (Next.js 15, React 19, SQLite, Drizzle ORM)
- ✅ Folder Structure (App Router conventions)
- ✅ Naming Conventions (files, components, DB tables)
- ✅ Database Patterns (Drizzle schema, migrations, query patterns)
- ✅ Component Patterns (Server vs Client components)
- ✅ API Route Patterns (standard response format, validation)
- ✅ Auth Pattern (server-side session check)
- ✅ Testing Patterns (Vitest + Playwright)
- ✅ What We Don't Do (and why)
- ✅ Dev Commands
- ✅ Pre-Commit Checklist
- ✅ AI Assistant Guidelines
