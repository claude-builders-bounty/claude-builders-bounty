# CLAUDE.md Template — Next.js 15 + SQLite SaaS

An opinionated, production-ready `CLAUDE.md` for a greenfield SaaS project
built with **Next.js 15 App Router** and **SQLite** (better-sqlite3 / Turso).

## Usage

Copy `CLAUDE.md` into the root of your Next.js project.  
No modifications needed — every rule applies as-is.

If you use Turso instead of better-sqlite3, swap the DB_URL variable.
