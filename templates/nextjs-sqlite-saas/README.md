# CLAUDE.md Template — Next.js 15 + SQLite SaaS

An opinionated, production-ready `CLAUDE.md` for a Next.js 15 (App Router) + SQLite SaaS project.

## Setup (3 Steps)

1. **Create your project**
   ```bash
   npx create-next-app@latest my-saas --typescript --tailwind --eslint --app --src-dir
   cd my-saas
   ```

2. **Add CLAUDE.md**
   ```bash
   curl -O https://raw.githubusercontent.com/your-fork/claude-builders-bounty/main/templates/nextjs-sqlite-saas/CLAUDE.md
   ```

3. **Start building**
   ```bash
   code .         # Open in VS Code
   # Claude Code will automatically read CLAUDE.md
   ```
