# Next.js + SQLite SaaS Template

This is an opinionated `CLAUDE.md` template for Next.js 15 App Router projects using SQLite (via better-sqlite3 or Turso) and Drizzle ORM.

## Usage

1. Copy the `CLAUDE.md` file to the root of your Next.js project.
2. Ensure your `package.json` has the relevant commands (`db:generate`, `db:push`, etc.).
3. Claude Code will automatically read this file and adapt its behavior to these conventions.
