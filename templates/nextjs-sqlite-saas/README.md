# Next.js + SQLite SaaS CLAUDE.md Template

An opinionated `CLAUDE.md` for greenfield SaaS projects using Next.js App
Router and SQLite.

## Use

1. Create or open a Next.js + SQLite SaaS repository.
2. Copy `CLAUDE.md` to the repository root.
3. Start Claude Code from that repository.

## Defaults

- Next.js 15 App Router
- React 19 and TypeScript 5
- SQLite through `better-sqlite3`
- Optional Turso/libSQL deployment path
- Drizzle schema and migrations
- Zod validation
- Server components by default
- Repository/service/action layering
