# Next.js + SQLite SaaS CLAUDE.md Template

This directory contains an opinionated `CLAUDE.md` for a greenfield SaaS project
using Next.js 15 App Router and SQLite through Drizzle with `better-sqlite3` or
Turso/libSQL.

Copy `CLAUDE.md` into the root of a new project before starting Claude Code.
The template is intentionally specific about ownership boundaries, migrations,
server actions, authorization, and validation commands so Claude can work
without first asking for architectural defaults.
