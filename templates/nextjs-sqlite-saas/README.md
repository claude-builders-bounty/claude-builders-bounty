# Next.js SQLite SaaS CLAUDE.md

This template is an opinionated `CLAUDE.md` for greenfield SaaS projects using Next.js 15 App Router with SQLite through `better-sqlite3` or Turso/libSQL.

Use it by copying `CLAUDE.md` to the root of a new project before starting Claude Code.

It covers:

- Stack and version assumptions.
- Folder structure.
- Naming conventions.
- SQL and migration rules.
- Server, component, auth, and testing patterns.
- Anti-patterns to avoid and the reason behind each one.
