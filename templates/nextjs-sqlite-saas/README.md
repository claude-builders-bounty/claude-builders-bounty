# Next.js + SQLite SaaS — CLAUDE.md Template

A production-ready `CLAUDE.md` for SaaS projects built with Next.js 15 App Router and SQLite.

## What's included

- **Stack decisions** with reasons (not just a list)
- **Project structure** with explanation of each directory
- **Naming conventions** for files, components, DB tables, types
- **Database rules** — Drizzle schema-first, migration workflow, SQLite-specific gotchas
- **Auth patterns** with Better Auth
- **Server Actions & queries** — complete patterns with examples
- **Component patterns** — Server Components first, Client Components only for interactivity
- **Anti-patterns** — what NOT to do, and why
- **Dev commands** reference
- **Feature checklist** — step-by-step for adding new features

## Usage

```bash
# Copy into your project root
cp CLAUDE.md /path/to/your/project/
```

Claude Code will automatically read it and understand your project's conventions without further context.

## Stack

Next.js 15 · TypeScript · better-sqlite3 · Drizzle ORM · Better Auth · Tailwind CSS · shadcn/ui · Zod · Vitest
