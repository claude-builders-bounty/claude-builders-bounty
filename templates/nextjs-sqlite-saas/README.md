# Next.js 15 + SQLite SaaS `CLAUDE.md` Template 🚀

A battle-tested, opinionated `CLAUDE.md` template designed specifically for modern SaaS web applications built with **Next.js 15 App Router**, **React 19**, **TypeScript**, and **SQLite** (via Drizzle ORM, better-sqlite3, or Turso).

---

## Why this Template?

Claude Code and other AI assistants perform drastically better when provided with strict boundaries, established architectural patterns, and negative constraints ("what not to do").

This template provides:
- **Zero Ambiguity**: Clear tech stack versions, directory hierarchy, and naming conventions.
- **SQLite Performance Guidelines**: Enforces WAL mode, foreign key PRAGMAs, and indexing rules.
- **Next.js 15 Best Practices**: Clear division between Server Components, Client Components, and Server Actions.
- **Security & Integrity**: Zod input validation schemas, anti-pattern tables, and environment safety rules.

---

## How to Use

1. Copy `CLAUDE.md` directly into the root of your Next.js project:
   ```bash
   cp templates/nextjs-sqlite-saas/CLAUDE.md /path/to/your-project/CLAUDE.md
   ```
2. Start Claude Code in your project directory:
   ```bash
   claude
   ```
3. Claude will automatically discover `CLAUDE.md` and immediately conform to your architecture without asking repetitive clarifying questions.
