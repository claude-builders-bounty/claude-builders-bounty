# Next.js + SQLite SaaS CLAUDE.md Template

This template is an opinionated `CLAUDE.md` for a greenfield SaaS app using Next.js 15 App Router and SQLite.

## Use

Copy `CLAUDE.md` into the root of a Next.js + SQLite project before starting Claude Code.

## Coverage

- Stack and versions
- Folder structure
- Naming conventions
- SQL and migration rules
- Data access boundaries
- Component patterns
- Dev commands
- Anti-patterns with reasons

## Validation

I checked the template against the bounty acceptance criteria with `validate-template.mjs`.
