# CLAUDE.md Template: Next.js + SQLite SaaS

## Usage
Copy `CLAUDE.md` to your project root and customize as needed.

## What's included
- Project structure conventions
- Naming conventions
- Database migration rules
- Dev commands
- Patterns to follow
- Anti-patterns to avoid

- Next.js 15 App Router
- SQLite (better-sqlite3 or Turso)
- Drizzle ORM
- TypeScript strict mode
