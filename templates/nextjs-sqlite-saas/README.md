# Next.js + SQLite SaaS CLAUDE.md Template

This folder contains an opinionated `CLAUDE.md` for a greenfield SaaS application using:

- Next.js 15 App Router
- TypeScript
- React Server Components
- SQLite with `better-sqlite3` locally or Turso/libSQL in production
- Zod validation
- pnpm

## Use

```bash
cp templates/nextjs-sqlite-saas/CLAUDE.md /path/to/nextjs-sqlite-app/CLAUDE.md
```

The template gives implementation guidance for structure, naming, migrations, database access, Server Actions, components, auth, testing, and anti-patterns.
