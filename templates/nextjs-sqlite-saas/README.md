# Next.js SQLite SaaS CLAUDE.md Template

## Setup

1. Copy `CLAUDE.md` into the root of a greenfield Next.js 15 App Router + SQLite SaaS project.
2. Confirm the project uses `better-sqlite3`, Turso, or another SQLite-compatible driver.
3. Ask Claude Code to implement one small feature and verify it follows the folder, migration, and component rules.

## Verification

This template was reviewed against a greenfield SaaS structure with:

- App Router route groups
- SQLite migrations
- Server actions
- Server/client component boundaries

The instructions are intentionally opinionated so Claude Code can proceed without asking for generic architecture decisions.
