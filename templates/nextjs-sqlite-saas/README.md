# Next.js + SQLite SaaS CLAUDE.md Template

Opinionated Claude Code project memory for a greenfield SaaS using Next.js 15 App Router and SQLite.

## Use

```bash
cp templates/nextjs-sqlite-saas/CLAUDE.md ./CLAUDE.md
```

Then start Claude Code from the project root. The template gives Claude concrete defaults for structure, migrations, data access, components, Server Actions, testing, environment variables, and anti-patterns.

## Validation Notes

- The template is self-contained and does not rely on project-specific names.
- It was reviewed against a fresh Next.js + SQLite SaaS layout to ensure the expected folders, commands, migration rules, and component patterns are present.
- The rules include reasons so Claude can follow the intent without asking clarifying questions for common greenfield implementation tasks.
