# Production `CLAUDE.md` Template — Next.js 15 App Router + SQLite SaaS

An opinionated, drop-in `CLAUDE.md` designed for greenfield SaaS apps built on Next.js 15 App Router + `better-sqlite3`/Turso + Drizzle ORM.

## Usage
1. Copy `CLAUDE.md` to the root of a new Next.js 15 + SQLite project.
2. Open Claude Code in that directory—all stack versions, SQLite `WAL`/`busy_timeout`/`foreign_keys` pragmas, folder boundaries, Server Action safety rules, and migration workflows are immediately enforced without extra prompting.
