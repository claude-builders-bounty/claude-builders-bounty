# Next.js 15 + SQLite SaaS Template Guidelines (`CLAUDE.md`)

An opinionated, production-ready rulebook for developing full-stack SaaS projects with Next.js 15 App Router, SQLite, and Drizzle ORM.

## Included Guidelines:
- Strict TypeScript configuration and folder conventions.
- Explicit database migration workflow (Drizzle + SQLite).
- Server Components by default with Server Actions.
- Pragmatic anti-pattern warnings to ensure robust AI agent pair programming.
