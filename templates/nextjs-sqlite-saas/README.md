# Next.js + SQLite CLAUDE.md Template

Production-ready [`CLAUDE.md`](CLAUDE.md) for greenfield SaaS projects on **Next.js 15 App Router + SQLite (Turso/Drizzle)**.

## Usage

Copy `templates/nextjs-sqlite-saas/CLAUDE.md` to the root of a new Next.js project:

```bash
cp templates/nextjs-sqlite-saas/CLAUDE.md /path/to/your-app/CLAUDE.md
```

Open the project in Claude Code — the template is opinionated enough that Claude should understand stack, folder layout, and conventions without follow-up questions.

## Sections covered

- Stack & versions (with rationale)
- Folder structure
- Dev commands
- SQL / migration conventions
- Component patterns
- Auth & tenancy rules
- Anti-patterns we avoid
- PR checklist
