# CLAUDE.md Template - Next.js 15 + SQLite SaaS

A production-ready CLAUDE.md template for Next.js 15 App Router projects with SQLite (Drizzle ORM).

## Installation

```bash
cp CLAUDE.md /path/to/your/project/
```

## Features

- Covers development, testing, and database commands
- Code style and TypeScript conventions
- Data access patterns with Drizzle ORM
- Project architecture overview
- Auth setup with NextAuth.js v5
- Environment variable documentation
