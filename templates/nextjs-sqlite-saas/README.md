# Next.js 15 + SQLite SaaS Claude Template

Production-oriented `CLAUDE.md` for a greenfield SaaS built with Next.js 15 App Router and SQLite through `better-sqlite3` or Turso/libSQL.

## Setup

1. Create a new Next.js App Router project.
2. Copy `CLAUDE.md` into the project root.
3. Start Claude Code from that root and ask it to add a feature.

## Validation Notes

This template is written to remove the common clarification loop around:

- App Router vs Pages Router.
- Server Components vs Client Components.
- Where SQL, migrations, validation, and business logic live.
- Which anti-patterns are forbidden and why.

It is intentionally opinionated rather than exhaustive.
