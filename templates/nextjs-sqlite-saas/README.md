# Next.js 15 + SQLite SaaS — CLAUDE.md template

Drop-in **CLAUDE.md** for greenfield SaaS apps (App Router, Drizzle, local SQLite + Turso).

## Use in 3 steps

1. Copy `CLAUDE.md` to your repo root.
2. Set env vars listed in the file (`DATABASE_URL`, `AUTH_SECRET`, …).
3. Open the project in Claude Code — it should default to Server Components, Drizzle migrations, and Server Actions without Pages Router drift.
