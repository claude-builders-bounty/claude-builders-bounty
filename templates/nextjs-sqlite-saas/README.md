# Next.js SQLite SaaS CLAUDE.md Template

Opinionated Claude Code project instructions for a greenfield SaaS built with Next.js 15 App Router and SQLite.

## Setup

1. Copy `CLAUDE.md` to the root of the target project.
2. Align `package.json` scripts with the command names listed in the template.
3. Ask Claude Code to implement a small feature; it should follow the structure, migration, data-access, and component rules without needing extra context.

## Included Files

- `CLAUDE.md` - production-ready project instructions.
- `VALIDATION.md` - smoke-test notes and coverage checklist.
