# Next.js + SQLite SaaS CLAUDE.md Template

This template is for bounty #2: a production-ready `CLAUDE.md` for a greenfield Next.js 15 App Router SaaS project using SQLite.

## Setup

1. Copy `CLAUDE.md` into the root of a Next.js 15 + SQLite project.
2. Update only the package-manager commands if the project does not use `pnpm`.
3. Ask Claude Code to inspect the project and implement a small feature; it should follow the documented folders, SQL rules, Server Action patterns, and safety checks without needing extra context.

## Validation Notes

The template was written against a standard App Router SaaS shape with `src/app`, Server Actions, Zod validation, and SQLite migrations. It includes concrete conventions for project structure, naming, migrations, query boundaries, components, auth, env handling, tests, and anti-patterns.
