# Next.js 15 + SQLite SaaS CLAUDE.md

Opinionated `CLAUDE.md` for a greenfield SaaS app using Next.js 15 App Router and SQLite.

## Setup

1. Copy `templates/nextjs-sqlite-saas/CLAUDE.md` into the root of a new Next.js 15 project.
2. Run Claude Code from that project root.
3. Ask for a feature using the app, database, or server action patterns in the template.

## Validation

This template was checked against the bounty acceptance criteria with `tests/test_nextjs_sqlite_template.py`. The test verifies stack specificity, folder structure, naming conventions, migration rules, dev commands, follow/avoid patterns with reasons, and concrete SQLite/Next.js SaaS guidance.
