# Next.js SQLite SaaS CLAUDE.md Template

An opinionated `CLAUDE.md` for greenfield SaaS projects using Next.js 15 App Router, TypeScript, and SQLite through `better-sqlite3` or Turso/libSQL.

## Use

1. Copy `templates/nextjs-sqlite-saas/CLAUDE.md` to the root of a new project.
2. Adjust package manager command names only if the project already uses different scripts.
3. Start Claude Code from the project root.

The template covers project structure, naming conventions, SQL migrations, database access, App Router patterns, component boundaries, auth, testing, and anti-patterns.
