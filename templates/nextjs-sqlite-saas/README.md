# 📦 Next.js 15 + SQLite SaaS Template for Claude Code

A complete, production-grade `CLAUDE.md` template designed specifically for greenfield Next.js 15 App Router + SQLite SaaS projects.

## 🚀 How to Use

1. Copy `CLAUDE.md` to the root directory of your Next.js project:
   ```bash
   cp templates/nextjs-sqlite-saas/CLAUDE.md ./CLAUDE.md
   ```
2. Start Claude Code in your project root:
   ```bash
   claude
   ```
3. Claude Code will automatically ingest the stack specifications, architectural rules, and SQLite WAL pragmas without requiring clarifying setup questions.
