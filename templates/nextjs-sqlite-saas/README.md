# Next.js 15 + SQLite SaaS CLAUDE.md Template

This template is an opinionated `CLAUDE.md` for a greenfield SaaS project using Next.js 15 App Router and SQLite through `better-sqlite3` or Turso/libSQL.

## Use

1. Copy `templates/nextjs-sqlite-saas/CLAUDE.md` into the root of a new project.
2. Run Claude Code from that project root.
3. Ask for a feature using the project conventions, for example: "Add workspace invitations with a server action and migration."

The file gives Claude Code enough context to choose folders, naming, migration rules, component boundaries, validation, and anti-patterns without asking for generic architecture clarification.
