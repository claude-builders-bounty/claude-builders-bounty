# Next.js 15 + SQLite SaaS CLAUDE.md Template

A production-ready, highly opinionated `CLAUDE.md` template designed specifically for building SaaS products using **Next.js 15 App Router**, **SQLite** (better-sqlite3 / Turso), and **Drizzle ORM**.

---

## 🚀 Quick Setup (2 Steps)

1. **Copy into your project root**:
   ```bash
   cp templates/nextjs-sqlite-saas/CLAUDE.md ./CLAUDE.md
   ```
2. **Launch Claude Code**:
   ```bash
   claude
   ```
   Claude Code will immediately recognize project conventions, database rules, dev commands, and architectural patterns without requiring clarifying prompts.

---

## 📋 Features Included
- Complete Next.js 15 App Router directory map
- Strict SQLite WAL mode and foreign key pragmas
- Drizzle ORM migration workflow commands
- Standardized Server Action return envelope
- Architectural anti-patterns list with concrete rationales
