# Next.js 15 + SQLite SaaS CLAUDE.md Template

A production-ready, opinionated configuration and context file (`CLAUDE.md`) optimized for SaaS projects built with **Next.js 15 App Router**, **SQLite / Turso**, and **Drizzle ORM**.

## Installation

1. Copy `CLAUDE.md` to the root directory of your Next.js project:
   ```bash
   cp templates/nextjs15-sqlite-saas/CLAUDE.md /path/to/your-project/CLAUDE.md
   ```
2. Start Claude Code in your project root:
   ```bash
   claude
   ```
3. Claude Code will automatically ingest the guidelines, architecture conventions, SQLite pragmas, and coding rules.
