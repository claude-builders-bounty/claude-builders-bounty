# Claude PR Review Agent

`claude-review` is a Claude Code PR reviewer agent that accepts a GitHub pull request URL and emits a structured Markdown review comment.

## Setup

```bash
chmod +x bin/claude-review
gh auth login
```

## Usage

```bash
bin/claude-review --pr https://github.com/owner/repo/pull/123
```

Optional file output:

```bash
bin/claude-review --pr https://github.com/owner/repo/pull/123 --output review.md
```

Claude Code can also use the bundled sub-agent at `.claude/agents/pr-reviewer.md`.

## Output Format

The Markdown review always includes:

- Summary of changes
- Identified risks
- Improvement suggestions
- Confidence score: `Low`, `Medium`, or `High`

## Requirements

- Python 3.10+
- GitHub CLI `gh` authenticated for live PR URLs
