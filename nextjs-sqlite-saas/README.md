# Next.js SQLite SaaS CLAUDE.md Template

This folder contains an opinionated `CLAUDE.md` for a greenfield SaaS project
built with Next.js 15 App Router and SQLite.

Use it by copying `CLAUDE.md` into the root of a new project before asking
Claude Code to implement features.

The template covers:

- stack and version assumptions
- folder structure
- naming conventions
- SQLite migration rules
- Server Component and Server Action patterns
- data access rules
- anti-patterns and done criteria
