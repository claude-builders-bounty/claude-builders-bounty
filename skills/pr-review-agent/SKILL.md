# PR Review Agent

A Claude Code sub-agent for automated PR review. Takes a GitHub PR URL,
fetches the diff, and produces a structured Markdown review.

## Trigger

Invoke with:
```
claude-review --pr https://github.com/owner/repo/pull/123
```

Or from within Claude Code:
```
Review PR https://github.com/owner/repo/pull/123
```

## Workflow

1. **Fetch PR data** — `gh pr view <PR_URL> --json title,body,author,additions,deletions,files`
2. **Fetch PR diff** — `gh pr diff <PR_URL>`
3. **Analyze** the diff for:
   - Logic errors, security issues, breaking changes
   - Missing tests, unclear naming, code duplication
   - Adherence to project conventions
4. **Output** a structured Markdown review

## Output Format

```markdown
# PR Review: <PR_TITLE>

**PR:** <URL>
**Author:** <AUTHOR>
**Changes:** +<N> / -<M> lines across <F> files

---

## Summary

<2-3 sentence summary of what this PR does>

## Identified Risks

- **<Risk Category>:** <description>
- ...

## Suggestions

- <suggestion 1>
- <suggestion 2>
- ...

## Confidence Score

**<Low / Medium / High>** — <one-line rationale>

---

*Review generated by PR Review Agent*
```

## Review Guidelines

### What to look for
- **Security**: exposed secrets, injection vectors, missing auth checks
- **Breaking changes**: API signature changes, DB migrations without rollback
- **Error handling**: missing try/catch, swallowed errors, unhandled promises
- **Tests**: new logic without tests, tests that don't assert anything
- **Naming**: confusing variable names, inconsistent conventions
- **Performance**: N+1 queries, unnecessary loops, missing indexes

### What NOT to flag
- Personal style preferences (semicolons, quote style)
- Minor formatting (unless it breaks lint rules)
- Issues already addressed in PR comments

## Confidence Score Guide

| Score | Criteria |
|-------|----------|
| **High** | Clear understanding of the codebase and change intent |
| **Medium** | Some uncertainty about context or side effects |
| **Low** | Significant ambiguity — needs human review |

## Prerequisites

- `gh` CLI authenticated (`gh auth login`)
- Access to the target repository
- (Optional) `ANTHROPIC_API_KEY` for AI-powered review generation
