# Changelog Generator

A Claude Code skill that generates a structured `CHANGELOG.md` from
git commit history.

## Trigger

From Claude Code:
```
/generate-changelog
```

Or via CLI:
```bash
bash scripts/changelog.sh
```

## How It Works

1. Finds the most recent git tag (or first commit if no tags)
2. Collects all commits since that tag
3. Categorizes each commit:
   - **Added**: commits starting with `feat:`, `add:`, `new:`, `introduce:`, `implement:`
   - **Fixed**: commits starting with `fix:`, `bug:`, `hotfix:`, `patch:`, `resolve:`, `correct:`
   - **Removed**: commits starting with `remove:`, `drop:`, `delete:`, `deprecate:`
   - **Changed**: everything else
4. Outputs a formatted `CHANGELOG.md`

## Usage

```bash
# From most recent tag
bash scripts/changelog.sh

# From a specific tag
bash scripts/changelog.sh --since v1.2.0

# Custom output path
bash scripts/changelog.sh --output docs/CHANGELOG.md
```

## Output Format

```markdown
# Changelog

## [v1.3.0] — 2026-05-19

### Added
- feat: add Stripe payment integration
- add: user onboarding flow

### Fixed
- fix: race condition in auth middleware
- bug: resolve 500 error on empty search

### Changed
- refactor: extract validation to shared module
- docs: update API reference

### Removed
- remove: deprecated v1 endpoints

---
*Generated by changelog.sh*
```

## Requirements

- Git repository with tagged releases
- bash + git CLI
