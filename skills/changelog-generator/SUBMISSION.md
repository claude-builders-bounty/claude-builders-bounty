# Issue #1 release evidence

The candidate provides both a Claude Code skill (`SKILL.md`) and a direct user command (`changelog.sh`). The command detects the latest reachable Git tag, reads every non-merge commit after it (or full history when untagged), maps commits into the literal `Added`, `Fixed`, `Changed`, and `Removed` sections, and writes `CHANGELOG.md`.

## Reproduce

```bash
python3 -m pytest -q skills/changelog-generator/tests
bash skills/changelog-generator/changelog.sh /path/to/a/git/repository
```

The regression suite creates real tagged and untagged Git repositories and executes the Bash user path. It also verifies that an invalid tag/repository fails instead of producing an empty success artifact. `SAMPLE_OUTPUT.md` is generated by the submitted implementation against the public `github.com/claude-builders-bounty/claude-builders-bounty` repository at source HEAD `1aeae2adc82d33f971fd7731644348dcdd24b5a6` with no reachable tag.
