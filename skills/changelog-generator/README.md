# CHANGELOG Generator — Claude Code Skill

Generate structured `CHANGELOG.md` from git history automatically.

## Setup

```bash
# 1. Install
cp -r skills/changelog-generator ~/.claude/skills/

# 2. Use in any repo
cd /path/to/your/repo
/generate-changelog
```

## Requirements

- Git with tags
- Bash 4+

That's it. Two steps, zero dependencies.
