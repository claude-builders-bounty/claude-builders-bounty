# Changelog Generator

Generates `CHANGELOG.md` from git history since the last tag.

## Setup

```bash
chmod +x skills/changelog-generator/changelog.sh
```

## Usage

```bash
# Bash
./skills/changelog-generator/changelog.sh

# Python
python3 skills/changelog-generator/changelog.py

# Claude Code
/generate-changelog
```

Outputs `CHANGELOG.md` in the current directory.
