# Git CHANGELOG Generator

A Python script that generates a structured CHANGELOG.md file from your git commit history.

## Features

- ✅ Supports **Conventional Commits** format
- ✅ Groups commits by type (Features, Bug Fixes, Documentation, etc.)
- ✅ Sorts commits chronologically (newest first)
- ✅ Clean markdown output
- ✅ Customizable output filename
- ✅ Limit number of commits to process

## Installation

Simply copy `git_changelog_generator.py` to your project directory.

## Usage

### Basic usage:
```bash
python git_changelog_generator.py
