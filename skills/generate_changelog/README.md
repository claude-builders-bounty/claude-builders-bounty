# Git CHANGELOG Generator

Generates a structured `CHANGELOG.md` file from git history categorized into `Added`, `Fixed`, `Changed`, and `Removed` sections.

## Quick Setup (3 Steps)

1. Copy the script to your project:
   ```bash
   cp skills/generate_changelog/changelog.py ./changelog.py
   ```
2. Make it executable:
   ```bash
   chmod +x ./changelog.py
   ```
3. Generate CHANGELOG:
   ```bash
   python3 ./changelog.py
   ```
