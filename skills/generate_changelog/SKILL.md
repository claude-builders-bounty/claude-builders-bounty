# Generate Structured CHANGELOG

Generates a clean `CHANGELOG.md` file from git commits since the last tag.

## Usage

Run via slash command:
```bash
/generate-changelog
```

Or run directly via python script:
```bash
python3 skills/generate_changelog/changelog.py
```
