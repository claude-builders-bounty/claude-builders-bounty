# Generate Changelog Skill & Tool

Automatically generate a clean, structured `CHANGELOG.md` from git history, grouped into **Added**, **Fixed**, **Changed**, and **Removed**.

## Quick Start (3 Steps)

1. **Copy into your repository:**
   Place the files in `.claude/skills/generate-changelog/` or your project root.

2. **Run the generator:**
   * In **Claude Code**: run `/generate-changelog`
   * Or in **Terminal**:
     ```bash
     bash changelog.sh
     ```

3. **View your updated `CHANGELOG.md`:**
   Your structured changelog is automatically created or updated with commits since the latest git tag!
