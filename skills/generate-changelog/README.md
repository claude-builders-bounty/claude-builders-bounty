# Generate a structured CHANGELOG from git history

A Claude Code skill + standalone bash script that turns a project's git history
into a structured `CHANGELOG.md`, auto-categorized into **Added / Fixed / Changed / Removed**.

Built for bounty [claude-builders-bounty#1](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/1).

## Setup (3 steps)

1. Copy `changelog.sh` (and optionally `SKILL.md`) into your repo.
2. `chmod +x changelog.sh`
3. Run it: `bash changelog.sh` → writes `CHANGELOG.md`.

## Usage

```bash
bash changelog.sh                                   # since last tag -> HEAD
bash changelog.sh --from v1.2.0 --version 1.3.0     # explicit range + heading
bash changelog.sh --out docs/CHANGELOG.md           # custom output path
```

As a Claude Code skill, drop `SKILL.md` into `.claude/skills/generate-changelog/`
and invoke `/generate-changelog`.

## How categorization works

| Category | Conventional prefix | Keyword fallback |
|----------|--------------------|------------------|
| **Added**   | `feat:` `feature:` | add, implement, introduce, support, create |
| **Fixed**   | `fix:` | fix, bug, patch |
| **Changed** | `perf:` `refactor:` `style:` `chore:` `build:` `ci:` `docs:` | (default bucket) |
| **Removed** | `remove:` `revert:` `deprecate:` | remove, delete, revert, drop |
