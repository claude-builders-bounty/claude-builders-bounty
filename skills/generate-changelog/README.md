# generate-changelog — setup (3 steps)

1. Copy `changelog.sh` to your repo root and `chmod +x changelog.sh`.
2. Optional: copy `skills/generate-changelog/SKILL.md` into your skills folder for `/generate-changelog`.
3. Run `bash changelog.sh` (writes `CHANGELOG.md`) or `bash changelog.sh path/to/out.md`.

See `samples/CHANGELOG.sample.md` for output from a real git history.
