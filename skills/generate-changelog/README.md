# Generate Changelog

A simple bash script to automatically generate a structured `CHANGELOG.md` from a project's git history since the last tag.

## Setup Instructions

1. Make the script executable:
   ```bash
   chmod +x changelog.sh
   ```

2. Run the script in the root of any git repository:
   ```bash
   ./changelog.sh
   ```

3. View your freshly generated `CHANGELOG.md` file!
