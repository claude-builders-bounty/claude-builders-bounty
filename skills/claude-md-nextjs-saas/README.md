# CLAUDE.md Next.js + SQLite SaaS — Usage

This is a drop-in `CLAUDE.md` for Next.js 15 App Router + SQLite SaaS projects.

## Setup

1. Copy to your project root:
   ```bash
   cp skills/claude-md-nextjs-saas/CLAUDE.md /your/project/CLAUDE.md
   ```

2. Open Claude Code in your project:
   ```bash
   cd /your/project && claude
   ```

3. Claude will automatically read `CLAUDE.md` on startup and follow the conventions.

## Customization

Edit the stack versions and environment variable names to match your project. Everything else is framework-level guidance that applies to any Next.js + SQLite SaaS.
