# SKILL.md — Generate Changelog

Generate a structured `CHANGELOG.md` from a project's git history.

## Usage

```bash
bash scripts/changelog/generate-changelog.sh [since-tag]
```

Or if using as a standalone script:

```bash
cd /path/to/repo
bash generate-changelog.sh v1.0.0
```

## Setup (3 steps)

1. Copy `scripts/changelog/generate-changelog.sh` to your project
2. Make it executable: `chmod +x generate-changelog.sh`
3. Run: `bash generate-changelog.sh` (optionally pass a tag like `v1.0.0`)

## Features

- **Auto-categorises** commits into: Added / Fixed / Changed / Removed
- **Tag-aware**: uses last git tag as start point by default
- **Conventional commit support**: parses `feat:`, `fix:`, `chore:`, etc.
- **Markdown table output**: commit hash + description
- **Merges with existing CHANGELOG.md** (preserves history)
- **Zero dependencies**: pure bash + standard Unix tools

## Output

Generates `CHANGELOG.md` with:
```markdown
# Changelog

_Generated by generate-changelog.sh_

## YYYY-MM-DD

### Added
| Commit | Description |
|--------|-------------|
| `abc1234` | Add user authentication |

### Fixed
...

### Changed
...

### Removed
...
```

## Testing

Run against any git repo:
```bash
cd /tmp && git clone https://github.com/example/repo.git && cd repo && bash /path/to/generate-changelog.sh && cat CHANGELOG.md
```
