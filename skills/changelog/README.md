# 📋 changelog.sh — Auto-generate CHANGELOG from git history

Generate a structured `CHANGELOG.md` from your project's git history in one command.

## Setup (2 steps)

1. **Download** — save [`changelog.sh`](./changelog.sh) to your project root
2. **Run** — `bash changelog.sh`

That's it. No dependencies beyond `git` and `bash`.

## Usage

```bash
# In your project directory
bash changelog.sh

# Or point to any git repo
bash changelog.sh /path/to/project
```

## Features

- ✅ Auto-detects last git tag as version anchor
- ✅ Categorizes commits by conventional-commit type:
  - **Added** — `feat:`, `feature:`
  - **Fixed** — `fix:`, `bug:`, `hotfix:`
  - **Changed** — `chore:`, `refactor:`, `perf:`, `docs:`, `style:`, `test:`, `ci:`, `build:`
  - **Removed** — `remove:`, `deprecat:`
- ✅ Strips conventional-commit prefixes for clean output
- ✅ Handles scoped commits (`feat(auth):`)
- ✅ Works on repos with or without tags
- ✅ Appends uncategorized commits at the bottom
- ✅ Pure bash — no Node, Python, or npm required

## Example Output

