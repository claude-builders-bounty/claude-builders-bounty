## 🚀 Setup in 3 Steps

```bash
# 1. Download
curl -sfL https://raw.githubusercontent.com/claude-builders-bounty/claude-changelog-skill/main/changelog.sh \
  -o /usr/local/bin/changelog.sh
chmod +x /usr/local/bin/changelog.sh

# 2. Run in any git repo
cd /path/to/your/repo
bash changelog.sh

# 3. Or use specific tags
bash changelog.sh v1.0.0
bash changelog.sh v1.0.0 v2.0.0
```

## 🔧 Usage

| Command | Description |
|---------|-------------|
| `bash changelog.sh` | Auto-detect latest tag → HEAD |
| `bash changelog.sh v1.0.0` | v1.0.0 → HEAD |
| `bash changelog.sh v1.0.0 v2.0.0` | Range: v1.0.0 → v2.0.0 |

### As a Claude Code Skill

Run `/generate-changelog` (requires the SKILL.md) or just call the script directly:

```bash
claude -p "Run bash changelog.sh to generate the changelog"
```

## 📋 Output Format

```markdown
# Changelog

## [v2.1.0] - 2026-05-16

### ⚠️ Breaking Changes
  - 1 breaking change(s) introduced

*12 commits — +4 / !1 / ~7*

### Added
  - Add user authentication middleware ([a1b2c3d](https://...))

### Fixed
  - Fix null pointer in payment handler ([e4f5g6h](https://...))

### Changed
  - Refactor database connection pooling ([i7j8k9l](https://...))

---
*Generated by changelog.sh*
```

## 📦 Categorization

| Category | Conventional Commit | Keywords |
|----------|-------------------|----------|
| **Added** | `feat:` | add, new, create, implement |
| **Fixed** | `fix:` | fix, correct, resolve, patch |
| **Changed** | `refactor:`, `style:` | update, change, improve |
| **Removed** | — | remove, delete, drop |
| **Deprecated** | `deprecat` | deprecate |
| **Security** | — | sec, vuln, cve |
| **Performance** | `perf:` | perf, speed, optimize |
| **Documentation** | `docs:` | doc, readme |
| **Internal** | `test:`, `chore:`, `ci:` | test, chore, ci, build |
