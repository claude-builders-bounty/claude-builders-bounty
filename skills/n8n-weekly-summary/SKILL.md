# n8n Weekly Dev Summary

An n8n workflow that automatically generates a weekly narrative summary of a GitHub repo's activity.

## What It Does

1. **Triggers** every Friday at 5:00 PM (cron)
2. **Fetches** from GitHub API:
   - Commits from the past week
   - Closed issues (filtered to exclude PRs)
   - Merged PRs
3. **Aggregates** data into a structured summary object
4. **Calls Claude API** (`claude-sonnet-4-20250514`) to generate a narrative
5. **Outputs** a formatted Markdown summary ready for posting

## Installation

1. Open n8n and go to **Workflows → Import from File**
2. Select `n8n/weekly-dev-summary.json`
3. Configure the **Set Repo URL** node — replace `REPO_OWNER/REPO_NAME` with your repo
4. Add a **Header Auth** credential for GitHub (token with `repo` scope)
5. Set the `ANTHROPIC_API_KEY` environment variable in n8n settings
6. Activate the workflow

## Nodes (8 total)

| Node | Type | Purpose |
|------|------|---------|
| Friday 5pm | Schedule Trigger | Weekly cron (Fri 17:00) |
| Set Repo URL | Code | Calculate week range, set repo |
| Fetch Commits | HTTP Request | GitHub commits API |
| Fetch Closed Issues | HTTP Request | GitHub issues API |
| Fetch Merged PRs | HTTP Request | GitHub pulls API |
| Aggregate Data | Code | Normalize all 3 API responses |
| Build Prompt | Code | Construct Claude prompt |
| Call Claude API | HTTP Request | Anthropic Messages API |
| Format Output | Code | Add header, final formatting |
