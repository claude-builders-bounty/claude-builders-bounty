# 📅 n8n Weekly Dev Summary with Claude

Automatically generates a narrative weekly summary of your GitHub repository's activity using the Claude API.

## Features

- ✅ **Weekly cron** — Runs every Friday at 5 PM (configurable)
- ✅ **GitHub data** — Fetches commits, closed issues, and merged PRs from the past 7 days
- ✅ **AI summary** — Uses `claude-sonnet-4-20250514` to write a narrative
- ✅ **Multi-channel** — Send to Slack, Discord, or Email
- ✅ **Configurable** — Change repo, language (English/French), destination channel
- ✅ **Importable** — One-click `.json` import into n8n

## Setup (5 steps)

### 1. Import the workflow

1. Open your n8n instance
2. Go to **Workflows** → **Add Workflow** → **Import from File**
3. Select `n8n-weekly-summary.json`

### 2. Configure GitHub credentials

1. Create a GitHub PAT: [github.com/settings/tokens](https://github.com/settings/tokens) (needs `repo` scope)
2. In n8n, go to **Settings** → **Credentials** → **Add Credential**
3. Select **GitHub API**, paste your PAT

### 3. Set Claude API key

1. Add your Anthropic API key as an n8n credential:
   - **Type:** Header Auth
   - **Name:** `x-api-key`
   - **Value:** `sk-ant-...`

### 4. Configure variables

Edit the workflow variables at the top of the **Set Variables** node:

| Variable | Example | Description |
|---|---|---|
| `repoOwner` | `vercel` | GitHub repository owner |
| `repoName` | `next.js` | GitHub repository name |
| `destination` | `slack` | `slack`, `discord`, or `email` |
| `language` | `en` | `en` for English, `fr` for French |
| `webhookUrl` | `https://hooks.slack.com/...` | Discord/Slack webhook URL |
| `emailTo` | `team@company.com` | Email recipient (if using email) |

### 5. Activate the workflow

1. Click **Save**
2. Toggle **Active** on
3. Click **Execute Workflow** to test it immediately

## Requirements

- n8n v1.60+ (or n8n.cloud account)
- GitHub Personal Access Token
- Anthropic API key

## Customization

### Change the schedule
Edit the **Schedule Trigger** node's cron expression. Default: `0 17 * * 5` (Friday 5 PM).

### Add more channels
The workflow uses a **Switch** node to route the output. Add a new channel by adding a case and the corresponding n8n node (e.g., Telegram, Microsoft Teams).

### Change the Claude model
Modify the `model` parameter in the **HTTP Request - Claude API** node.
