# Changelog Generator

One-command structured CHANGELOG.md from git history.

## Installation

```bash
pip install -r requirements.txt  # None required, stdlib only
```

## Usage

```bash
python skills/generate-changelog.py
```

## Features
- Auto-detects last git tag
- Categorizes commits: Added/Fixed/Changed/Removed
- Follows conventional commits
- Pure Python, no dependencies
