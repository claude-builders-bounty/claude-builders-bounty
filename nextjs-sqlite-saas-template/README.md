# Next.js + SQLite SaaS CLAUDE.md Template

Opinionated `CLAUDE.md` for a greenfield SaaS built with Next.js 15 App Router and SQLite.

## Use

1. Copy `CLAUDE.md` to the root of your Next.js + SQLite project.
2. Adjust only the database driver line if you use Turso/libSQL instead of `better-sqlite3`.
3. Start Claude Code from the project root.

The template covers structure, commands, naming, migrations, database access, server actions, components, auth, testing, and anti-patterns with reasons.
