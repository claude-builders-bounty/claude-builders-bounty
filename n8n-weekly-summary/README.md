# 📊 Weekly Dev Summary — n8n + Claude Code Workflow

> Automated weekly narrative summary of GitHub repo activity, generated by Claude and delivered to your team.  
> Part of the [Claude Builders Bounty](https://github.com/claude-builders-bounty) program — Issue #5.

## What it does

Every Friday at 5pm, this n8n workflow:

1. **Fetches** commits, closed issues, and merged PRs from your GitHub repo (last 7 days)
2. **Processes** the data into a structured prompt
3. **Calls Claude API** (`claude-sonnet-4-20250514`) to generate a narrative summary
4. **Delivers** the summary via Slack, Discord, or Email

## Setup (5 steps)

### 1. Install n8n

```bash
npm install -g n8n
n8n start
# Open http://localhost:5678
```

### 2. Import the workflow

- Go to **Workflows → Import from File**
- Select `workflow.json`

### 3. Configure variables

Open the **Set Config** node and fill in:

| Variable | Description | Example |
|----------|-------------|---------|
| `repo` | GitHub owner/repo | `my-org/my-project` |
| `github_token` | GitHub personal access token | `ghp_xxxx` |
| `anthropic_key` | Anthropic API key | `sk-ant-xxxx` |
| `language` | Summary language | `EN` or `FR` |
| `delivery_method` | `slack`, `discord`, or `email` | `slack` |
| `slack_webhook` | Slack incoming webhook URL | (if using Slack) |
| `discord_webhook` | Discord webhook URL | (if using Discord) |
| `resend_key` | Resend API key | (if using email) |
| `email_from` | Sender email | (if using email) |
| `email_to` | Recipient email | (if using email) |

### 4. Activate the workflow

Toggle the **Active** switch (top-right in n8n editor).

### 5. Test

Click **Execute Workflow** to test immediately.

## Workflow structure (9 nodes)

```
[Cron: Fri 5pm] → [Set Config] → [Fetch Commits] → [Fetch Issues] → [Fetch PRs]
    → [Prepare Prompt] → [Claude API] → [Format Summary] → [Deliver Summary]
```

### Nodes

| Node | Type | Purpose |
|------|------|---------|
| Every Friday 5pm | Schedule Trigger | Weekly cron trigger |
| Set Config | Set | All configurable parameters in one place |
| Fetch Commits | HTTP Request | GitHub API — commits since last week |
| Fetch Closed Issues | HTTP Request | GitHub API — closed issues |
| Fetch Merged PRs | HTTP Request | GitHub API — merged PRs |
| Prepare Claude Prompt | Code | Merge data into structured prompt |
| Call Claude API | HTTP Request | Anthropic API — generate summary |
| Format Summary | Code | Extract Claude's response, add footer |
| Deliver Summary | Code | Send to Slack, Discord, or Resend email based on config |

## Requirements

- n8n instance (self-hosted or cloud)
- GitHub personal access token (repo scope)
- Anthropic API key
- Delivery destination: Slack webhook, Discord webhook, or Resend API key

## Customization

- **Change schedule**: Edit the Cron node → change `0 17 * * 5` to your preferred cron expression
- **Add more repos**: Duplicate the Fetch nodes for each additional repo and extend the prompt assembly in the Code node
- **Change summary format**: Edit the prompt template in the "Prepare Claude Prompt" Code node
- **Use a different model**: Change `model` in the "Call Claude API" node
- **Change delivery**: Set `delivery_method` to `slack`, `discord`, or `email`

## Validation

- `workflow.json` is valid JSON and imports as a single n8n workflow.
- The workflow uses a sequential execution path so each node can reliably reference prior node output.
- Delivery is centralized in one Code node to avoid invalid empty webhook URLs for inactive channels.
