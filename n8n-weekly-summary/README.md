# n8n Weekly Dev Summary

Automated weekly development summary powered by Claude API + GitHub.

## What It Does

Every Friday at 5pm, this workflow:
1. Fetches the week's commits, merged PRs, and closed issues from GitHub
2. Sends the data to Claude API for narrative analysis
3. Delivers the summary via Discord webhook and/or email

## 5-Step Setup

### 1. Import the workflow
In n8n, go to **Workflows → Import from File** and select `workflow.json`.

### 2. Set up GitHub credentials
- Go to **Settings → Credentials → Add Credential → Header Auth**
- Name: `GitHub Token`
- Header Name: `Authorization`
- Header Value: `token ghp_your_github_token_here`

### 3. Configure variables
In the workflow, set these variables (click the workflow canvas → Variables):

| Variable | Description | Example |
|----------|-------------|---------|
| `GITHUB_OWNER` | Repo owner | `anthropics` |
| `GITHUB_REPO` | Repo name | `claude-code` |
| `ANTHROPIC_API_KEY` | Claude API key | `sk-ant-...` |
| `DISCORD_WEBHOOK_URL` | Discord webhook (optional) | `https://discord.com/api/webhooks/...` |
| `TO_EMAIL` | Email recipient (optional) | `team@example.com` |
| `FROM_EMAIL` | Sender email | `noreply@example.com` |
| `LANGUAGE` | Output language | `EN` or `FR` |

### 4. Activate the workflow
Toggle the workflow to **Active** in the top-right corner.

### 5. Test manually
Click **Test Workflow** to run it immediately and verify the output.

## Customization

### Change the schedule
Edit the "Weekly Trigger" node. Current: Friday 5pm. Change to any cron schedule.

### Add Slack delivery
Add an HTTP Request node after "Format Output" with your Slack webhook URL.

### Change the AI prompt
Edit the "Call Claude API" node's JSON body to customize the summary style.

## Requirements

- n8n instance (self-hosted or cloud)
- GitHub personal access token with `repo` scope
- Anthropic API key
- Discord webhook OR email SMTP credentials
