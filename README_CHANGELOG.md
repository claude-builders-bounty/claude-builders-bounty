# changelog.sh — Structured CHANGELOG Generator

Generates a `CHANGELOG.md` from your project's git history using conventional commits.

## Usage

```bash
# In your project directory:
bash changelog.sh

# Or specify output:
bash changelog.sh --output CHANGELOG.md
```

## How It Works

1. Fetches commits since the last git tag
2. Auto-categorizes by commit type into: **Added** / **Fixed** / **Changed** / **Removed**
3. Outputs a properly formatted `CHANGELOG.md` with commit links

## Example Output

```markdown
# Changelog

## [Unreleased]

### Added
- user authentication with NextAuth.js ([a1b2c3d](...))

### Fixed
- database connection timeout ([e4f5g6h](...))

### Changed
- upgrade to Next.js 15 ([i7j8k9l](...))

_Generated by changelog.sh_
```

## Requirements

- Git
- Bash 4+
