# Claude PR Reviewer (Bounty #4)

A Python CLI tool that takes a GitHub Pull Request URL, fetches the code diff using the `gh` CLI, and calls the Anthropic API to generate a structured PR review in Markdown.

## Features
- **Zero Heavy Dependencies**: Written in pure Python 3 using standard libraries (`urllib`, `subprocess`). No need to install `requests` or an external SDK.
- **Fast diff fetching**: Uses `gh pr diff` locally to get the exact changes securely.
- **Structured Outputs**: Forces Claude to strictly output: Summary, Risks, Improvements, and Confidence Score.

## Prerequisites
1. [GitHub CLI (`gh`)](https://cli.github.com/) installed and authenticated (`gh auth login`).
2. An Anthropic API key.

## Installation & Usage

1. Copy the script and make it executable:
```bash
chmod +x claude-review.py
```

2. Export your API key:
```bash
export ANTHROPIC_API_KEY="sk-ant-api03-..."
```

3. Run the reviewer against any PR URL:
```bash
./claude-review.py --pr https://github.com/owner/repo/pull/123
```
