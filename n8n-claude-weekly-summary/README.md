# 📊 n8n + Claude Code — Weekly Dev Summary

An n8n workflow that automatically generates a weekly narrative summary of a GitHub repo's activity, powered by Claude API.

## ✨ Features

- **Weekly cron trigger** (configurable day/time)
- **Fetches from GitHub API**: commits, closed issues, merged PRs
- **Calls Claude API** (`claude-sonnet-4-20250514`) for narrative generation
- **Delivers via Discord webhook** (or email — configurable)
- **Configurable**: repo, channel, language (EN/FR)

## 🚀 Setup (5 Steps)

### 1. Install n8n
```bash
npm install -g n8n
n8n start
```
Or use Docker: `docker run -it --rm -p 5678:5678 n8nio/n8n`

### 2. Import the Workflow
1. Open n8n at `http://localhost:5678`
2. Click **Workflows → Import from File**
3. Select `workflows/weekly-dev-summary.json`

### 3. Add Credentials
| Credential | How to Get |
|------------|-----------|
| **GitHub API** | Settings → Credentials → Add → GitHub → Paste your [GitHub token](https://github.com/settings/tokens) |
| **Anthropic API** | Settings → Credentials → Add → Anthropic → Paste your [Claude API key](https://console.anthropic.com) |

### 4. Configure Environment Variables
In n8n Settings → Variables, add:
```
GITHUB_OWNER = your-org-or-username
GITHUB_REPO  = your-repo-name
DISCORD_WEBHOOK_URL = https://discord.com/api/webhooks/...
SUMMARY_LANGUAGE = English    # or "French"
```

### 5. Activate
1. Open the workflow
2. Click **Active** toggle
3. The workflow runs automatically every Friday at 5:00 PM

## 🏗️ Workflow Architecture

```
Weekly Trigger (Friday 5PM)
    ↓
Set Date Range (last 7 days)
    ↓
┌─────────────┬─────────────┬─────────────┐
│ Get Commits │ Get Issues  │ Get PRs     │
│  (GitHub)   │  (GitHub)   │  (GitHub)   │
└─────────────┴─────────────┴─────────────┘
    ↓
Merge & Format Data
    ↓
Claude API (narrative summary)
    ↓
Discord Webhook (delivery)
```

## 🔧 Customization

### Change Delivery Method
Replace the **Discord Webhook** node with:
- **Email** (SMTP node)
- **Slack** (Slack node)
- **Telegram** (Telegram node)

### Change Schedule
Edit the **Weekly Trigger** node:
- Field: `weeks` → change to `days` for daily
- Or use `cron` expression: `0 17 * * 5` (Friday 5PM)

### Change Language
Set `SUMMARY_LANGUAGE` variable:
- `English` — default
- `French` — summaries in French
