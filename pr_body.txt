/claim #3

## Solution
A Python pre-tool-use hook for Claude Code that intercepts and blocks dangerous bash commands.

### Files
- pre-tool-use.py - main hook script (JSON stdin/stdout format)
- HOOK_README.md - 2-command install guide

### Blocked Patterns
- rm -rf / sudo rm -rf
- DROP TABLE / TRUNCATE
- DELETE FROM without WHERE
- git push --force / -f
- dd to block devices / mkfs
- fork bombs
- chmod -R 777 / / chown -R /

### Behavior
- Blocks dangerous commands with clear message
- Logs blocked attempts to ~/.claude/hooks/blocked.log
- Passes through normal commands

### Tested
rm -rf /tmp/test -> BLOCKED
npm install express -> ALLOWED
