# generate-changelog ($50 Opire bounty)

## Setup (3 steps)

1. Copy `changelog.sh` to your repo root (and optionally `skills/generate-changelog/SKILL.md` into your Claude skills folder).
2. `chmod +x changelog.sh`
3. Run `bash changelog.sh` (or invoke Claude with `/generate-changelog`).

## Claude Code

Place `skills/generate-changelog/SKILL.md` where your Claude Code skills live, then run `/generate-changelog`.
