# CLAUDE.md for Next.js 15 + SQLite SaaS

This directory contains a production-ready `CLAUDE.md` template for Next.js 15 SaaS projects using SQLite (better-sqlite3) + Drizzle ORM.

## Usage

1. Copy `CLAUDE.md` to the root of your Next.js 15 project
2. Claude Code will read it automatically

## What It Covers

| Section | What's Included |
|---------|----------------|
| Stack & Versions | Exact versions and rationale for each technology choice |
| Project Structure | Directory layout with explanations for each folder |
| Conventions | TypeScript, React, Database, API, Git conventions |
| SQL/Migration Rules | 5 hard rules for safe database migrations |
| Component Patterns | Code examples: page, server action, client form |
| Anti-patterns | 9 things we don't do and why |
| Dev Commands | Quick reference for all common commands |

## Validation

Tested by creating a fresh `create-next-app` project, placing this `CLAUDE.md` at the root, and verifying that Claude Code correctly understands the project context without asking clarifying questions.
