# claude-review — AI PR Reviewer

> 🤖 An AI-powered CLI agent that analyzes GitHub PR diffs and returns a structured Markdown review comment.

Built for [Bounty #4](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/4) — $150 via Opire.

---

## Features

- 📋 **Structured reviews** — Summary, Risks, Suggestions, Confidence Score
- 🚀 **Zero dependencies** — Pure Node.js, no npm install needed
- 🔌 **Multi-provider** — Claude (Anthropic), Gemini, or Groq
- 🛠️ **GitHub Action** — Drop-in workflow for automated reviews on every PR
- 📦 **Auto-fetches diffs** — Uses `gh` CLI or GitHub API automatically

## Quick Start

### Prerequisites

- Node.js 18+ (`node --version`)
- `gh` CLI (optional but recommended) — [install](https://cli.github.com/)
- An API key for your chosen provider

### Installation

```bash
# Clone or download
curl -fsSL https://raw.githubusercontent.com/pino12033/claude-builders-bounty/main/bounties/issue-4-pr-reviewer/claude-review.js \
  -o claude-review.js
chmod +x claude-review.js

# Optional: install globally
sudo cp claude-review.js /usr/local/bin/claude-review
```

## Usage

### CLI

```bash
# Using Claude (Anthropic) — recommended
export ANTHROPIC_API_KEY=sk-ant-...
node claude-review.js --pr https://github.com/owner/repo/pull/123

# Using Groq (free tier available)
export GROQ_API_KEY=gsk_...
node claude-review.js --pr https://github.com/owner/repo/pull/123 --provider groq

# Using Gemini
export GEMINI_API_KEY=AIza...
node claude-review.js --pr https://github.com/owner/repo/pull/123 --provider gemini

# JSON output (for piping/automation)
node claude-review.js --pr https://github.com/owner/repo/pull/123 --json

# Verbose debug output
node claude-review.js --pr https://github.com/owner/repo/pull/123 --verbose
```

### Full options

```
claude-review — AI-powered PR reviewer

USAGE:
  claude-review --pr <github-pr-url> [options]

OPTIONS:
  --pr <url>          GitHub PR URL (required)
  --provider <name>   LLM provider: anthropic (default) | gemini | groq
  --model <name>      Override default model
  --json              Output raw JSON instead of Markdown
  --verbose, -v       Print debug info
  --help, -h          Show this help

ENVIRONMENT VARIABLES:
  ANTHROPIC_API_KEY   Required when using --provider anthropic
  GEMINI_API_KEY      Required when using --provider gemini
  GROQ_API_KEY        Required when using --provider groq
  GITHUB_TOKEN        Optional — increases GitHub API rate limits
```

## GitHub Action

Add this workflow to your repo at `.github/workflows/claude-review.yml`:

```yaml
name: Claude PR Review

on:
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  contents: read
  pull-requests: write

jobs:
  pr-review:
    name: AI Code Review
    runs-on: ubuntu-latest
    steps:
      - name: Download claude-review
        run: |
          curl -fsSL https://raw.githubusercontent.com/pino12033/claude-builders-bounty/main/bounties/issue-4-pr-reviewer/claude-review.js \
            -o claude-review.js

      - name: Run AI PR Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          node claude-review.js \
            --pr "https://github.com/${{ github.repository }}/pull/${{ github.event.pull_request.number }}" \
            > review-output.md

      - name: Post review comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const review = fs.readFileSync('review-output.md', 'utf8');
            await github.rest.issues.createComment({
              owner: context.repo.owner,
              repo: context.repo.repo,
              issue_number: context.issue.number,
              body: review,
            });
```

**Required secrets**: Add `ANTHROPIC_API_KEY` in your repo's Settings → Secrets → Actions.

## How It Works

```
┌─────────────────────────────────────────────────────────┐
│                    claude-review                         │
│                                                          │
│  1. Parse --pr URL → owner/repo/number                  │
│  2. Fetch diff (gh CLI or GitHub API)                   │
│  3. Fetch PR metadata (title, author, stats)            │
│  4. Build structured analysis prompt                    │
│  5. Call LLM (Claude / Gemini / Groq)                   │
│  6. Format output as Markdown review                    │
│  7. Print to stdout                                     │
└─────────────────────────────────────────────────────────┘
```
