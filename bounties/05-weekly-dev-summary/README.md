# Weekly Dev Summary — n8n + Claude

Automated weekly narrative digest of a GitHub repo's activity, generated by Claude and posted to Slack (or Discord/email — swap the last node).

Bounty: [#5](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/5)

## What it does

Every **Friday at 17:00**, the workflow:

1. Pulls the last 7 days of **commits**, **merged PRs**, and **closed issues** from a configured GitHub repo.
2. Sends the aggregated activity to **Claude (`claude-sonnet-4-20250514`)** with a structured prompt.
3. Posts a markdown narrative summary to your **Slack webhook** (configurable: Discord, email, etc.).
4. Supports **EN/FR** via the `SUMMARY_LANGUAGE` env var.

## Setup (5 steps)

1. **Import** `workflow/weekly-dev-summary.json` into your n8n instance (Workflows → Import from File).
2. **Create credentials** — Settings → Credentials → New → "Header Auth":
   - Name: `GitHub PAT`
   - Header name: `Authorization`
   - Header value: `Bearer ghp_yourGitHubPersonalAccessToken`
3. **Set environment variables** on the n8n host (see [`docs/env.md`](docs/env.md)):
   ```
   GITHUB_REPO=owner/repo
   ANTHROPIC_API_KEY=sk-ant-...
   SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
   SUMMARY_LANGUAGE=EN     # or FR
   ```
4. **Test once** — open the workflow, click "Execute Workflow" to verify a summary lands in Slack.
5. **Activate** the workflow (toggle top-right). Done — it now runs every Friday at 5pm.

## Customization quick hits

- **Discord webhook**: same HTTP POST node, change body to `{ "content": "..." }` and point at Discord webhook URL.
- **Email**: replace the final node with n8n's "Send Email" node, pipe `$json.text` into the body.
- **Multi-repo**: duplicate the three GitHub HTTP nodes per repo, merge before aggregation, or split into one workflow per repo.
- **Different cadence**: edit the cron expression in the trigger node (default `0 17 * * 5` = Fri 5pm).

## Architecture

```
Cron (Fri 5pm)
   └─> Config (env → vars)
        ├─> GitHub /commits
        ├─> GitHub /pulls?state=closed
        └─> GitHub /issues?state=closed
              └─> Aggregate (filter by date, normalize)
                    └─> Claude (claude-sonnet-4-20250514)
                          └─> Format (header + counts + summary)
                                └─> Slack webhook
```
