# Next.js + SQLite CLAUDE.md template

## Install
1. Copy `CLAUDE.md` to the root of a Next.js 15 App Router SaaS project using SQLite.
2. Update command names only if your package scripts differ.
3. Start Claude Code from the project root and ask it to implement a small feature or migration.

## Test performed
This template was checked against a greenfield Next.js 15 + SQLite SaaS structure: it gives Claude concrete stack, folder, migration, DB, auth, component, and anti-pattern rules without requiring follow-up questions about project conventions.
