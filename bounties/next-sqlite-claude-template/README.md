# Next.js + SQLite CLAUDE.md Template

Opinionated `CLAUDE.md` for a greenfield SaaS app built with Next.js 15 App Router and SQLite through `better-sqlite3` or Turso/libSQL.

## Setup

1. Copy `CLAUDE.md` to the root of a Next.js 15 + SQLite project.
2. Add the scripts listed in the Dev Commands section to `package.json` if they are missing.
3. Start Claude Code from the project root and ask for a small feature or schema change.

## What It Covers

- Stack and version assumptions
- Folder structure
- Naming conventions
- SQLite migration rules
- Data access boundaries
- App Router and Server Action patterns
- Component patterns
- Auth, testing, logging, and security rules
- Anti-patterns with reasons

## Validation

See `validation.md` for the greenfield project check and a context-readiness prompt.
