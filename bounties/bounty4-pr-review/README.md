# 🤖 Claude Code PR Review Agent

> **Bounty #4** — AI-powered structured code review for any GitHub PR.

## Features

- **CLI mode**: Review any PR: `claude-review --pr https://github.com/owner/repo/pull/123`
- **GitHub Action**: Auto-reviews every PR on your repo
- **Structured output**: Summary, risks, suggestions, confidence score
- **Works with any Claude-compatible API**

## CLI Usage

```bash
# 1. Make executable
chmod +x claude-review

# 2. Set your API key
export CLAUDE_API_KEY=sk-ant-...

# 3. Review any PR
./claude-review --pr https://github.com/owner/repo/pull/123

# 4. Save output to file
./claude-review --pr https://github.com/owner/repo/pull/123 --output review.md

# 5. Review a local diff
git diff main > changes.patch
./claude-review --diff changes.patch
```

## GitHub Action Setup

1. Copy `.github/workflows/claude-review.yml` to your repo
2. Add `ANTHROPIC_API_KEY` to your repo's GitHub Secrets (Settings → Secrets and variables → Actions)
3. Open a PR — the review will be posted automatically
