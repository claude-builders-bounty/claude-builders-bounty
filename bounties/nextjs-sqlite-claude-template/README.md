# Next.js + SQLite CLAUDE.md template

This bounty deliverable provides an opinionated `CLAUDE.md` for a greenfield SaaS project using Next.js 15 App Router and SQLite.

## Use in 3 steps

```bash
cp CLAUDE.md /path/to/your-nextjs-sqlite-app/CLAUDE.md
cd /path/to/your-nextjs-sqlite-app
claude
```

## What it covers

- stack and version assumptions
- folder structure
- naming conventions
- SQLite access rules
- migration conventions
- App Router server/client boundaries
- component patterns
- auth and authorization checks
- anti-patterns with reasons

## Validation note

The template was reviewed against the bounty criteria for a greenfield Next.js 15 + SQLite SaaS project. It is intentionally specific to direct SQLite/libSQL workflows and avoids generic full-stack advice.
