# Claude PR Review Agent

A Python CLI that takes a GitHub PR URL (or local diff file) and produces a structured Markdown review with summary, risks, suggestions, and confidence score.

## Installation (2 commands)

```bash
# 1. Make script executable and copy to PATH
chmod +x claude_review.py && sudo mv claude_review.py /usr/local/bin/claude-review

# 2. Verify installation
claude-review --help
```

That's it. Pure Python 3.6+ stdlib, zero dependencies.

## Usage

### Review a GitHub PR

```bash
claude-review --pr https://github.com/owner/repo/pull/123
```

### Review a local diff file

```bash
git diff main > changes.diff
claude-review --file changes.diff
```

### Output as JSON

```bash
claude-review --pr https://github.com/owner/repo/pull/123 --json
```

### Write to file

```bash
claude-review --pr https://github.com/owner/repo/pull/123 --output review.md
```

**PR:** <title> (by @<author>)
**Branch:** `<head>` → `<base>`
**Files changed:** N | **Confidence:** Low/Medium/High

*Generated by `claude-review`*

## Risk Detection

The agent scans diffs for common security/correctness patterns:

| Pattern | Risk Flag |
|---|---|
| `.call(`, `.delegatecall(`, `.send(`, `.transfer(` | External call — verify reentrancy |
| `onlyOwner`, `msg.sender == owner` | Owner-only function — centralization |
| `selfdestruct`, `suicide` | Contract destruction — irreversible |
| `tx.origin` | Phishing vulnerability |
| `block.timestamp`, `now()` in comparison | Miner manipulation |
| `random`, `blockhash`, `block.prevrandao` | Weak randomness |
| `unchecked { ... }` | Arithmetic overflow risk |
| `password`, `secret`, `api_key`, `token` | Possible leaked credential |
| `console.log`, `print(`, `fmt.Println` | Debug output left in |
| `TODO`, `FIXME`, `XXX`, `HACK` | Incomplete code |

## Improvement Suggestions

| Pattern | Suggestion |
|---|---|
| `public function` | Use `external` for gas savings |
| `uint256 x = 0` | Skip default init (defaults to 0) |
| `string memory` | Use `bytes32` for fixed strings |
| Loop with `.length` | Cache array length outside loop |
| `require(x != address(0))` | Use OpenZeppelin's Address.isContract |

## Confidence Score

- **High:** < 50 lines changed, no risks detected
- **Medium:** < 200 lines OR ≤ 2 risks
- **Low:** Large change OR many risks
