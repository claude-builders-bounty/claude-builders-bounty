# n8n Workflow: Automated Weekly GitHub Dev Summary

> Resolves [BOUNTY #5](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/5)

## 功能

每周自动拉取指定 GitHub 仓库的提交、PR、Issue 数据，通过 Claude API 生成结构化的中文/英文周报，并保存为 Markdown 文件 + 推送到 Slack。

## 流程图

```
[Weekly Trigger] --> [GitHub Commits]
               \--> [GitHub Issues & PRs]
                      |
                      v
               [Aggregate Data (Code Node)]
                      |
                      v
               [Claude Summary (Anthropic)]
                      |
                      v
               [Format Output (Code Node)]
                      |
        +-------------+-------------+
        v                           v
 [Save Markdown File]      [Slack Notify]
```

## 节点说明

| 节点 | 类型 | 作用 |
|---|---|---|
| Weekly Trigger | Schedule Trigger | 每周一早上 9:00 自动触发 |
| GitHub Commits | GitHub | 拉取最近 7 天 commits |
| GitHub Issues & PRs | GitHub | 拉取最近 7 天 issues / merged PRs |
| Aggregate Data | Code (JavaScript) | 合并、过滤、统计数据 |
| Claude Summary | Anthropic Chat Model | 调用 Claude 生成周报正文 |
| Format Output | Code (JavaScript) | 包装为 Markdown 格式 |
| Save Markdown File | Read/Write File | 写入本地 `weekly-summary-{repo}-{date}.md` |
| Slack Notify | Slack | 推送到 `#dev-updates` 频道 |

## 前置要求

1. **n8n** 实例（本地 / Docker / Cloud）
2. **GitHub API** 凭证（Personal Access Token）
3. **Anthropic API Key**（用于 Claude）
4. **Slack Bot Token**（可选，用于推送）

## 导入方式

1. 打开 n8n 工作台
2. Settings → Workflows → Import from File
3. 选择 `weekly-github-summary.json`
4. 配置以下凭证：
   - `github-api-creds`：GitHub Personal Access Token
   - `anthropic-api-creds`：Anthropic API Key
   - `slack-api-creds`：Slack Bot Token（可选）
5. 修改 Weekly Trigger 中的仓库信息（owner/repo）
6. 激活 Workflow

## 自定义参数

在 `Weekly Trigger` 节点的 JSON 中设置：

```json
{
  "owner": "your-org",
  "repo": "your-repo"
}
```

或在 `Aggregate Data` 节点中批量支持多仓库循环。
