# Weekly Dev Summary - n8n + Claude AI

Automated weekly narrative summary of GitHub repository activity, powered by n8n and Claude API.

## 🎯 Bounty Acceptance Criteria

- ✅ Exportable n8n workflow (importable `.json` file)
- ✅ Trigger: weekly cron (Friday at 5pm)
- ✅ Fetches from GitHub API: commits, closed issues, merged PRs
- ✅ Calls Claude API (`claude-sonnet-4-20250514`) for narrative summary
- ✅ Delivers via email AND Discord webhook (both supported)
- ✅ Configurable variables: GitHub repo, destination, language (EN/FR)
- ✅ README with setup in 5 steps

## 📋 Prerequisites

1. n8n instance ([self-hosted](https://docs.n8n.io/hosting/installation/) or [cloud](https://n8n.io/cloud/))
2. GitHub Personal Access Token ([create here](https://github.com/settings/tokens))
3. Anthropic API key ([get from Console](https://console.anthropic.com/))

## 🚀 5-Minute Setup

### Step 1: Import Workflow
1. Open n8n → Click **"Import from File"**
2. Select `workflow.json` from this repo
3. Click **Save**

### Step 2: Configure Variables
Open **Settings → Variables** and set:

| Variable | Example | Description |
|----------|---------|-------------|
| `GITHUB_REPO` | `Kasionchen/my-project` | Target GitHub repo |
| `ANTHROPIC_API_KEY` | `sk-ant-...` | Your Anthropic API key |
| `REPORT_EMAIL` | `team@company.com` | Email for reports |
| `DISCORD_WEBHOOK` | `https://discord.com/api/webhooks/...` | Discord webhook URL |
| `LANGUAGE` | `EN` or `FR` | Summary language |

### Step 3: Add Credentials
For HTTP Request nodes that call GitHub:
1. Create **"Header Auth"** credential
2. Name it `github-auth`
3. Add Header: `Authorization` = `Bearer YOUR_GITHUB_TOKEN`

### Step 4: Activate
Toggle the workflow **ON** → it triggers every Friday at 5pm

### Step 5: Test Manually
Click **"Test Workflow"** to run immediately and verify output.

## 📊 What It Does

```
Friday 5pm → Fetch last week's →
  - Commits (up to 100)
  - Closed issues
  - Merged PRs
  → Aggregate stats
  → Send to Claude API
  → Generate narrative summary
  → Deliver via Email + Discord
```

## 🔧 Troubleshooting

**GitHub API rate limiting?**
- Add more tokens or use GitHub App authentication
- Reduce `per_page` parameter in HTTP nodes

**Claude API errors?**
- Verify API key is correct and has credits
- Check `max_tokens` is within limits

**No output?**
- Enable **Error Workflow** in n8n settings
- Check n8n execution logs
