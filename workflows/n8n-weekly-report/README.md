# Weekly Dev Summary - n8n + Claude AI

Automated weekly narrative summary of GitHub repository activity, powered by n8n and Claude API.

## 🎯 Bounty Acceptance Criteria

- ✅ Exportable n8n workflow (importable `.json` file)
- ✅ Trigger: weekly cron (Friday at 5pm)
- ✅ Fetches from GitHub API: commits, closed issues, merged PRs
- ✅ Calls Claude API (`claude-sonnet-4-20250514`) for narrative summary
- ✅ Delivers via **Email**, **Slack**, and **Discord** (all supported)
- ✅ Summary includes: top contributors, key PRs, issue resolution rate, highlights
- ✅ README with complete setup instructions

## 📋 Prerequisites

1. **n8n instance** ([self-hosted](https://docs.n8n.io/hosting/installation/) or [cloud](https://n8n.io/cloud/))
2. **GitHub Personal Access Token** with `repo` scope ([create here](https://github.com/settings/tokens))
3. **Anthropic API key** ([get from Console](https://console.anthropic.com/))

## 🚀 5-Minute Setup

### Step 1: Import Workflow

1. Open n8n → Click **"Import from File"**
2. Select `workflow.json` from this repo
3. Click **Save**

### Step 2: Configure Variables

Open **Settings → Variables** and set:

| Variable | Example | Description |
|----------|---------|-------------|
| `GITHUB_REPO` | `Kasionchen/my-project` | Target GitHub repo |
| `GITHUB_TOKEN` | `ghp_...` | GitHub Personal Access Token |
| `ANTHROPIC_API_KEY` | `sk-ant-...` | Your Anthropic API key |
| `REPORT_EMAIL` | `team@company.com` | Email for reports |
| `SLACK_WEBHOOK` | `https://hooks.slack.com/...` | Slack webhook URL |
| `DISCORD_WEBHOOK` | `https://discord.com/api/webhooks/...` | Discord webhook URL |
| `LANGUAGE` | `EN` or `FR` | Summary language (optional) |

> **Note:** At least one delivery method (Email, Slack, or Discord) should be configured with a non-empty value.

### Step 3: Add Credentials

No additional credentials needed! The workflow uses variable-based authentication:
- GitHub API calls use `GITHUB_TOKEN` in Authorization header
- Claude API calls use `ANTHROPIC_API_KEY` in x-api-key header

### Step 4: Activate

Toggle the workflow **ON** → it triggers every Friday at 5pm (UTC)

### Step 5: Test Manually

Click **"Test Workflow"** to run immediately and verify output.

## 📊 What It Does

```
Friday 5pm (UTC) → Calculate date range →
  - Fetch commits (up to 100, last 7 days)
  - Fetch closed issues (last 7 days)
  - Fetch merged PRs (last 7 days)
  → Aggregate stats (commits, issues, PRs, resolution rate)
  → Calculate top contributors
  → Send to Claude API (claude-sonnet-4-20250514)
  → Generate narrative summary
  → Deliver via Email + Slack + Discord (all parallel)
```

## 🔧 Troubleshooting

**GitHub API rate limiting?**
- Add more tokens or use GitHub App authentication
- Reduce `per_page` parameter in HTTP nodes
- Add `GITHUB_TOKEN` to increase rate limit (5000 req/hour vs 60 req/hour)

**Claude API errors?**
- Verify API key is correct and has credits
- Check `max_tokens` is within limits (currently 1024)

**No output?**
- Enable **Error Workflow** in n8n settings
- Check n8n execution logs
- Verify at least one delivery channel (Email/Slack/Discord) is configured
