# Weekly Dev Summary — n8n Workflow

Automated weekly development summary for any GitHub repository, generated by Claude Sonnet 4.

**What it does:**
- Triggers every Friday at 5:00 PM local time
- Fetches commits, closed issues, and merged PRs from the last 7 days
- Generates an AI narrative summary via Claude Sonnet 4
- Outputs a formatted message ready for Slack, Teams, email, or any destination

---

## Setup (5 Steps)

### 1. Import the workflow

1. Open your n8n instance
2. Go to **Workflows** → **Import from File**
3. Select `workflow.json`
4. The workflow appears with 14 nodes — do not modify the node connections

### 2. Create required credentials

You need **two** credentials in n8n:

| Credential | Type | What it needs |
|---|---|---|
| **GitHub API** | `GitHub API` (OAuth2 or Personal Access Token) | `repo` scope for private repos, `public_repo` for public repos |
| **Anthropic API** | `Anthropic API` | Your Anthropic API key from [console.anthropic.com](https://console.anthropic.com) |

To create them: **Credentials** → **Add Credential** → search for the type above.

### 3. Attach credentials to the workflow

In the workflow editor:

- Click the **GitHub - Get Commits** node → **Parameters** tab → under **Credential**, select your GitHub credential
- Repeat for **GitHub - Get Issues** and **GitHub - Get PRs**
- Click **Claude API - Generate Summary** → **Parameters** → select your Anthropic credential

### 4. Configure variables

Open the **Workflow Config** node (the Set node after the Schedule Trigger). Edit these values:

| Variable | Default | Description |
|---|---|---|
| `githubRepo` | `n8n-io/n8n` | Repository in `owner/repo` format (e.g. `facebook/react`) |
| `destinationChannel` | `#weekly-dev-summary` | Target channel name (informational, used in output) |
| `language` | `EN` | Dropdown: `EN` for English, `FR` for French |

### 5. Set the delivery destination

The final output message is in the `message` field of the **Final Output** node. To deliver it:

**Option A: Slack**
1. Add a **Slack** node after **Format Output**
2. Connect the "message" output to Slack's text field
3. Set channel from `$json.destination`

**Option B: Email**
1. Add an **Email** (SMTP) node after **Format Output**
2. Set body to `{{ $json.message }}`

**Option C: Webhook**
1. Add a **Webhook** or **HTTP Request** node after **Format Output**
2. POST `{{ $json.message }}` to your endpoint

**Option D: Manual (no additional node)**
- View results in n8n's execution history
- Check the **Final Output** node's output panel after each run

## Testing

1. Click **Execute Workflow** (the play button)
2. The workflow fetches the last 7 days of activity and generates a summary
3. Check the **Format Output** node's output to see the message
4. The workflow is disabled by default — toggle **Active** on when ready

## Workflow Diagram

```
Schedule Trigger (Fri 5pm)
  -> Workflow Config (githubRepo, language, destination)
    -> Compute Date Range (last 7 days)
      -> GitHub - Get Commits  ->  Clean Commits  -+
      -> GitHub - Get Issues   ->  Clean Issues   -+-> Merge Data
      -> GitHub - Get PRs      ->  Clean PRs      -+     |
                                                      Build Summary & Prompt
                                                        -> Claude API (claude-sonnet-4)
                                                          -> Format Output
                                                            -> Final Output
```

## Troubleshooting

| Problem | Likely cause | Fix |
|---|---|---|
| Empty commits list | Wrong repo name | Check `githubRepo` format is `owner/repo` |
| GitHub 401 error | Missing/expired credential | Re-authenticate GitHub credential |
| Claude 401 error | Missing API key | Check Anthropic credential |
| Claude 529 error | Rate limited | Workflow retries on next execution |
| No output message | Execution failed | Check node error indicators (red border) |
