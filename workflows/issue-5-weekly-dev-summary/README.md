# Weekly Dev Summary — n8n + Claude Workflow

Automatically generates a **narrative weekly summary** of any GitHub repository's activity, powered by Claude AI, and delivers it to Discord (or Slack/email).

> 💰 **Bounty:** $200 | **Issue:** [claude-builders-bounty#5](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/5)

## What It Does

Every **Friday at 5pm**, this workflow:

1. **Fetches** from GitHub API: all commits, closed issues, and merged PRs for the week
2. **Sends** the raw data to **Claude (Sonnet 4)** with a structured prompt
3. **Receives** a professional narrative summary (~500 words)
4. **Delivers** it to your chosen channel (Discord webhook by default)

## Setup (5 Steps)

### Step 1: Import the Workflow

1. Open your n8n instance → **Workflows** → **Import from File**
2. Upload `weekly-dev-summary.json`
3. Click **Import**

### Step 2: Configure GitHub Credential

1. Go to **Credentials** → **Add Credential** → **GitHub API**
2. Generate a [GitHub Personal Access Token](https://github.com/settings/tokens) (need `repo` and `read:org` scopes)
3. Paste the token and save

### Step 3: Configure Anthropic/Claude Credential

1. Go to **Credentials** → **Add Credential** → **Anthropic** (or install the [@anthropic-ai/anthropic community node](https://community.n8n.io/nodes/sub-nodes/naas-ai-anthropic/))
2. Paste your [Anthropic API key](https://console.anthropic.com/settings/keys)
3. Save

> **Note:** If the community node is unavailable, replace the "Call Claude API" node with a standard **HTTP Request** node pointing to `https://api.anthropic.com/v1/messages` with header `x-api-key` + `anthropic-version: 2023-06-01`.

### Step 4: Set Environment Variables

In n8n, go to **Settings** → **Variables** and add:

| Variable | Description | Example |
|----------|-------------|---------|
| `GITHUB_REPO` | Target repository (`owner/repo`) | `octocat/Hello-World` |
| `DESTINATION_TYPE` | `discord`, `slack`, or `email` | `discord` |
| `WEBHOOK_URL` | Discord/Slack webhook URL | `https://discord.com/api/webhooks/...` |
| `SUMMARY_LANGUAGE` | `EN` or `FR` | `EN` |

### Step 5: Activate & Test

1. Toggle the workflow **ON** (top-right switch)
2. Click **Test Step** on the "Log Success" node to verify end-to-end
3. Check your Discord channel for the summary!

## Workflow Architecture

```
[Weekly Cron Trigger]
        │
        ▼
[Set Week Variables] ──┬──▶ [Fetch Commits] ───┐
                        ├──▶ [Fetch Issues] ────┤──▶ [Merge Data] ──▶ [Build Prompt] ──▶ [Claude API] ──┬──▶ [Send Discord]
                        └──▶ [Fetch Merged PRs] ┘                                                                      └──▶ [Log Success]
```

## Customization

### Change Schedule
Edit the **Schedule Trigger** node's cron expression:
- Every Friday at 5pm: `0 17 * * 5` (default)
- Every Monday at 9am: `0 9 * * 1`
- Custom: [crontab guru](https://crontab.guru/)

### Add Email Delivery
Replace/Split the "Send to Discord" node:
1. Add an **SMTP Email** node (or **SendGrid / Resend**)
2. Connect it after "Call Claude API"
3. Configure recipient, subject (`Weekly Dev Summary - ${repo}`), and body

### Support More Languages
The prompt builder already handles `EN` and `FR`. To add more, edit the "Build Claude Prompt" node's code and add language blocks.

## Requirements

- **n8n** ≥ v1.0 (self-hosted or cloud)
- **GitHub Personal Access Token** with `repo` scope
- **Anthropic API Key** (Claude Sonnet 4)
- **Discord Webhook URL** (or Slack/Email alternative)
