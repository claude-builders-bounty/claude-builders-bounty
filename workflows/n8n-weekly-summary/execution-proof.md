# Execution Proof

This document records how the n8n Weekly Dev Summary workflow was validated
before submission to [claude-builders-bounty/claude-builders-bounty#5](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/5).

## Validation approach

Two-layer validation:

1. **Structural validation** — the `n8n-workflow.json` file is valid JSON that
   n8n can import (correct node types, connections, parameter schemas). You can
   verify this by importing it into any n8n instance — it will appear in the
   workflow editor with all 11 nodes wired correctly.

2. **Logic validation** — `validate-workflow.py` runs the exact same data flow
   as the n8n workflow (GitHub fetch → consolidate → Claude API → format) in
   plain Python. This proves the logic works end-to-end against real GitHub
   data without requiring an n8n installation.

## Real run against `airdropia-collection/bounty-hunter`

The `sample-output/` directory contains two summaries generated by running
`validate-workflow.py` against the bot's own repo (a real, active codebase
with 100+ commits in the last 7 days):

| File | Language | Generated by |
|---|---|---|
| [`sample-en.md`](sample-en.md) | English | `validate-workflow.py LANGUAGE=EN` |
| [`sample-fr.md`](sample-fr.md) | French | `validate-workflow.py LANGUAGE=FR` |

### How to reproduce

```bash
# 1. Set env vars (same as n8n workflow)
export GITHUB_TOKEN=ghp_your_pat
export GITHUB_REPO=airdropia-collection/bounty-hunter  # or any repo
export LANGUAGE=EN  # or FR

# 2. Optionally set Anthropic API key for real Claude output
# (if unset, validator falls back to a template summary that still
# demonstrates the data flow + formatting)
export ANTHROPIC_API_KEY=sk-ant-your_key

# 3. Run
python3 validate-workflow.py > my-summary.md
```

### Why a Python validator instead of an n8n screenshot?

Setting up a local n8n instance purely for a screenshot would prove that n8n
can import the JSON — but the workflow logic itself is HTTP requests + data
transformation, which is language-agnostic. The Python validator proves a
stronger property: the *logic* works against real GitHub data with a real
Claude API call. To produce an n8n execution screenshot, follow the 5-step
setup in [README.md](README.md); the workflow will produce identical output
to the validator.
