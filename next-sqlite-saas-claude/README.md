# Next.js 15 + SQLite SaaS CLAUDE.md Template

This directory contains an opinionated `CLAUDE.md` for a greenfield SaaS project built with Next.js 15 App Router and SQLite.

## Use

1. Copy `CLAUDE.md` to the root of a new Next.js + SQLite SaaS repo.
2. Adjust only project-specific commands if your package manager differs.
3. Start Claude Code from the repo root.

## Validation Notes

The file is intentionally concrete: it names folders, file suffixes, migration rules, auth boundaries, and anti-patterns with reasons. It is designed to be usable without extra context in a greenfield app that uses Drizzle with `better-sqlite3` or Turso/libSQL.
