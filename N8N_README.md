# 📊 n8n + Claude API — Weekly Dev Summary Workflow

An automated n8n workflow that generates a narrative weekly summary of a GitHub repository's activity using the Claude API.

## Quick Start (5 steps)

1. **Install n8n** (if you haven't already):
   ```bash
   n8n start
   # or use n8n.cloud
   ```

2. **Import the workflow**:
   - Open n8n → **Workflows** → **Import from File**
   - Select `weekly-summary-workflow.json`

3. **Set up credentials**:
   - **GitHub**: Create a Personal Access Token → n8n credential "Header Auth" with `Authorization: Bearer ghp_...`
   - **Anthropic**: Get an API key → n8n credential "Header Auth" with `x-api-key: sk-ant-...`
   - **Email** (optional): Configure SMTP credentials if using email delivery

4. **Configure variables** (in the "GitHub Config" node):
   | Variable | Example | Description |
   |----------|---------|-------------|
   | `owner` | `vercel` | GitHub org/username |
   | `repo` | `next.js` | Repository name |
   | `language` | `EN` or `FR` | Output language |
   | `webhookUrl` | `https://discord.com/api/webhooks/...` | Discord/Slack webhook URL (leave empty for email) |
   | `fromEmail` | `n8n@yourdomain.com` | Sender email (for email delivery) |
   | `toEmail` | `team@yourdomain.com` | Recipient email |

5. **Activate** the workflow — it runs every Friday at 5pm UTC automatically.

   To test immediately, click **Execute Workflow** in the n8n editor.

## What it does

| Step | Description |
|------|-------------|
| 🕐 **Triggers** | Friday 5pm UTC (customizable cron) |
| 🔍 **Fetches GitHub data** | Commits, closed issues, and merged PRs from the past week |
| 🤖 **Calls Claude API** | Generates a narrative, enthusiastic summary using `claude-sonnet-4-20250514` |
| 📬 **Delivers** | Via Discord/Slack webhook OR email (configurable) |

## Customization

- **Schedule**: Edit the "Weekly Cron Trigger" node → change the cron expression
- **GitHub data**: Modify `Get Commits` / `Get Issues` / `Get PRs` HTTP request nodes to change filtering
- **Claude model**: Change `model` in the "Call Claude API" node body
- **Prompt**: Edit the "Build Claude Prompt" Code node to customize the style

## Requirements

- n8n (self-hosted or cloud)
- GitHub Personal Access Token (with `repo` scope)
- Anthropic API key
- SMTP credentials (for email) OR webhook URL (for Discord/Slack)
