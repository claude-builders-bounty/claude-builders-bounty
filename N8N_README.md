# 📋 Weekly Dev Summary — n8n + Claude

Automated weekly narrative summary of GitHub repo activity, generated by Claude and delivered via email or webhook.

## Setup (5 steps)

```bash
# 1. Import the workflow
# In n8n: Workflows → Import from File → select weekly-dev-summary.json

# 2. Configure credentials
# Add two HTTP Header Auth credentials:
#   - "GitHub Token": Header = "Authorization", Value = "Bearer ghp_YOUR_TOKEN"
#   - "Anthropic API Key": Header = "x-api-key", Value = "sk-ant-YOUR_KEY"

# 3. Set environment variables
GITHUB_REPO=owner/repo          # e.g. "keephq/keep"
DELIVERY_METHOD=email           # "email" or "webhook"
SUMMARY_LANGUAGE=EN             # "EN" or "FR"

# For email delivery:
EMAIL_FROM=noreply@example.com
EMAIL_TO=team@example.com

# For webhook delivery (Discord or Slack):
WEBHOOK_URL=https://discord.com/api/webhooks/...  # or Slack webhook URL

# 4. Update credential IDs in the workflow JSON
# Replace "CRED_GITHUB_TOKEN" and "CRED_ANTHROPIC_KEY" with your n8n credential IDs

# 5. Activate the workflow
# Click "Active" toggle in n8n — runs every Friday at 5PM UTC
```

## How It Works

```
Every Friday 5PM (cron)
    ├── Get Commits (GitHub API, last 7 days)
    ├── Get Closed Issues (GitHub API, last 7 days)
    └── Get Merged PRs (GitHub API, last 7 days)
        │
        ▼
    Merge Data
        │
        ▼
    Claude API (claude-sonnet-4-20250514)
    → Generates narrative summary
        │
        ▼
    Extract Summary (Code node)
        │
        ▼
    Delivery Method Switch
    ├── Email → Send via SMTP
    └── Webhook → Discord or Slack
```

## Configurable Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GITHUB_REPO` | ✅ | — | GitHub repo in `owner/repo` format |
| `DELIVERY_METHOD` | ✅ | `webhook` | `email` or `webhook` |
| `SUMMARY_LANGUAGE` | ❌ | `EN` | `EN` or `FR` |
| `WEBHOOK_URL` | if webhook | — | Discord/Slack webhook URL |
| `EMAIL_FROM` | if email | — | Sender email |
| `EMAIL_TO` | if email | — | Recipient email |

## Language Support

Set `SUMMARY_LANGUAGE=FR` for French output. Claude generates the summary in the specified language naturally.

## Requirements

- n8n (self-hosted or cloud)
- GitHub Personal Access Token (with repo access)
- Anthropic API Key
- SMTP server (if using email delivery) OR Discord/Slack webhook URL
