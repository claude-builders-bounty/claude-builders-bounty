# Changelog Generator

Automatically generate a structured `CHANGELOG.md` from your git history.

## Setup

1. Copy `changelog.sh` into your project directory.
2. Make it executable: `chmod +x changelog.sh`
3. Run it: `./changelog.sh` (or `bash changelog.sh`)

It will generate a `CHANGELOG.md` categorizing commits into Added, Fixed, Changed, and Removed since your last git tag!
