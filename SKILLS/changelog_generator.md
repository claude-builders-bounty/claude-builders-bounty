# Skill: Generate Structured CHANGELOG from Git History\n\n## Overview\nThis skill provides a method to generate a structured CHANGELOG.md file from git commit history, organized by semantic version categories.\n\n## Method\n\n### 1. Parse Git Commits\n```bash\ngit log --pretty=format:"%h|%s|%an|%ad" --date=short --since="2024-01-01"\n```\n\n### 2. Categorize by Conventional Commits\nMap commit prefixes to CHANGELOG sections:\n- `feat:` -> **Features**\n- `fix:` -> **Bug Fixes**\n- `perf:` -> **Performance Improvements**\n- `docs:` -> **Documentation**\n- `refactor:` -> **Refactoring**\n- `test:` -> **Tests**\n- `chore:` -> **Chores**\n- `ci:` -> **CI/CD**\n- `style:` -> **Style Changes**\n- `build:` -> **Build System**\n\n### 3. Generate CHANGELOG.md Template\n```markdown\n# Changelog\n\n## [Unreleased]\n\n### Features\n- feat: description of feature\n\n### Bug Fixes\n- fix: description of bug fix\n```\n\n### 4. Full Implementation Script\n```python\n#!/usr/bin/env python3\n"""Generate CHANGELOG from git log."""\nimport subprocess\nimport re\nfrom collections import defaultdict\nfrom datetime import datetime\n\nCATEGORIES = {\n    "feat": "Features",\n    "fix": "Bug Fixes",\n    "perf": "Performance Improvements",\n    "docs": "Documentation",\n    "refactor": "Refactoring",\n    "test": "Tests",\n    "chore": "Chores",\n    "ci": "CI/CD",\n    "style": "Style Changes",\n    "build": "Build System",\n}\n\ndef parse_commit(line):\n    """Parse a git log line into components."""\n    parts = line.split("|")\n    if len(parts) != 4:\n        return None\n    sha, subject, author, date = parts\n    match = re.match(r"(feat|fix|perf|docs|refactor|test|chore|ci|style|build)(?:\(.+\))?!?:\s+(.+)", subject)\n    if match:\n        return {"type": match.group(1), "message": match.group(2), "sha": sha[:7], "author": author, "date": date}\n    return None\n\ndef generate_changelog(since_date=None):\n    """Generate CHANGELOG content from git history."""\n    cmd = ["git", "log", "--pretty=format:%h|%s|%an|%ad", "--date=short"]\n    if since_date:\n        cmd.extend(["--since", since_date])\n    result = subprocess.run(cmd, capture_output=True, text=True)\n    commits = []\n    for line in result.stdout.strip().split("\n"):\n        parsed = parse_commit(line)\n        if parsed:\n            commits.append(parsed)\n    grouped = defaultdict(list)\n    for c in commits:\n        cat = CATEGORIES.get(c["type"], "Other")\n        grouped[cat].append(c)\n    lines = ["# Changelog\n"]\n    for cat in ["Features", "Bug Fixes", "Performance Improvements", "Documentation",\n                "Refactoring", "Tests", "Chores", "CI/CD", "Style Changes", "Build System"]:\n        if cat in grouped:\n            lines.append("\n## %s\n" % cat)\n            for c in grouped[cat]:\n                lines.append("- %s (`%s`)" % (c["message"], c["sha"]))\n    return "\n".join(lines)\n\nif __name__ == "__main__":\n    changelog = generate_changelog()\n    with open("CHANGELOG.md", "w") as f:\n        f.write(changelog)\n    print("CHANGELOG.md generated successfully.")\n```\n\n### 5. Usage\n1. Place the script in the project root\n2. Run: `python generate_changelog.py`\n3. Review and commit: `CHANGELOG.md`\n\n## Acceptance Criteria\n- [x] Parses conventional commit messages\n- [x] Groups commits by semantic category\n- [x] Generates valid Markdown format\n- [x] Includes commit SHA references\n- [x] Supports date range filtering\n- [x] Handles edge cases (no commits, malformed messages)\n
