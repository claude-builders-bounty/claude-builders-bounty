# generate-changelog — structured CHANGELOG.md from git history

Zero-dependency (bash + git + python3). Categorizes commits into
**Added / Fixed / Changed / Removed** (plus Deprecated / Security / Docs / Tests / Chore)
using Conventional Commits prefixes and Chinese keyword fallback.

## Setup (3 steps)

1. Copy `changelog.sh` and `changelog_gen.py` into your repository (any folder).
2. Run `bash changelog.sh` — it cuts commits since the **last git tag**
   (falls back to full history when the repo has no tags) and writes `CHANGELOG.md`.
3. Commit the generated `CHANGELOG.md`.

Also works as a Claude Code skill: point `/generate-changelog` at
`bash changelog.sh "$REPO"` or run `python3 changelog_gen.py --repo "$REPO" --range <tag>..HEAD`.
