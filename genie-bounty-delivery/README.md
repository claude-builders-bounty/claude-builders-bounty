# Changelog generator

## Usage
1. `bash genie-bounty-delivery/changelog.sh`
2. Or invoke `/generate-changelog` (see `generate-changelog.md`)
3. Commits since last tag are categorised into Added / Fixed / Changed / Removed
4. Output is appended-ready markdown (see SAMPLE_CHANGELOG_OUTPUT.md)
5. Tested against this repository — sample captured in SAMPLE_CHANGELOG_OUTPUT.md
