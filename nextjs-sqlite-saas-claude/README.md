# Next.js SQLite SaaS CLAUDE.md Template

This directory contains an opinionated `CLAUDE.md` for a greenfield Next.js 15 App Router SaaS project using SQLite through Drizzle, `better-sqlite3`, and Turso/libSQL.

## Use in 3 Steps

```bash
cp nextjs-sqlite-saas-claude/CLAUDE.md /path/to/your-project/CLAUDE.md
cd /path/to/your-project
claude
```

The template covers project structure, naming conventions, database migration rules, component patterns, dev commands, anti-patterns, and the reasons behind the rules.
