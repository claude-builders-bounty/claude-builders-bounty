# claude-review — AI-Powered PR Review

A Claude Code agent that takes a GitHub PR, analyzes the diff, and posts a structured Markdown review comment.

## Setup (2 steps)

### CLI Usage

1. Install the script:
```bash
cp claude-review /usr/local/bin/claude-review
chmod +x /usr/local/bin/claude-review
```

2. Ensure `gh` CLI is authenticated and one of:
   - `claude` CLI is installed, OR
   - `ANTHROPIC_API_KEY` environment variable is set

### GitHub Action Usage

1. Copy `.github/workflows/review.yml` to your repo's `.github/workflows/` directory
2. Add `ANTHROPIC_API_KEY` as a repository secret (Settings → Secrets → Actions)

## Usage

### CLI

```bash
# Full URL
claude-review --pr https://github.com/owner/repo/pull/123

# Shorthand
claude-review --pr owner/repo#123

# From inside a git repo (just PR number)
cd my-repo
claude-review --pr 42
```

The review is printed to stdout. To post it as a comment:

```bash
claude-review --pr owner/repo#123 | gh pr comment 123 --repo owner/repo --body-file -
```

### GitHub Action

Automatic — reviews are posted as comments on every opened or updated PR.

## Review Format

Every review contains exactly these sections:

### Summary
2-3 sentences describing what the PR does and why.

### Risks
Bulleted list of potential risks, bugs, or issues found.

### Suggestions
Bulleted list of improvement suggestions.

### Confidence
Low / Medium / High — the reviewer's confidence level.

## Example Output

```markdown
## AI Code Review

### Summary
This PR adds a new `/api/v1/teams` endpoint that creates and lists teams.
It introduces a `teams` table with foreign keys to the `users` table and
adds JWT-based authorization middleware to the team routes.

### Risks
- No input validation on the team name field — could accept empty strings
- The `DELETE /teams/:id` endpoint doesn't check if the user is a team member
- Missing index on `teams.owner_id` may cause slow queries at scale

### Suggestions
- Add Zod schema validation for the team creation payload
- Return 403 instead of 404 when a non-member tries to delete a team
- Add a database index on `owner_id` for faster lookups

### Confidence
Medium — the diff is well-structured but the authorization logic needs manual verification.

---
*Generated by claude-review — PR [#123](https://github.com/owner/repo/pull/123)*
```

## Requirements

- `gh` CLI (authenticated)
- Claude CLI OR `ANTHROPIC_API_KEY` environment variable
- Bash 4+
- Python 3.8+ (for JSON parsing)
