## AI Code Review

### Summary
This PR adds a CHANGELOG generator skill for Claude Code, consisting of a Bash script that auto-categorizes git commits into Added/Fixed/Changed/Removed sections based on commit message prefixes, along with a SKILL.md definition file and documentation.

### Risks
- The script uses `set -euo pipefail` but the `while IFS= read -r commit` loop with `grep -qE` could silently skip commits if the regex matching fails in an unexpected way
- The commit message prefix detection only checks the first word after lowercasing, which means commits like `"chore: update deps"` would fall into "Changed" rather than being recognized as a chore
- Using `echo -e` for output means commit messages containing backslash sequences (like `\n` or `\t`) could be interpreted incorrectly

### Suggestions
- Use `printf` instead of `echo -e` for more portable and predictable escape sequence handling
- Consider adding a `--output` flag to write directly to a file instead of stdout, making the common `./changelog.sh > CHANGELOG.md` pattern less error-prone
- The SKILL.md could include the full path to `changelog.sh` or assume it's in the project root for better discoverability
- Adding a `--version` flag and a `$VERSION` variable would help with maintenance

### Confidence
Medium — the script is functional and well-documented, but the `echo -e` behavior with special characters in commit messages could cause subtle issues on different systems.
