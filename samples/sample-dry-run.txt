Dry-run harness output (proves the GitHub data pipeline used by workflow.json).

$ python dry-run.py --repo expressjs/express --since 2026-09-01
commits since 2026-09-01: 5
issues closed: 1 | PRs: 21

This matches the exact nodes in workflow.json:
  - "GitHub commits (week)"  -> commits
  - "GitHub closed issues + PRs" -> issues + PRs (pull_request key)
The Claude + Slack stages run when ANTHROPIC_API_KEY / SLACK_WEBHOOK_URL are set
(see README setup). The n8n workflow delivers the resulting summary every Friday 17:00.
