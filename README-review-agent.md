# Claude Code PR Review Agent

A CLI tool that takes a GitHub PR URL, fetches the diff, and uses Claude API to generate a structured code review.

## Quick Start



## Output Format

- **Summary** — 2-3 sentence overview of changes
- **Identified Risks** — bullet list of potential issues
- **Improvement Suggestions** — actionable recommendations
- **Confidence Score** — High / Medium / Low with justification
