# Real-PR sample outputs

Run the following from the repository root after installing/authenticating Claude Code:

```bash
npm run samples
```

This generates reviews for two real public pull requests:

- https://github.com/claude-builders-bounty/claude-builders-bounty/pull/2281
- https://github.com/claude-builders-bounty/claude-builders-bounty/pull/2271
