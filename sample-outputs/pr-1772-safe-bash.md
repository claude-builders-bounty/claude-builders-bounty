## Summary
This PR adds a Claude Code pre-tool-use hook at `hooks/safe-bash/` that intercepts Bash tool invocations and blocks destructive patterns (`rm -rf`, `DROP TABLE`, `git push --force`, etc.) before they execute. Each blocked attempt is logged to `~/.claude/hooks/blocked.log` with timestamp, pattern name, and the full command. Ships with a 5-file deliverable including the hook script, settings snippet, installer, test harness (28 fixtures), and README.

## Identified Risks
- **Maintainability — substring matching:** The hook uses regex substring matching rather than shell tokenization, so data-only strings like `echo 'rm -rf safe'` are blocked. This is intentional (conservative-by-default) and documented in the README, but could surprise users who pass `rm -rf` as literal data in a heredoc or echo.
- **Correctness — Python 3 dependency:** Requires Python 3 on the host. If a user's system has `python3` at an unexpected path the hook fails silently. The README could suggest checking `which python3` before install.
