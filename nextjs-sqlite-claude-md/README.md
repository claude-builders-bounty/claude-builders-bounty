# Next.js 15 + SQLite CLAUDE.md

Opinionated `CLAUDE.md` for a greenfield App Router + SQLite SaaS.

## Use

1. Copy `CLAUDE.md` to the repository root.
2. Start Claude Code in that repo.
3. Ask it to add a feature (e.g. "add invoices for the current user"). It should follow the folder, SQL, and anti-pattern rules without asking whether to use Prisma or the pages router.

`npx create-next-app@15` with App Router, then this file, is the intended setup.
