# Next.js 15 + SQLite CLAUDE.md template

Copy `CLAUDE.md` to the root of a greenfield Next.js 15 SaaS repository. It chooses a concrete architecture instead of offering a menu of patterns, and every important rule includes its reason.

Validation in this submission is static because the current execution environment does not include the Claude Code CLI; `validate_template.py` checks that all acceptance sections and required commands are present.
