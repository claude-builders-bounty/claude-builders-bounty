# claude-review — Automated PR Reviewer

A CLI tool and GitHub Action that reviews pull requests and outputs structured Markdown comments.

## Features

- Fetches PR diff via GitHub CLI
- Analyzes code changes for risks, issues, and improvement opportunities
- Outputs structured Markdown with summary, risks, improvements, and confidence score
- Works as CLI tool or GitHub Action
- Supports posting reviews as PR comments

## Requirements

- Python 3.10+
- GitHub CLI (`gh`) installed and authenticated
- `gh` with `repo` scope for commenting

## Setup

### 1. Install GitHub CLI

```bash
# macOS
brew install gh

# Ubuntu/Debian
sudo apt-get install gh

# Authenticate
gh auth login
```

### 2. Make the script executable

```bash
chmod +x claude-review
```

No additional Python packages are needed — the tool uses only the standard library and the `gh` CLI.

## Usage

### CLI — Review and print to stdout

```bash
./claude-review --pr https://github.com/owner/repo/pull/123
```

### CLI — Save review to a file

```bash
./claude-review --pr https://github.com/owner/repo/pull/123 --output review.md
```

### CLI — Post review as PR comment

```bash
./claude-review --pr https://github.com/owner/repo/pull/123 --post
```

### CLI — JSON output

```bash
./claude-review --pr https://github.com/owner/repo/pull/123 --json
```

### GitHub Action

Copy `.github/workflows/pr-review.yml` into your repository. The action will automatically review new PRs and post comments.

You can also trigger it manually via the Actions tab with a specific PR URL.

## Output Structure

The tool produces structured Markdown with these sections:

### Summary
A 2-3 sentence overview of the changes, including file count, languages, and key files modified.

### Identified Risks
A list of potential issues detected via static heuristics, including:
- File deletion operations
- Subprocess/command execution
- eval/exec usage
- Hardcoded credentials
- SQL injection patterns
- SSL verification disabled
- Large PRs (many hunks)
- Lock file or config file changes

### Improvement Suggestions
Actionable suggestions such as:
- Leftover debug statements (print/console.log)
- Bare except clauses
- TODO/FIXME comments
- PR size recommendations

### Confidence Score
- **High** — small, focused changes with few risks
- **Medium** — moderate size with some concerns
- **Low** — large or complex changes requiring careful review

## Limitations

- This is a **heuristic-based** static analyzer, not an AI model
- It detects patterns but cannot understand code semantics
- Use it as a first-pass filter, not a replacement for human review
- False positives are possible, especially with risk patterns
