# changelog.sh

Generate a structured `CHANGELOG.md` from your git history in one command.

## Quick Start (3 steps)

```bash
# 1. Download the script
curl -O https://raw.githubusercontent.com/kodokushi444-commits/claude-builders-bounty/main/changelog.sh
chmod +x changelog.sh

# 2. Run it in any git repo
bash changelog.sh

# 3. Done — CHANGELOG.md is generated
```

## Features

- Auto-detects the **last git tag** and scans commits since
- Categorizes by [Conventional Commits](https://www.conventionalcommits.org/):
  - `feat:` → **Added**
  - `fix:` → **Fixed**
  - `refactor:`, `perf:`, `style:`, `docs:`, `ci:`, `build:`, `test:`, `chore:` → **Changed**
  - `revert:`, `remove:`, `drop:` → **Removed**
  - Everything else → **Other**
- Falls back to full history when no tags exist
- Works on macOS, Linux, and WSL

## Usage

```bash
bash changelog.sh [OPTIONS]
```

| Option | Description | Default |
|--------|-------------|---------|
| `--output FILE` | Output file path | `CHANGELOG.md` |
| `--since TAG` | Start from a specific tag | Last git tag |
| `--repo PATH` | Path to the repo | `.` |
| `--verbose` | Print extra details | off |
| `-h, --help` | Show help | — |

### Examples

```bash
# Generate CHANGELOG for the current repo
bash changelog.sh

# Output to a different file
bash changelog.sh --output docs/CHANGELOG.md

# Scan from a specific version
bash changelog.sh --since v2.0.0

# Run on a repo elsewhere
bash changelog.sh --repo /path/to/project --verbose
```
