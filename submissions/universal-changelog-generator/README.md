# Universal CHANGELOG Generator

A powerful script to automatically generate structured CHANGELOGs from your git history.

## Quick Start (3 Steps)
1. **Copy**: Place `changelog_gen.py` and `changelog.sh` in your repo root.
2. **Run**: Execute `bash changelog.sh`.
3. **Review**: Check the newly created `CHANGELOG.md`.

## Features
- Auto-categorization: Added, Fixed, Changed, Removed.
- Smart tag detection: Only fetches commits since last release.
- Clean Markdown output.
