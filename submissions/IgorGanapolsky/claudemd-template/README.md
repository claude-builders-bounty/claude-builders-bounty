# Next.js + SQLite CLAUDE.md Template

An opinionated, production-ready `CLAUDE.md` startup configuration template for Next.js 15 (App Router) + SQLite SaaS projects.

## 🚀 Setup & Usage (1 step)

1. **Copy the `CLAUDE.md` template** to the root of your Next.js + SQLite project.

Claude Code will automatically detect and parse this file on startup to guide its code generation and structure decisions.
