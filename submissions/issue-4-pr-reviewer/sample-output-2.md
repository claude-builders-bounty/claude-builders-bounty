## Summary

This PR fixes three critical bugs that caused 456 out of 1055 source_port elements to have NaN pin_number values when parsing the Smoothie Board DSN file. The fixes address tokenizer issues with lone minus signs, rotation modifier parsing, and forced number coercion of named pins.

## Identified Risks

- **Correctness**: The tokenizer change for handling lone `-` characters relies on single-character lookahead which could miss edge cases with complex DSN syntax variations
- **Performance**: Additional regex checks are now performed for every pin, potentially impacting large DSN files
- **Maintainability**: The PIN_MODIFIER_KEYWORDS set is hardcoded and may need updates if new DSN modifier keywords are encountered

## Improvement Suggestions

3. **Add validation** to ensure `port_hints` array doesn't contain empty strings or duplicate values when storing named pin labels
4. **Document the trade-off** in code comments explaining why circuit-json's typed pin_number field limitation necessitates storing named pins in port_hints instead
