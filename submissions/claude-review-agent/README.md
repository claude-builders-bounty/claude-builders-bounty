# Claude Review — AI-Powered PR Review CLI

Automated, structured code review for GitHub pull requests using Claude API.

## Quick Start (2 steps)

```bash
# 1. Set your API key
export ANTHROPIC_API_KEY="sk-ant-..."

# 2. Review any PR
python3 claude_review.py --pr https://github.com/owner/repo/pull/123
```

Or with OpenAI-compatible APIs:
```bash
export OPENAI_API_KEY="sk-..."
export OPENAI_BASE_URL="https://api.openai.com/v1"
python3 claude_review.py --pr owner/repo/123 --provider openai
```

## Usage

```bash
# Full URL
python3 claude_review.py --pr https://github.com/vercel/next.js/pull/70000

# Short reference
python3 claude_review.py --pr vercel/next.js/70000

# Custom model
python3 claude_review.py --pr owner/repo/123 --model claude-opus-4-20250514

# Save to file
python3 claude_review.py --pr owner/repo/123 --output review.md
```

## Output Format

```markdown
# PR Review: <title>
**PR**: owner/repo#123
**Reviewed**: 2026-05-19 10:00 UTC
**Stats**: 5 files changed (+120 −30)

## Summary
(2–3 sentence high-level summary)

## Identified Risks
- **Risk**: specific risk with explanation

## Improvement Suggestions
- **Suggestion**: actionable improvement

## Confidence Score
High / Medium / Low — with one-line justification
```

## How It Works

1. Parses PR URL → extracts owner/repo/number
2. Fetches PR metadata + diff via GitHub API (no auth needed for public repos)
3. Builds a structured prompt with diff, file stats, and review instructions
4. Calls Claude API to analyze
5. Formats output as structured Markdown

## Requirements

- Python 3.8+
- Anthropic API key (or OpenAI-compatible key)

## API Support

| Provider | Env Var | Default Model |
|----------|---------|---------------|
| Anthropic | `ANTHROPIC_API_KEY` | `claude-sonnet-4-20250514` |
| OpenAI | `OPENAI_API_KEY` + `OPENAI_BASE_URL` | `gpt-4o` |

## GitHub Action (Optional)

```yaml
name: AI PR Review
on:
  pull_request:
    types: [opened, synchronize]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run claude-review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          python3 claude_review.py \
            --pr "${{ github.repository }}/${{ github.event.pull_request.number }}" \
            --output review.md
      - name: Post review comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const review = fs.readFileSync('review.md', 'utf8');
            await github.rest.issues.createComment({
              ...context.repo,
              issue_number: context.issue.number,
              body: review
            });
```
