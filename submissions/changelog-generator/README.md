# Changelog Generator

A zero-dependency bash script that generates a structured **CHANGELOG.md** from your git history using [Conventional Commits](https://www.conventionalcommits.org/) and the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## Setup

1. Copy `changelog.sh` into your project (or add it to your `$PATH`)
2. Make it executable: `chmod +x changelog.sh`
3. Run it: `./changelog.sh`

## Usage

```bash
# Print changelog to stdout
./changelog.sh

# Save to a file
./changelog.sh -o CHANGELOG.md

# Generate changelog since a specific tag
./changelog.sh -t v1.0.0

# Label the release with a version number
./changelog.sh -v 2.0.0 -o CHANGELOG.md

# Point at a different repo directory
./changelog.sh -d /path/to/repo
```

### CLI Options

| Flag | Description |
|------|-------------|
| `-o FILE` | Write output to FILE instead of stdout |
| `-t TAG` | Use TAG as the starting point (default: latest tag, or all commits if none) |
| `-v VERSION` | Label the release section (default: `Unreleased`) |
| `-d DIR` | Path to the git repository (default: `.`) |
| `-h` | Show help |

## How Categorization Works

The script parses each commit's subject line for a conventional commit prefix (the word before the first `:`). Commits are sorted into sections:

| Prefix | Section |
|--------|---------|
| `feat`, `feature`, `add` | **Added** |
| `fix`, `bugfix`, `hotfix`, `patch` | **Fixed** |
| `refactor`, `chore`, `docs`, `style`, `perf`, `build`, `ci`, `test` | **Changed** |
| `revert`, `remove`, `delete`, `deprecate` | **Removed** |
| _(anything else)_ | **Other** |

Scoped prefixes like `feat(auth):` and breaking-change markers like `feat!:` are handled correctly -- the scope and bang are stripped, and the clean message is kept.

### Edge Cases

- **No tags in the repo**: All commits are included.
- **No commits since the last tag**: An empty changelog section is generated with a note.
- **Non-conventional commits**: Placed under the "Other" section so nothing is lost.
