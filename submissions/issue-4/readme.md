# Claude Code PR Review Agent

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Automated GitHub Pull Request review agent powered by Claude API. This sub-agent fetches PR diffs, sends them to Claude for intelligent review, and posts structured feedback directly on the PR.

## 🎯 Features

- **Automatic PR Analysis**: Fetches PR diff and metadata via GitHub CLI
- **Structured Reviews**: Generates comprehensive reviews with:
  - Summary of changes
  - Potential bugs and issues
  - Actionable improvement suggestions
  - Security considerations
  - Code quality assessment
- **Configurable Focus Areas**: Choose between general, security, performance, or readability reviews
- **Robust Error Handling**: Handles large PRs, API failures, and edge cases
- **Dry-Run Mode**: Test reviews without posting to PR
- **Claude Code Integration**: Works as a hook, sub-agent, or standalone tool

## 📋 Prerequisites

- Python 3.8 or higher
- [GitHub CLI (`gh`)](https://cli.github.com/) installed and authenticated
- Anthropic API key

## 🚀 Quick Start

### 1. Install Dependencies

```bash
pip install requests
```

### 2. Authenticate with GitHub

```bash
gh auth login
```

Follow the prompts to authenticate with your GitHub account.

### 3. Set Your Anthropic API Key

```bash
export ANTHROPIC_API_KEY="your-api-key-here"
```

Or create a `.env` file:

```env
ANTHROPIC_API_KEY=your-api-key-here
```

### 4. Run Your First Review

```bash
python pr_review_agent.py https://github.com/owner/repo/pull/123
```

## 📖 Usage

### Basic Usage

```bash
# Review a PR
python pr_review_agent.py https://github.com/owner/repo/pull/123

# Dry-run (generate review without posting)
python pr_review_agent.py https://github.com/owner/repo/pull/123 --dry-run

# Verbose output
python pr_review_agent.py https://github.com/owner/repo/pull/123 --verbose
```

### Advanced Options

```bash
# Use a different Claude model
python pr_review_agent.py https://github.com/owner/repo/pull/123 \
  --model claude-3-opus-20240229

# Security-focused review
python pr_review_agent.py https://github.com/owner/repo/pull/123 \
  --focus security

# Performance-focused review
python pr_review_agent.py https://github.com/owner/repo/pull/123 \
  --focus performance

# Handle larger PRs
python pr_review_agent.py https://github.com/owner/repo/pull/123 \
  --max-diff-size 1000000

# Specify API key directly
python pr_review_agent.py https://github.com/owner/repo/pull/123 \
  --api-key sk-ant-...
```

### Command-Line Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| `pr_url` | GitHub PR URL (required) | - |
| `--api-key` | Anthropic API key | `$ANTHROPIC_API_KEY` |
| `--model` | Claude model to use | `claude-3-5-sonnet-20241022` |
| `--focus` | Review focus (general, security, performance, readability) | `general` |
| `--max-diff-size` | Maximum diff size in bytes | `500000` |
| `--dry-run` | Generate review without posting | `False` |
| `--verbose` | Enable detailed logging | `False` |

## 🔧 Integration with Claude Code

### As a Claude Code Hook

1. Copy `pr_review_agent.py` to your hooks directory
2. Add to your Claude Code config:

```json
{
  "hooks": {
    "pr-review": {
      "command": "python /path/to/pr_review_agent.py",
      "triggers": ["review", "pr"],
      "description": "Review a GitHub PR"
    }
  }
}
```

### As a Sub-Agent

See `CLAUDE.md` for detailed integration instructions.

### GitHub Actions Workflow

Automate PR reviews in your CI/CD pipeline:

```yaml
name: Auto PR Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      - run: pip install requests
      - name: Run PR Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          python pr_review_agent.py \
            https://github.com/${{ github.repository }}/pull/${{ github.event.number }} \
            --focus security
```

## 📝 Review Format

The agent generates structured reviews in this format:

```markdown
## Summary
Brief overview of what the PR changes.

## Potential Issues
- [Issue 1]
- [Issue 2]

## Suggestions for Improvement
- [Suggestion 1]
- [Suggestion 2]

## Security Considerations
- [Security point 1]
- [Security point 2]

## Code Quality
Overall assessment of code quality and maintainability.

---
*Review generated by Claude Code PR Review Agent*
```

## 🔒 Security Best Practices

1. **API Keys**: Never commit API keys to version control
2. **GitHub Token**: Use minimal required permissions for GitHub token
3. **Large PRs**: Review large PRs manually before running automated reviews
4. **Review Output**: Always review generated comments before posting in production

## 🐛 Error Handling

The agent handles various error scenarios:

- **Large PRs**: Rejects PRs exceeding `--max-diff-size` with clear error message
- **API Failures**: Handles Claude API timeouts and errors gracefully
- **Invalid URLs**: Validates PR URL format before processing
- **GitHub Auth**: Detects missing or invalid GitHub authentication
- **Network Issues**: Provides clear error messages for connectivity problems
