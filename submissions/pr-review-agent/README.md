# Claude PR Review Agent

A Claude Code sub-agent that analyzes PR diffs and generates structured Markdown review comments.

## 💰 Bounty

This project was created for the [Claude Builders Bounty](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/4) - $150 reward.

## Features

- ✅ CLI tool: `claude-review --pr https://github.com/owner/repo/pull/123`
- ✅ Structured Markdown output with:
  - Summary of changes (2-3 sentences)
  - Identified risks (list)
  - Improvement suggestions (list)
  - Confidence score: Low / Medium / High
- ✅ Can post reviews directly to GitHub PRs
- ✅ Works with Claude API (`claude-sonnet-4-20250514`)

## Prerequisites

- Python 3.7+
- `requests` library
- Anthropic API key
- GitHub token (for private repos and posting comments)

## Installation

```bash
bash install.sh
```

Or manually:

```bash
pip3 install requests
cp claude-review /usr/local/bin/
chmod +x /usr/local/bin/claude-review
```

## Configuration

Set environment variables:

```bash
export ANTHROPIC_API_KEY='your-anthropic-api-key'
export GITHUB_TOKEN='your-github-token'  # Optional, for private repos
```

## Usage

### Review a PR (output to stdout)

```bash
claude-review --pr https://github.com/microsoft/vscode/pull/1
```

### Review and post comment to PR

```bash
claude-review --pr https://github.com/microsoft/vscode/pull/1 --post
```

### Save review to file

```bash
claude-review --pr https://github.com/microsoft/vscode/pull/1 --output review.md
```

## Output Format

```markdown
## 🤖 Automated PR Review

### Summary
Brief summary of the changes...

### Confidence Score
🟡 Medium

### ⚠️ Identified Risks
- Potential security issue with user input
- Missing error handling

### 💡 Improvement Suggestions
- Add input validation
- Consider adding tests

---
*Generated by Claude Code PR Review Agent*
```

## GitHub Action (Optional)

Create `.github/workflows/pr-review.yml`:

```yaml
name: PR Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run Claude Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          pip3 install requests
          python3 claude-review --pr ${{ github.event.pull_request.html_url }} --post
```
