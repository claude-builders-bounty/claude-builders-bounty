# 📋 CHANGELOG Generator — Claude Code Skill

**Bounty:** [#1 — SKILL: Generate a CHANGELOG from git history](https://github.com/claude-builders-bounty/claude-builders-bounty/issues/1)
**Reward:** $50
**Status:** ✅ Submitted

## Overview

A Claude Code skill that generates a structured `CHANGELOG.md` from conventional git commits. Categorizes changes into Added, Fixed, Changed, Removed, Documentation, and Testing sections.

## Quick Start (≤ 3 steps)

### 1. Install

Copy `generate-changelog.sh` to your project:

```bash
curl -O https://raw.githubusercontent.com/claude-builders-bounty/claude-builders-bounty/main/submissions/1-changelog-skill/generate-changelog.sh
chmod +x generate-changelog.sh
```

### 2. Run

```bash
./generate-changelog.sh
# Generates CHANGELOG.md from latest tag to HEAD

./generate-changelog.sh CHANGELOG.md v1.0.0
# Generates from tag v1.0.0
```

### 3. Integrate with Claude Code

Add to your `.claude/settings.json` under `skills`:

```json
{
  "skills": {
    "generate-changelog": {
      "command": ["bash", "./generate-changelog.sh"]
    }
  }
}
```

## Output Format

```markdown
# Changelog

## [v1.0.0] - 2026-07-10

### 🚀 Added
- New dashboard analytics (abc1234)

### 🐛 Fixed
- User session timeout issue (def5678)

### 🔧 Changed
- Refactored API routes for performance (ghi9012)

### 🗑️ Removed
- Deprecated v1 endpoints (jkl3456)

---

*Generated by [changelog-skill]*
```
