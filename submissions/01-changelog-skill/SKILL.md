# Generate Changelog

Generate a structured `CHANGELOG.md` from the project's git history.

## Usage

```
/generate-changelog
```

Or run directly:
```bash
bash changelog.sh [output-file]
# Default: CHANGELOG.md
```

## How It Works

1. Finds the last git tag as the reference point
2. Fetches all commits since that tag
3. Parses conventional commit messages (`feat:`, `fix:`, `chore:`, etc.)
4. Categorizes into **Added** / **Fixed** / **Changed** / **Removed**
5. Outputs a formatted `CHANGELOG.md`

## Conventional Commit Parsing

| Commit Type | Changelog Section |
|-------------|------------------|
| `feat:` | Added |
| `fix:` | Fixed |
| `chore:` `refactor:` `docs:` `perf:` | Changed |
| `remove:` `revert:` `deprecate:` | Removed |
| `BREAKING:` | Changed ⚠️ |

Non-conventional commits are inferred by the first word of the message.

## Output Example

```markdown
# Changelog

## [Unreleased]

### Added
- User authentication with OAuth2 (abc1234)
- Dark mode toggle (def5678)

### Fixed
- Race condition in WebSocket handler (ghi9012)

### Changed
- Upgrade to Go 1.23 (jkl3456)
- Refactor database layer (mno7890)

### Removed
- Deprecated v1 API endpoints (pqr1234)

---
_Generated by changelog.sh — 24 commits since v1.2.0_
```
