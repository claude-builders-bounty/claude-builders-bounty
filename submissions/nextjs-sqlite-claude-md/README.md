# Next.js + SQLite SaaS — CLAUDE.md Template 💎

**Bounty #2 — $75**

An opinionated, production-ready `CLAUDE.md` template for SaaS projects built with Next.js 15 App Router and SQLite.

## What's Included

| File | Purpose |
|------|---------|
| `CLAUDE.md` | Drop-in context file for Claude Code |

## Features

- ✅ Complete project structure with App Router conventions
- ✅ SQLite best practices (parameterized queries, migrations, schema patterns)
- ✅ Server vs Client Component decision guide
- ✅ TypeScript strict mode conventions
- ✅ Naming conventions for files, variables, database tables
- ✅ Auth, validation (Zod), and form patterns
- ✅ Common commands reference
- ✅ Testing guidelines (Vitest)
- ✅ Security checklist
- ✅ Environment variable template

## Usage

Copy `CLAUDE.md` to your project root:

```bash
cp CLAUDE.md /path/to/your/nextjs-project/
```

Claude Code will automatically read it for context when working on your project.
