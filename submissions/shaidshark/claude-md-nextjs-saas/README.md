# CLAUDE.md Template — Next.js + SQLite SaaS

A production-ready `CLAUDE.md` template for Claude Code projects using Next.js 14+ with SQLite.

## What's Included

- **Project structure** conventions for App Router
- **Database** patterns with Drizzle ORM + better-sqlite3
- **Auth** setup with NextAuth.js v5
- **API route** conventions with Zod validation
- **Testing** setup with Vitest
- **Security** checklist
- **Deployment** notes

## Usage

1. Copy `CLAUDE.md` to your project root
2. Customize the sections for your specific SaaS
3. Add project-specific rules as needed

```bash
cp CLAUDE.md /your-project/CLAUDE.md
```

## Why CLAUDE.md?

Claude Code reads `CLAUDE.md` automatically and follows its conventions. This ensures:
- Consistent code patterns across the project
- Correct technology choices (SQLite, not Postgres)
- Proper auth and security practices
- Standard testing approach
