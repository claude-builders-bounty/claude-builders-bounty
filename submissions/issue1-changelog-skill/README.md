# CHANGELOG Generator

Auto-generates a structured `CHANGELOG.md` from git history.

## Setup (3 steps)

```bash
# 1. Download the script
curl -O https://raw.githubusercontent.com/claude-builders-bounty/claude-builders-bounty/main/submissions/issue1-changelog-skill/changelog.sh

# 2. Make it executable
chmod +x changelog.sh

# 3. Run it
bash changelog.sh
```

## Usage

```bash
bash changelog.sh                           # auto-detect last tag
bash changelog.sh --since v1.2.3           # explicit start tag
bash changelog.sh --output RELEASES.md     # custom output file
```

Or via Claude Code:

```
/generate-changelog
```

(Copy `SKILL.md` to `.claude/commands/generate-changelog.md` to register the command)

## Requirements

- `git` in PATH
- bash 4+
- No external dependencies
