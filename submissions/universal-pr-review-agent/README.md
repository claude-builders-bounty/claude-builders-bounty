# Universal PR Review Agent

An automated agent for reviewing Pull Requests with advanced logic and security scanning.

## Features
- Fetches PR diffs automatically
- Analyzes code for quality, security, and best practices
- Dual mode: CLI for local use, GitHub Action for automated CI

## Setup
Set your `ENGINE_API_KEY` and `GITHUB_TOKEN` as repository secrets.
