# Next.js SQLite SaaS CLAUDE.md

Opinionated Claude Code instructions for a greenfield SaaS project using Next.js 15 App Router and SQLite.

## Use in 3 steps

1. Create a Next.js 15 App Router project with TypeScript.
2. Copy `CLAUDE.md` into the project root.
3. Ask Claude Code to inspect the project, then follow the rules before editing.

## What is included

- Stack, folder, naming, and command conventions.
- SQLite, better-sqlite3, Turso, and migration rules.
- Server Action, Route Handler, component, auth, validation, testing, performance, security, and anti-pattern guidance.
- Claude Code behavior rules for small, reviewable SaaS changes.
