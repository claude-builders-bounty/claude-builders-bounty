# 📜 CHANGELOG Generator

自动生成结构化的CHANGELOG.md from git history

## 功能

- ✅ 自动获取自最新git tag以来的commits
- ✅ 智能分类：Added / Fixed / Changed / Removed
- ✅ 支持Conventional Commits规范
- ✅ 自动递增版本号
- ✅ 保留历史CHANGELOG内容

## 安装

```bash
# 克隆或下载脚本
git clone <repo-url>
cd changelog-generator

# 赋予执行权限
chmod +x changelog.sh
# 或
chmod +x changelog.py
```

## 使用

### Bash版本

```bash
./changelog.sh
```

### Python版本

```bash
python3 changelog.py
```

## 分类规则

脚本根据commit message自动分类：

| 分类 | 关键词 |
|------|--------|
| **Added** | feat, feature, add, new, implement, introduce, create |
| **Fixed** | fix, bugfix, bug, repair, resolve, patch, hotfix |
| **Changed** | update, change, modify, refactor, improve, enhance |
| **Removed** | remove, delete, drop, cleanup, deprecate, eliminate |

## 示例输出

```markdown
# Changelog

## [v1.2.3] - 2026-03-29

### Added
- New feature for user authentication (a1b2c3d)
- Implement dark mode support (e4f5g6h)

### Fixed
- Fix login bug on mobile devices (i7j8k9l)

### Changed
- Update documentation (m0n1o2p)
```
