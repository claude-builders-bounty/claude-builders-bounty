# Production CLAUDE.md for Next.js 15 + SQLite SaaS

An opinionated, production-ready `CLAUDE.md` specification for SaaS projects built with Next.js 15 App Router and SQLite (Turso / better-sqlite3 + Drizzle ORM).

## 🚀 2-Step Usage
1. Copy `templates/CLAUDE.md` to the root of your Next.js project.
2. Rename or ensure it is named `CLAUDE.md`. Claude Code will automatically ingest all architectural constraints and SQLite WAL conventions.
