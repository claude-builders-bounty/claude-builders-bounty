# Claude PR Review Agent 🤖

> A Claude Code sub-agent that analyzes Pull Request diffs and posts structured, actionable code reviews directly to GitHub or the terminal.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

## ⚡ Features

- **CLI or GitHub Action**: Run locally as `claude-review --pr ...` or automate in CI/CD on every PR.
- **Structured Markdown Schema**:
  - 📋 **Summary of Changes**: 2–3 concise sentences outlining core modifications and blast radius.
  - ⚠️ **Identified Risks**: Security vulnerabilities, breaking changes, dependency drift, and missing tests.
  - 💡 **Actionable Suggestions**: Concrete, prioritized recommendations to enhance code quality.
  - 🎯 **Confidence Score**: `High`, `Medium`, or `Low` with explicit rationale.
- **Dual Inference Engine**:
  - **Claude API Mode**: Leverages Anthropic's `claude-3-5-sonnet` for deep semantic code comprehension when `ANTHROPIC_API_KEY` is provided.
  - **Static Heuristic Engine**: Built-in zero-dependency AST/diff analyzer that works offline out of the box.
- **Automated PR Posting**: Pass `--post-comment` to automatically publish the review to the GitHub PR thread.

## 🚀 Quick Start

### 1. Installation

Clone the repository and install `claude-review`:

```bash
git clone https://github.com/claude-builders-bounty/claude-builders-bounty.git
cd claude-builders-bounty/agents/claude-review

# Install in editable mode
pip install -e .

# Or run directly via executable binary
./bin/claude-review --help
```

### 2. Environment Variables (Optional)

```bash
# Recommended for private repos or posting comments
export GITHUB_TOKEN="ghp_yourPersonalAccessToken"

# For Claude 3.5 Sonnet LLM analysis
export ANTHROPIC_API_KEY="sk-ant-api..."
```

## 💻 CLI Usage Examples

### Review any public GitHub PR
```bash
claude-review --pr https://github.com/pallets/flask/pull/5400
```

### Review and save to Markdown file
```bash
claude-review --pr https://github.com/owner/repo/pull/123 --output review.md
```

### Review and automatically post as a comment on GitHub
```bash
claude-review --pr https://github.com/owner/repo/pull/123 --post-comment
```

### Review local git diff offline
```bash
git diff main > feature.diff
claude-review --diff-file feature.diff --output local_review.md
```

## 🤖 GitHub Action CI/CD Integration

To automatically review every incoming Pull Request, add `.github/workflows/claude-review.yml` to your repository:

```yaml
name: Claude PR Reviewer

on:
  pull_request_target:
    types: [opened, synchronize, reopened]

permissions:
  contents: read
  pull-requests: write
  issues: write

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"

      - name: Install dependencies
        run: |
          pip install -e agents/claude-review

      - name: Run Claude PR Review Agent
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          claude-review \
            --pr "${{ github.event.pull_request.html_url }}" \
            --post-comment
```
