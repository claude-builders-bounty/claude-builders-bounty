## Summary
This PR migrates the `got` HTTP library from CommonJS to pure ESM, removing the dual CJS/ESM build in favor of a single ESM-only distribution. This is a major breaking change that requires consumers to use ESM `import` syntax and drops support for older Node.js versions that lack native ESM support. The implementation is thorough but the migration guide for existing users is minimal.

## Risks
- **Breaking change for all CJS consumers**: Any project using `const got = require('got')` will break immediately on upgrade. The README mentions this but no codemods or compatibility shim are provided.
- **`package.json` `"main"` field removed**: Older bundlers (Webpack 4, Jest without `extensionsToTreatAsEsm`) that rely on `"main"` may fail to resolve the package silently.
- **Node.js version requirement bump**: The PR implicitly requires Node 12.20+ or 14.13+ for ESM support; this constraint is not documented in the `engines` field of `package.json`.
- `test/helpers/server.ts` uses top-level `await` which is only valid in ESM — if any consumer's test runner is configured in CJS mode, the test suite will silently fail to load.

## Improvement Suggestions
- `package.json`: Add `"engines": { "node": ">=14.13.0" }` to make the Node.js version requirement explicit and surfaced via npm install warnings.
- `readme.md`: Add a migration guide section with a before/after code example showing the change from `require` to `import`.
- `source/index.ts`: The barrel export could use explicit named exports in addition to the default export to improve tree-shaking in bundlers.
- Consider adding a `package.json#exports["require"]` fallback that throws a helpful error explaining CJS is no longer supported, rather than a cryptic module-not-found error.
