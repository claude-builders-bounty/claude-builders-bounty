# Claude Code PR Reviewer Agent 🤖

An autonomous, deterministic Claude Code sub-agent that ingests pull request unified diffs, analyzes code changes for architectural impact, security vulnerabilities, and test coverage, and renders structured Markdown review comments directly into GitHub PRs.

---

## ⚡ Quickstart

### 1. Run via CLI

Review any public or private GitHub pull request directly:

```bash
# Review via GitHub PR URL
python3 agents/pr-reviewer/claude_review.py --pr https://github.com/owner/repo/pull/123

# Direct executable wrapper
chmod +x agents/pr-reviewer/claude-review
./agents/pr-reviewer/claude-review --pr https://github.com/owner/repo/pull/123
```

Review a local diff file or standard input:

```bash
# From diff file
./agents/pr-reviewer/claude-review --diff path/to/patch.diff

# Pipe git diff directly
git diff main...feature-branch | ./agents/pr-reviewer/claude-review
```

Post the review comment directly to the GitHub PR:

```bash
./agents/pr-reviewer/claude-review \
  --pr https://github.com/owner/repo/pull/123 \
  --token "$GITHUB_TOKEN" \
  --post
```

## 🤖 GitHub Actions CI/CD Integration

To run automated reviews on every pull request, add this workflow file to `.github/workflows/claude-pr-review.yml`:

```yaml
name: Claude Code PR Reviewer

on:
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  contents: read
  pull-requests: write
  issues: write

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - name: Check out repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Run Claude Code PR Reviewer
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          chmod +x agents/pr-reviewer/claude-review
          ./agents/pr-reviewer/claude-review \
            --pr "${{ github.event.pull_request.html_url }}" \
            --token "${{ secrets.GITHUB_TOKEN }}" \
            --post
```

Every generated review strictly adheres to the required structured Markdown specification:

```markdown

PR #123 introduces 'feature description', touching 3 file(s) across +150/-20 lines. Includes automated test updates across 1 test suite(s). Architectural impact is localized with clearly defined entry points.

### ⚠️ Identified Risks
- Missing automated test coverage: 2 source files modified with no corresponding test files updated.
- Potential SQL injection vulnerability via raw string interpolation.

### 💡 Improvement Suggestions
- Add unit or integration tests exercising newly added or refactored paths.
- Refactor to use parameterized queries or sanitized input validation.

---
**Confidence Score:** 🟢 **High**

> *Automated review generated by [Claude Code PR Reviewer Agent](https://github.com/claude-builders-bounty/claude-builders-bounty)*
```
