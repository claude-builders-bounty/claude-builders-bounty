# Claude Code PR Review Sub-Agent

Autonomous sub-agent that inspects Pull Request diffs and generates structured Markdown reviews with summaries, risk scores, and actionable feedback.

## Features
- **CLI Mode**: `python agents/pr-reviewer/reviewer.py --pr https://github.com/owner/repo/pull/123`
- **GitHub Action Workflow**: Automatically comments on opened/updated PRs (`.github/workflows/claude-review.yml`).
- **Structured Output**: Summary, Identified risks, Suggestions, Confidence score.
