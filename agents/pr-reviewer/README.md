# 🔍 PR Reviewer — Claude Code AI Agent

AI-powered PR review tool with automatic diff analysis and structured Markdown output.

## Setup (2 commands)

```bash
chmod +x claude-review
# Optional: Set Anthropic API key for AI-powered reviews
export ANTHROPIC_API_KEY=sk-ant-...
```

## Usage

```bash
# Review a GitHub PR (requires GITHUB_TOKEN)
claude-review --pr https://github.com/owner/repo/pull/123 --token $GITHUB_TOKEN

# Review a local diff file
claude-review --diff my-changes.patch
```

## Output Format

Produces structured Markdown with:
- **Summary** — 2-3 sentences of what changed
- **Identified Risks** — security, scale, breaking changes
- **Improvement Suggestions** — actionable code quality tips
- **Confidence Score** — Low / Medium / High with reasoning

## Modes

| Mode | Trigger | Analysis |
|------|---------|----------|
| **AI-Powered** | `ANTHROPIC_API_KEY` set | Claude API deep analysis |
| **Static Analysis** | No API key | Pattern-based security + quality scan |

The static mode detects: hardcoded secrets, command injection, SQL injection, missing tests, large PRs, and more.

## Requirements

- `bash` 4+, `python3`, `curl`
- `GITHUB_TOKEN` (for PR URLs)
- `ANTHROPIC_API_KEY` (optional, for AI mode)
