# 🤖 PR Reviewer — Automated GitHub PR Code Review Agent

An intelligent code review agent that analyzes GitHub Pull Requests for security vulnerabilities, performance issues, and code quality concerns. Posts structured, actionable review comments directly on your PRs.

**Works as:**
- 🐍 Standalone Python CLI tool
- 🔧 Claude Code skill (drop `SKILL.md` into your skills directory)

---

## ⚡ Setup (3 steps)

### 1. Install dependencies

```bash
pip install requests
```

### 2. Set your GitHub token

```bash
export GITHUB_TOKEN=ghp_your_token_here
```

> **Note**: A token with `repo` scope is required to post comments. For read-only reviews, a public-token or `public_repo` scope suffices.

### 3. Run it

```bash
python pr-reviewer.py --repo owner/repo --pr 123
```

That's it! 🎉

---

## 📖 Usage

```bash
# Review a PR (prints Markdown to stdout)
python pr-reviewer.py --repo owner/repo --pr 42

# Post the review as a comment on the PR
python pr-reviewer.py --repo owner/repo --pr 42 --post

# Save review to a file
python pr-reviewer.py --repo owner/repo --pr 42 --output review.md

# Output structured JSON
python pr-reviewer.py --repo owner/repo --pr 42 --json

# Pass token directly
python pr-reviewer.py --repo owner/repo --pr 42 --token ghp_xxx
```

### CLI Options

| Flag | Description |
|------|-------------|
| `--repo` | GitHub repository in `owner/repo` format (**required**) |
| `--pr` | Pull request number (**required**) |
| `--post` | Post the review as a comment on the PR |
| `--output FILE` | Write review Markdown to a file |
| `--json` | Output raw structured data as JSON |
| `--token TOKEN` | GitHub personal access token (or use `GITHUB_TOKEN` / `GH_TOKEN` env vars) |

## 🧠 What It Detects

### 🔒 Security Issues
- Hardcoded secrets, API keys, passwords
- `eval()` / `exec()` usage
- Shell injection (`subprocess` with `shell=True`, `os.system`)
- Unsafe deserialization (`pickle.load`)
- SQL injection patterns
- XSS risks (`innerHTML`, `dangerouslySetInnerHTML`)
- Disabled SSL verification
- Wildcard CORS origins

### ⚡ Performance Concerns
- Nested loops / O(n²) patterns
- `SELECT *` queries
- Synchronous HTTP calls in loops
- File descriptor leaks (missing context managers)
- Unnecessary `time.sleep()` calls

### 📝 Code Quality
- Debug statements (`print()`, `console.log()`)
- TODO/FIXME comments
- Linter suppressions (`#noqa`)
- Tab vs. space inconsistencies
