# claude-review

A Claude Code sub-agent that reviews GitHub pull requests and returns structured Markdown comments.

## Quick Start

```bash
pip install -r agents/pr-review/requirements.txt
export GITHUB_TOKEN=ghp_xxx
export CLAUDE_API_KEY=sk-ant_xxx
python agents/pr-review/agent.py --pr https://github.com/owner/repo/pull/123
```

## Usage

### CLI
```
python agents/pr-review/agent.py --pr https://github.com/owner/repo/pull/123
python agents/pr-review/agent.py --pr https://github.com/owner/repo/pull/123 --output review.md
python agents/pr-review/agent.py --pr https://github.com/owner/repo/pull/123 --basic
```

### GitHub Action

Add `.github/workflows/pr-review.yml` to your repo to auto-review PRs.

## Output Format

```markdown
# PR Review: owner/repo#123
> **PR Title** by @author
> 5 files | +200/-50
---
## Summary
...
## Risks
- ...
## Suggestions
- ...
## Confidence
High / Medium / Low
---
*Generated by claude-review*
```
