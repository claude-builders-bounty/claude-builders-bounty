# Third-party fixture attribution

The `diff` fields in `requests-6731.snapshot.json` and
`requests-6710.snapshot.json` are verbatim excerpts of Requests pull requests
from https://github.com/psf/requests, supplied by the connected GitHub API.
They remain subject to the Apache License 2.0; see `REQUESTS-LICENSE.txt`.
Requests is maintained by the Python Software Foundation and its contributors.

The surrounding JSON is a new test-fixture representation. Metadata was
normalized into the fields consumed by this reviewer; the source diff was not
edited. PR descriptions retain their original text. Each fixture records its
source URL and exact head/base commit IDs. Generated review responses and the
reviewer implementation are separate from the Requests source excerpts.
