# CLAUDE.md Template — Next.js + SQLite SaaS

A drop-in, opinionated `CLAUDE.md` for a Next.js 15 (App Router) + SQLite (better-sqlite3 + drizzle-orm) SaaS project, written so Claude Code can work in the repo without asking clarifying questions.

To use it: copy `CLAUDE.md` into the root of your project and adjust only the spots called out in its "How to Use This Template" section (DB driver if you use Turso/libsql, auth provider, seed script, env var names, plus any project-specific rules you append at the end).
