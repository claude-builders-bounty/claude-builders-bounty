# claude-review

AI-powered GitHub PR review CLI tool.

## Features

- Fetches PR metadata and diff using `gh` CLI
- Analyzes code changes for potential risks
- Generates structured Markdown review output
- Detects security issues, debug code, and code quality concerns

## Prerequisites

- Python 3.8+
- GitHub CLI (`gh`) installed and authenticated

Install and authenticate GitHub CLI:

```bash
# Install gh (Ubuntu/Debian)
sudo apt install gh

# Install gh (macOS)
brew install gh

# Authenticate
gh auth login
```

## Installation

### Option 1: Direct usage

```bash
# Clone or download the script
git clone <repo-url>
cd claude-review

# Make executable
chmod +x claude-review.py

# Run directly
./claude-review.py --pr https://github.com/owner/repo/pull/123
```

### Option 2: Install as command

```bash
# Copy to a directory in your PATH
cp claude-review.py ~/.local/bin/claude-review
chmod +x ~/.local/bin/claude-review

# Now you can run from anywhere
claude-review --pr https://github.com/owner/repo/pull/123
```

### Option 3: Install with pip

```bash
# Create a package and install
cd claude-review
pip install -e .
```

## Usage

### Basic usage

```bash
claude-review --pr https://github.com/owner/repo/pull/123
```

### Save review to file

```bash
claude-review --pr https://github.com/owner/repo/pull/123 --output file --output-dir ./reviews
```

### Example output

```markdown
# Code Review

**PR:** [Add new feature]([(https://github.com/owner/repo/pull/123))
**Author:** @developer
**Branch:** feature-branch → main
**Changes:** +150 / -30 across 5 file(s)

---

## Summary

PR #123 'Add new feature' by developer adds 120 net lines across 5 file(s). 
Key changes in: src/main.py, src/utils.py, tests/test_main.py.

## Risks

- 🚨 Potential hardcoded secrets or credentials detected
- ⚠️ Debug statements or TODOs found in changes

## Suggestions

- Consider running `ruff check` or `pylint` for Python code quality
- Ensure test coverage for new/modified functions
- Consider adding/updating documentation for new functionality

## Confidence

🟡 **Medium**

---

*Generated by claude-review CLI tool*
```

## Output Format

The tool generates a structured Markdown review with:

| Section | Description |
|---------|-------------|
| **Summary** | 2-3 sentence overview of the PR changes |
| **Risks** | List of potential issues found (security, code quality) |
| **Suggestions** | Recommendations for improvement |
| **Confidence** | Low/Medium/High - based on analysis depth |

## Risk Detection

The tool checks for:

- **Security Issues**
  - SQL injection patterns
  - XSS vulnerabilities
  - Hardcoded secrets/credentials
  - Dangerous functions (eval, exec)

- **Code Quality**
  - Debug statements (print, console.log)
  - TODO/FIXME comments
  - Large PRs (500+ lines)
  - Many files changed (10+)

## Troubleshooting

### "gh command failed"

Ensure GitHub CLI is installed and authenticated:

```bash
gh auth status
```

### "Invalid GitHub PR URL"

Make sure the URL format is correct:
- `https://github.com/owner/repo/pull/123`

### Permission denied

Make the script executable:

```bash
chmod +x claude-review.py
```
