# claude-review 🤖

Static PR reviewer that fetches a GitHub PR diff, runs rule-based analysis, and outputs structured Markdown review comments.

**Zero API keys needed.** Works on any public repository via `curl` and `diff` parsing.

## Installation

```bash
git clone https://github.com/korpo1337/claude-builders-bounty.git
cd claude-builders-bounty/claude-review
python3 claude-review.py --help
```

Requires Python 3.8+ (stdlib only — no dependencies).

## Usage

### CLI

```bash
# Print review to stdout
python3 claude-review.py https://github.com/owner/repo/pull/123

# Save to file
python3 claude-review.py --output review.md https://github.com/owner/repo/pull/123
```

### GitHub Action

Add `.github/workflows/pr-review.yml` to any repo:

```yaml
name: PR Review Bot

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Run claude-review
        run: |
          python .github/scripts/claude-review.py "${{ github.event.pull_request.html_url }}" > review.md
      - name: Post review comment
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          gh pr comment "${{ github.event.pull_request.number }}" --body-file review.md
```

Copy `claude-review.py` to `.github/scripts/claude-review.py` in your repo.

## How it works

1. **Fetch PR diff** via GitHub's public `.diff` endpoint
2. **Parse metadata** via GitHub API (title, author, body)
3. **Static analysis** on *new* lines only (`+` in diff):
   - Debug logging detection
   - Secret/credential pattern matching
   - Dynamic code execution (`eval`, `exec`, `new Function`)
   - XSS vectors (`innerHTML`, `dangerouslySetInnerHTML`)
   - SQL injection patterns
   - TODO/FIXME detection
   - `process.exit()` anti-pattern
   - Size risk (large additions, file count)
4. **Structured output** with confidence score (Low/Medium/High)
