# 🕵️ claude-review

A **zero-dependency** CLI tool that reviews GitHub PRs using Claude.

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
python claude_review.py --pr https://github.com/owner/repo/pull/123
```

**Output:** Structured Markdown with summary, risks, suggestions, and a confidence score — posted to stdout or saved to a file.

---

## Features

- **Zero pip dependencies** — uses only Python stdlib (`urllib`, `json`, `argparse`)
- **Two modes**: standalone CLI + GitHub Action
- **Structured output**: Summary → Risks → Suggestions → Confidence Score
- **Configurable model**: pick any Anthropic Claude model

## Quick Start

### CLI

```bash
# 1. Auth
export ANTHROPIC_API_KEY="sk-ant-..."

# 2. Review a PR
python claude_review.py --pr https://github.com/vercel/next.js/pull/76543

# 3. Save to file
python claude_review.py \
  --pr https://github.com/vercel/next.js/pull/76543 \
  --output review.md

# 4. Use a different model
python claude_review.py \
  --pr https://github.com/owner/repo/pull/123 \
  --model claude-opus-4-20250514
```

### GitHub Action (one-click)

Add `.github/workflows/pr-review.yml` to your repo:

```yaml
name: Claude PR Review
on:
  pull_request:
    types: [opened, synchronize]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: >
          python <(curl -fsSL
          https://raw.githubusercontent.com/claude-builders-bounty/claude-builders-bounty/main/agents/claude-review/claude_review.py)
          --pr "${{ github.event.pull_request.html_url }}"
          --output /tmp/review.md
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      - run: gh pr comment "${{ github.event.pull_request.number }}" --body "$(cat /tmp/review.md)"
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

> You need two secrets in your repo:
> - `ANTHROPIC_API_KEY` — from [console.anthropic.com](https://console.anthropic.com)
> - `GITHUB_TOKEN` — auto-provided, but needs `pull-requests: write` scope

### Use it as a reusable GitHub Action

```yaml
- uses: claude-builders-bounty/claude-builders-bounty/agents/claude-review@main
  with:
    anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}
```

## Options

| Flag | Default | Description |
|------|---------|-------------|
| `--pr` | (required) | Full GitHub PR URL |
| `--output` / `-o` | stdout | Write review to this file |
| `--model` | `claude-sonnet-4-20250514` | Anthropic model name |
| `--github-token` | `$GITHUB_TOKEN` | For higher API rate limits |
| `--no-header` | false | Skip the metadata header |

## Architecture

```
                    ┌──────────────┐
                    │  GitHub API  │
                    │  (unauthed   │
                    │   or token)  │
                    └──────┬───────┘
                           │  GET /repos/o/r/pulls/:num
                           ▼
                    ┌──────────────┐
                    │              │
                    │  claude-     │
                    │  review.py   │
                    │              │
                    └──────┬───────┘
                           │  POST /v1/messages
                           ▼
                    ┌──────────────┐
                    │  Claude API  │
                    │  (Anthropic) │
                    └──────────────┘
                           │
                           ▼
                    ┌──────────────┐
                    │  Structured  │
                    │  Markdown    │
                    │  Review      │
                    └──────────────┘
```

## Why zero dependencies?

The tool uses **Python stdlib only** so you can run it anywhere Python 3 is installed — no pip, no venv, no dependency conflicts. The only external thing you need is an Anthropic API key.
