# Sample review — claude-builders-bounty/claude-builders-bounty#4371

Source PR: https://github.com/claude-builders-bounty/claude-builders-bounty/pull/4371

## Summary
This PR adds a Claude Code PreToolUse guard that blocks several destructive Bash and SQL patterns before execution, records denied attempts, and returns a structured denial reason to Claude. It also adds an installer that preserves existing user hooks plus setup documentation describing the protected command classes.

## Risks
- SQL blocking is intentionally tied to recognized SQL-client contexts or SQL-leading commands, so destructive SQL tunneled through an unrecognized wrapper such as a container or remote-exec command could bypass the SQL-specific checks.
- The installer writes through a deterministic settings.json.tmp path, so two concurrent installer invocations could contend for the same temporary file.

## Improvement Suggestions
- Use a uniquely created temporary file in the settings directory before atomic replacement so concurrent installs remain isolated.
- Document the SQL-context boundary explicitly, or add safe unwrapping for common transport wrappers if the hook is expected to protect SQL passed through them.
