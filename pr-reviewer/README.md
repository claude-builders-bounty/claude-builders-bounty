# claude-review

A CLI tool that reviews GitHub Pull Requests and produces structured Markdown review comments.

## Features

- **Zero configuration**: Just pass a PR URL
- **Structured output**: Summary, risks, suggestions, and confidence score
- **Security scanning**: Detects potential hardcoded secrets, SQL injection risks
- **Code quality checks**: Finds TODO/FIXME comments, debug statements
- **Multi-language support**: Detects changes in JavaScript, TypeScript, Python, Go, Rust, and more
- **GitHub Action ready**: Includes a workflow YAML for CI/CD integration

## Installation

### Option 1: Direct Node.js usage

```bash
# Clone or copy the repository
git clone https://github.com/lam1688/claude-builders-bounty.git
cd claude-builders-bounty/pr-reviewer

# Run directly with Node
node claude-review.js --pr https://github.com/owner/repo/pull/123
```

### Option 2: Install as a global package

```bash
cd claude-builders-bounty/pr-reviewer
npm install -g

# Now available globally
claude-review --pr https://github.com/owner/repo/pull/123
```

### Option 3: Use with npx (no install needed)

```bash
npx --yes https://github.com/lam1688/claude-builders-bounty/tree/main/pr-reviewer --pr https://github.com/owner/repo/pull/123
```

### Option 4: GitHub Action

See the [`.github/workflows/pr-review.yml`](.github/workflows/pr-review.yml) file.

## Usage

### CLI

```bash
# Full URL format
claude-review --pr https://github.com/owner/repo/pull/123

# Short format (owner/repo/number)
claude-review --pr owner/repo/123

# Just PR number (when in a git repo with matching remote)
claude-review --pr 123
```

### GitHub Action

```yaml
- name: PR Reviewer
  uses: lam1688/claude-builders-bounty/pr-reviewer@main
  with:
    pr_url: ${{ github.event.pull_request.html_url }}
```

Or use the workflow dispatch:

```yaml
on:
  workflow_dispatch:
    inputs:
      pr_url:
        description: 'Pull Request URL'
        required: true
```

## Output Format

The CLI produces a structured Markdown review:

```markdown
# 📋 PR Review: #123 - Feature Title

## Summary
This PR modifies **5 file(s)** across JavaScript, Python, with **+200 additions** and **-50 deletions**.

## 🔍 Identified Risks
- Security: Potential hardcoded secret detected
- Size: Large PR with >1000 lines added - consider splitting

## 💡 Improvement Suggestions
- Add test files to improve code coverage
- Consider breaking this PR into smaller, focused changes

## 📊 Review Metadata
| Metric | Value |
|--------|-------|
| Confidence Score | **Medium** |
| Files Changed | 5 |
| Lines Added | +200 |
| Lines Deleted | -50 |
| Languages | JavaScript, Python |
| Has Tests | ❌ No |
| Has Docs | ✅ Yes |

---
*Generated by claude-review CLI*
```

## How It Works

1. **Fetches PR data** using the `gh` CLI (GitHub CLI)
2. **Retrieves the diff** for detailed analysis
3. **Analyzes the changes** for:
   - Security issues (hardcoded secrets, SQL injection patterns)
   - Code quality (TODO/FIXME, debug statements)
   - PR characteristics (size, test coverage, documentation)
4. **Generates structured Markdown** with risk assessment and suggestions

- GitHub CLI (`gh`) authenticated and available in PATH
