# Claude PR Reviewer Agent

This agent uses Claude (via the Anthropic API) to analyze a GitHub Pull Request diff and provide a structured Markdown review comment. It can be run either as a standalone CLI tool or as a GitHub Action.

## Features

Provides a structured Markdown output with:
- Summary of changes (2–3 sentences)
- Identified risks (list)
- Improvement suggestions (list)
- Confidence score (Low / Medium / High)

## Setup & Usage

### 1. Standalone CLI

**Prerequisites:**
- Python 3.8+
- `ANTHROPIC_API_KEY` set in your environment
- `GH_TOKEN` (or `GITHUB_TOKEN`) set in your environment (recommended for private repos and higher rate limits)

**Installation:**
```bash
git clone https://github.com/claude-builders-bounty/claude-builders-bounty.git
cd claude-builders-bounty/pr-reviewer
pip install -r requirements.txt
chmod +x claude-review.py
```

**Usage:**
```bash
export ANTHROPIC_API_KEY="your-api-key"
export GH_TOKEN="your-github-token"

./claude-review.py --pr https://github.com/owner/repo/pull/123
```

You can optionally specify a model (defaults to `claude-3-7-sonnet-20250219`):
```bash
./claude-review.py --pr https://github.com/owner/repo/pull/123 --model claude-3-haiku-20240307
```

### 2. GitHub Action

You can also use this directly in your CI/CD workflows to automatically comment on new PRs.

```yaml
name: Claude PR Reviewer
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4
      
      - name: Run Claude Review
        uses: claude-builders-bounty/claude-builders-bounty/pr-reviewer@main
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          pr_url: ${{ github.event.pull_request.html_url }}
```

Ensure that your repository has the `ANTHROPIC_API_KEY` secret configured, and that `GITHUB_TOKEN` has permission to add PR comments (under Settings -> Actions -> General -> Workflow permissions, enable "Read and write permissions").
