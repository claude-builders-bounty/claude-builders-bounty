# PR Review Agent

Claude Code sub-agent that reviews GitHub PRs and posts structured Markdown comments.

## Quick Start

### Option 1: CLI

```bash
# Set environment variables
export GH_TOKEN=your_github_token
export ANTHROPIC_API_KEY=your_claude_api_key

# Run review
python pr_reviewer.py --pr https://github.com/owner/repo/pull/123

# Post directly to GitHub
python pr_reviewer.py --pr https://github.com/owner/repo/pull/123 --post
```

### Option 2: GitHub Actions

1. Add secrets to your repo:
   - `GH_TOKEN` - GitHub personal access token
   - `ANTHROPIC_API_KEY` - Claude API key

2. Copy workflow file to `.github/workflows/pr-review.yml`

3. Done! Every PR will be automatically reviewed.

---

## Features

- ✅ **Structured Output**: Summary, Risks, Suggestions, Confidence Score
- ✅ **CLI Mode**: Run manually on any PR
- ✅ **GitHub Actions**: Automatic review on PR open/update
- ✅ **Configurable**: Works with any public GitHub repo

---

## Output Format

```markdown
## 🤖 Automated PR Review

### Summary
This PR adds user authentication with OAuth2 and session management.
The implementation includes login/logout endpoints and JWT token handling.

### Identified Risks
- JWT secret stored in environment variable (ensure it's not committed)
- No rate limiting on login endpoint (potential brute force risk)
- Session timeout set to 30 days (consider shorter for security)

### Improvement Suggestions
- Add rate limiting to /api/login endpoint
- Consider using httpOnly cookies for JWT storage
- Add tests for edge cases (expired tokens, invalid credentials)
- Add logging for failed login attempts

### Confidence Score
Medium

---
*Generated by PR Review Agent*
```
